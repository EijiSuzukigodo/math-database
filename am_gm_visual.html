相加平均・相乗平均を図とグラフで理解する

数学Ⅱ ｜ 式と証明 ｜ 動かして学ぶ教材

まずは公式を確認

(a + b) / 2 ≥ √(ab)

条件：a ≥ 0、b ≥ 0。左辺が相加平均、右辺が相乗平均です。a = b のときだけ等号が成立します。

① a と b を動かしてみよう

相加平均 (a+b)/23.000
相乗平均 √(ab)2.828
差（必ず0以上）0.172

② 面積で確かめる

辺の長さが a と b の長方形の面積は ab。その面積と同じ正方形の一辺は √(ab) です。右の正方形の一辺 (a+b)/2 と比べてください。

※長方形と2つの正方形は、共通の縮尺で描いています。a または b が0なら面積0になります。

③ グラフで確かめる

b = 2.0 に固定し、横軸 a（0〜10）に対して、相加平均と相乗平均を描きます。縦の点線が現在の a です。

両曲線は a=b の位置で接します。a と b の値を変えて確認してください。

④ なぜ必ず成立する？

① 実数の2乗は必ず0以上：(√a − √b)² ≥ 0
② 展開すると：a − 2√(ab) + b ≥ 0
③ 移項すると：a + b ≥ 2√(ab)
④ 両辺を2で割る：(a+b)/2 ≥ √(ab)
⑤ 等号は √a = √b、つまり a = b のときだけ成立します。

発展：a,b が正のとき、長方形の周の長さが同じなら、a=b の正方形が最大の面積を持つことにもつながります。
