コーシー列と実数の完備性

「極限値が先に分からなくても、数列の収束を調べられる」

1．コーシー列とは？

数列の後ろのほうの項どうしが、いくらでも近くなる数列をコーシー列といいます。

任意の ε > 0 に対して、ある N が存在し、
m, n ≥ N ならば |an − am| < ε

「ある時点より先では、どの2項を選んでも距離が ε より小さい」という意味です。極限値 L を先に知らなくても定義できます。

ε–N論法：項と極限値の距離を調べる。
コーシー条件：項と項の距離を調べる。

3．収束とコーシー列の関係

実数の数列について、次の同値が成り立ちます。

実数列が収束する ⇔ その数列はコーシー列である

「収束 ⇒ コーシー」は三角不等式から分かります。一方「コーシー ⇒ 収束」は実数の完備性を使います。

証明①　収束する数列はコーシー列

an → L とする。任意の ε > 0 に対し、ある N をとって n ≥ N なら |an−L| < ε/2 とできる。したがって m,n ≥ N なら

|an−am| ≤ |an−L| + |am−L| < ε/2 + ε/2 = ε

証明②　コーシー列は実数の中で収束する（概略）

コーシー列は有界である。有界実数列には収束部分列が存在する（ボルツァーノ・ワイエルシュトラスの定理）。その部分列の極限を L とすると、コーシー条件と三角不等式により数列全体も L に収束する。

※ 有界数列が収束部分列をもつ性質は、実数の完備性に基づきます。この意味で「コーシー列が収束する」は実数の重要な性質です。

4．練習問題と解答

問題1　aₙ = 1/n がコーシー列であることを証明

ε > 0 を任意にとる。自然数 N を 1/N < ε となるように選ぶ。m,n ≥ N なら、1/m,1/n はともに (0,1/N] にあるので、|1/n−1/m| ≤ 1/N < ε。よってコーシー列である。

問題2　aₙ = (−1)ⁿ がコーシー列でないことを証明

ε = 1 とする。どの N に対しても、N 以降の偶数 n と奇数 m を選べる。そのとき |aₙ−aₘ| = |1−(−1)| = 2 ≥ 1。したがってコーシー条件を満たさない。

問題3　aₙ = (−1)ⁿ/n がコーシー列であることを証明

ε > 0 を任意にとる。N を 2/N < ε と選べば、m,n ≥ N に対して |aₙ−aₘ| ≤ 1/n + 1/m ≤ 2/N < ε。したがってコーシー列である。

問題4　なぜ有理数だけでは完備でないのか？

例えば √2 に近づく有理数の列（1, 1.4, 1.41, 1.414, …）は有理数の範囲でもコーシー列ですが、その極限 √2 は有理数ではありません。つまり、有理数全体では「コーシー列は必ずその集合内で収束する」が成立しません。
