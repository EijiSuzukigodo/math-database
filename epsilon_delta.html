ε–δ論法で学ぶ関数の連続性

連続と不連続を、帯の幅と反例の点で確かめよう

連続性の定義

関数 f が x = a で連続であるとは、任意の ε > 0 に対し、ある δ > 0 が存在して、

|x − a| < δ ⇒ |f(x) − f(a)| < ε

が、定義域に属するすべての x について成り立つことです。εは縦方向の許容幅、δは横方向の許容幅です。

2. なぜ連続・不連続なのか

学習のポイント

連続の場合は、εがどれほど小さくても、それに合わせてδを選べます。不連続の場合は、あるεを一つ固定すると、どんなδを選んでも条件を破る点が見つかります。

グラフが途中でつながって見えるかどうかだけではなく、量化の順序「任意のε → あるδ → すべてのx」が重要です。
