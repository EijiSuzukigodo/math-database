ε–δ論法を動かして理解する

連続な関数と不連続な関数を、同じ ε と δ で比べてみましょう。

① 定義をグラフで確かめる

点 x = 0 で連続であるとは、任意の ε > 0 に対して、ある δ > 0 が存在し、|x| < δ なら |f(x) − f(0)| < ε となることです。

|x| < δ の帯|f(x) − f(0)| < ε の帯関数のグラフ

図の座標範囲は x：−2～2、y：−0.5～2。スライダーは縦横の帯を変えます。条件の判定は、描画の近似ではなく数式に基づきます。

② なぜ違いが生まれるのか

連続な例： f(x) = x² では f(0) = 0 です。|x| < δ なら |x²| < δ² なので、例えば δ = √ε と取れば必ず条件を満たします。

不連続な例： g(x) = 0（x ≤ 0）, 1（x > 0） とすると g(0) = 0 です。ε = 12 を固定すると、どれほど小さい δ を選んでも、その右側に g(x) = 1 となる点があり、条件が成り立ちません。

数学的な証明を読む（連続な場合）

任意に ε > 0 を取る。δ = √ε > 0 と定める。|x − 0| < δ なら、|f(x) − f(0)| = |x²| = |x|² < δ² = ε。したがって f は 0 で連続である。□

数学的な証明を読む（不連続な場合）

ε = 1/2 と置く。どんな δ > 0 に対しても x = δ/2 > 0 と選べば、|x| < δ である一方、|g(x) − g(0)| = |1 − 0| = 1 ≥ ε。よって定義の条件を満たす δ は存在せず、g は 0 で不連続である。□

③ 練習問題

問題： f(x) = 3x が x = 0 で連続であることを ε–δ論法で示しましょう。

解答・解説を見る

任意の ε > 0 に対し δ = ε/3 と置く。|x| < δ なら |f(x) − f(0)| = 3|x| < 3δ = ε。したがって x = 0 で連続である。□
