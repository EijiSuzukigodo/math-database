数列の収束と ε–N論法

「いつから先の項が全部入るのか」を、点と帯で確かめよう。

学習の目標

数列が「収束する」とは？

数列 an が L に収束するとは、どんなに小さな ε > 0 を指定しても、ある自然数 N が存在し、それ以降すべての項が L から距離 ε 未満に入ることです。

すべての ε > 0 に対し、ある N が存在して、
n ≧ N ならば |an − L| < ε

ポイント：ひとつの項だけでなく、N以降のすべての項が条件を満たす必要があります。

① ε と N を動かしてみよう

帯の幅を変える
縦の線を左右に動かす
|aₙ−0| < ε の範囲 数列の点 N の位置

※ 横軸は項番号 n、縦軸は aₙ です。例の候補極限値は L = 0。描画は1〜150項で、判定には数列の式から導く全項に関する条件を使用しています。

② 図の読み方

  1. まず aₙ = 1/n を選び、ε = 0.30 にします。
  2. N = 4 にすると、n ≧ 4 では 1/n ≦ 1/4 = 0.25 < 0.30 です。
  3. ε をもっと小さくすると、必要な N は大きくなります。
  4. aₙ = (−1)ⁿ では、帯をいくら先まで移動しても全項は入りません。0 に収束しません（実際、どんな実数にも収束しません）。

ε–δ論法では入力 x の近さを δ で指定しましたが、ε–N論法では項番号 n が十分大きいことを N で指定します。

③ 厳密な証明

命題：数列 an = 1/n は 0 に収束する。

証明：任意に ε > 0 を取る。アルキメデスの性質により、N > 1/ε となる自然数 N を選べる。このとき n ≧ N なら

|an − 0| = 1/n ≦ 1/N < ε

である。よって定義から an → 0。□

もう一歩：aₙ = (−1)ⁿ/n も 0 に収束する理由

すべての自然数 n に対して |(−1)ⁿ/n| = 1/n。したがって先ほどと同じ N を選べば |aₙ−0| < ε となる。符号が交互に変わっても、0 からの距離が小さくなることが重要。

発展：aₙ = (−1)ⁿ が収束しない証明

仮に L に収束するとすると、偶数番目の部分列はつねに 1 なので L = 1、奇数番目の部分列はつねに −1 なので L = −1 でなければならない。しかし極限値は一意であり矛盾する。したがって収束しない。

④ 練習問題

問題1：aₙ=1/n とし、ε = 0.20 とする。条件 |aₙ| < ε が n ≧ N で成立する最小の自然数 N を求めなさい。

解答・解説を見る

1/n < 0.20 = 1/5 より n > 5。したがって N = 6。等号では不十分な点に注意しましょう。

問題2：aₙ=1/√n とし、ε = 0.25 とする。最小の自然数 N を求めなさい。

解答・解説を見る

1/√n < 1/4 は n > 16 と同値。したがって N = 17。
