数学Ⅰ・A 第1問〔2〕 後半
接線の長さと三角形の辺の比

学習の目的

2026年度本試験の後半では、円の外部から引いた接線の長さと、三角形の正弦定理を組み合わせます。交点Rが直線PQのどちら側にあるかで、辺の長さの式が変わることが重要です。

前半の面積公式・操作教材に戻る →

問題文と公式図の転載は行っていません。以下は出題条件に基づく独自の解説・模式図です。

① 2つの場合を切り替えてみよう

図は位置関係を学ぶための模式図です。正確な作図ではなく、辺の「足し算」と「引き算」の違いに注目してください。

② (i) 接線の長さが PK=12、QL=9 の場合

円の半径は6です。接点において半径と接線が直角になるため、前半で求めた四角形の面積公式から、

sin P = 4/5、sin Q = 12/13

△PQRに正弦定理を使うと、PRは角Qの向かい側、RQは角Pの向かい側です。

PR : RQ = sin Q : sin P
= (12/13) : (4/5)
= 15 : 13

Rから引いた2本の接線は等しいので、RK=RL=x とおきます。この場合、点の並びから

PR = PK + KR = 12 + x
RQ = QL + LR = 9 + x

したがって、

(12+x) : (9+x) = 15 : 13
13(12+x) = 15(9+x)
156 + 13x = 135 + 15x
2x = 21
x = 21/2 = 10.5

よって PR=45/2、RQ=39/2 となり、15:13 と一致します。

③ (ii) 接線の長さが PK=4√2、QL=3√2 の場合

今度はRが直線PQについてOと反対側にあります。円は△PQRの傍接円に対応し、点の並びが(i)と変わります。

面積を2通りで表すと、

sin P = 12√2/17
sin Q = 2√2/3

△PQRの内角は、もとの接線の角の補角になりますが、sin(180°−θ)=sin θ なので、正弦定理を使えます。

PR : RQ = sin Q : sin P
= (2√2/3) : (12√2/17)
= 17 : 18

RK=RL=x とおくと、この配置では接点がRとP・Qの間ではなく、P・Qを越えた側にあります。

PR = RK − PK = x − 4√2
RQ = RL − QL = x − 3√2

よって、

(x−4√2) : (x−3√2) = 17 : 18
18(x−4√2) = 17(x−3√2)
18x−72√2 = 17x−51√2
x = 21√2

したがって PR=17√2、RQ=18√2 となります。

④ なぜ式が変わるのか

ヒント：点の並びを考える

同じ直線上でも、PとRの間にKがあるか、PがRとKの間にあるかで、PRはPK+KRにも、RK−PKにもなります。

答えの確認
  • (i) 接線の長さ RK=RL=21/2
  • (ii) 接線の長さ RK=RL=21√2

公式を暗記するよりも、実際の図で点の順番を確認することが大切です。
