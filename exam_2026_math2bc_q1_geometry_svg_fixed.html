1．問題と解答例

例題：中心間の距離が 2.5、半径がそれぞれ 2 と 3 の2円について、位置関係を答えなさい。

解答：2点で交わる。

途中計算

中心間の距離を d、半径を r₁、r₂ とすると、d = 2.5、r₁ = 2、r₂ = 3。

|r₁ − r₂| = |2 − 3| = 1
r₁ + r₂ = 2 + 3 = 5
1 < 2.5 < 5

したがって |r₁ − r₂| < d < r₁ + r₂ が成り立つので、2円は異なる2点で交わります。

なぜこの不等式で分かるのか

2円が交わる点を P、中心を O₁、O₂ とすると、三角形 O₁PO₂ の3辺の長さは r₁、r₂、d です。三角形が成立する条件は「2辺の差より残りの1辺が大きく、2辺の和より小さい」ことです。

2．位置関係の判定表

中心が異なる2円（d > 0）について、次の5通りに分類できます。

d > r₁ + r₂：離れている（共有点なし）
d = r₁ + r₂：外接（共有点1つ）
|r₁ − r₂| < d < r₁ + r₂：2点で交わる
d = |r₁ − r₂|：内接（共有点1つ）
0 < d < |r₁ − r₂|：一方が他方の内部（共有点なし）

補足：中心が一致する d = 0 の場合、半径が等しければ同一の円、異なれば同心円です。この教材の中心間距離は2.5に固定しています。

4．判定条件の証明

2点で交わる条件の証明

交点 P が2つ存在するとき、O₁、O₂、P は一直線上になく、3辺 r₁、r₂、d で三角形ができます。三角形の成立条件より |r₁ − r₂| < d < r₁ + r₂ が必要です。

逆に、この不等式が成り立てば3辺 r₁、r₂、d の三角形を作れます。中心を結ぶ直線の上下に対称な2つの頂点 P が得られるため、2円は2点で交わります。

接するときに等号になる理由

交点 P が中心を結ぶ直線上にあるとき、三角形がつぶれて一直線になります。P が中心の間にあれば d = r₁ + r₂（外接）、同じ方向にあれば d = |r₁ − r₂|（内接）です。

5．確認問題

中心間の距離を d = 2.5 として考えましょう。

問題A：r₁ = 1、r₂ = 1 のときは？（答えを見る）

1 + 1 = 2 < 2.5 なので、2円は離れています。

問題B：r₁ = 1、r₂ = 1.5 のときは？（答えを見る）

1 + 1.5 = 2.5 なので、外接します。

問題C：r₁ = 0.5、r₂ = 3 のときは？（答えを見る）

|0.5 − 3| = 2.5 なので、内接します。

問題D：r₁ = 0.2、r₂ = 4 のときは？（答えを見る）

|0.2 − 4| = 3.8 > 2.5 なので、小さい円は大きい円の内部にあり、共有点はありません。
