この教材で学ぶこと

関数 y = A sin(x + φ) の振幅、位相、最大値・最小値を、グラフと計算の両方から理解します。

学習用の独自例題 以下の問題・解答は、2026年度共通テストの設問や正式解答を再現したものではありません。

例題1：最大値・最小値を求める

問題：関数 y = 2 sin(x + π/3) + 1 の最大値、最小値、およびそれぞれをとる x の条件を求めなさい。

解答：最大値は 3、最小値は −1。最大値をとるのは x = π/6 + 2kπ、最小値をとるのは x = 7π/6 + 2kπ（k は整数）。

途中計算と考え方

  1. どんな実数 t に対しても −1 ≤ sin t ≤ 1 です。
  2. 両辺を2倍して1を加えると、−1 ≤ 2 sin(x + π/3) + 1 ≤ 3。
  3. 最大値3となるのは sin(x + π/3) = 1 のとき。したがって x + π/3 = π/2 + 2kπ から x = π/6 + 2kπ。
  4. 最小値−1となるのは sin(x + π/3) = −1 のとき。x + π/3 = 3π/2 + 2kπ より x = 7π/6 + 2kπ。

ポイント：位相のずれは、最大値・最小値そのものを変えず、最大・最小をとる x の位置を変えます。

例題2：グラフの移動と周期

問題：y = −3 sin(2x − π/2) の振幅、周期、最大値、最小値を求めなさい。

解答：振幅 3、周期 π、最大値 3、最小値 −3。

詳しい解説

2x − π/2 = 2(x − π/4) なので、基本の正弦曲線を右へ π/4 だけ移動し、横方向を1/2倍、縦方向を3倍して上下反転したグラフです。

一般に y = A sin(Bx + C) + D（A ≠ 0、B ≠ 0）では、振幅は |A|、周期は 2π/|B|、最大値は D + |A|、最小値は D − |A| です。

公式はなぜ成り立つ？

最大値・最小値の理由：−1 ≤ sin θ ≤ 1 なので、A が正でも負でも −|A| ≤ A sin θ ≤ |A| です。これに D を加えると、D − |A| ≤ A sin θ + D ≤ D + |A|。sin θ は実際に ±1 をとるので、両端の値が最大値・最小値になります。

周期の理由：sin は角度が 2π 進むと同じ値になります。B(x + T) + C = Bx + C ± 2π を満たす最小の正の T は T = 2π/|B| です。

位相の理由：Bx + C = B(x + C/B) と変形できるため、基本のグラフは x 軸方向に −C/B だけ平行移動します。

自分で解いてみよう

練習1：y = 4 sin(x − π/6) − 2 の最大値・最小値は？（答えを表示）

最大値 2、最小値 −6。 −1 ≤ sin ≤ 1 を4倍して2を引くと −6 ≤ y ≤ 2 です。

練習2：y = 2 cos(3x) + 1 の周期と値域は？（答えを表示）

周期 2π/3、値域 −1 ≤ y ≤ 3。 cos(3x) は x が 2π/3 増えると1周期進みます。

練習3：y = −sin(x + π/2) の最大値と、そのときの x は？（答えを表示）

最大値 1。 sin(x + π/2) = −1 のときなので、x = π + 2kπ（k は整数）です。

操作のヒント

上のグラフでは y = A sin(x + φ) を描いています。振幅 A を変えると縦の広がりが変わり、位相 φ を増やすと曲線が左へ動きます。例題1のような上下移動「+1」は、このスライダーの対象外です。
