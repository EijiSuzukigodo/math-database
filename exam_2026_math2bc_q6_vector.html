1. 位置ベクトルを動かそう（従来の学習内容）

原点 O から点 A に向かうベクトル a = (x, y) を、成分を変えて観察します。

2. ベクトルの和と内積

青い a とオレンジの b を足すと、緑の a + b になります。内積は角度の関係を表します。

ab（破線は平行移動）a + b

内積と角度の関係を確認する

a · b = |a||b| cos θ。内積が正なら鋭角、0なら直角、負なら鈍角です（両方が零ベクトルでない場合）。

3. 線形結合と点の決定

点 P の位置ベクトルを OP = s·a + t·b とします。係数を動かして点 P の位置を調べます。

s + t = 1 なら、P は A と B を通る直線上にあります。0 ≤ s, t ≤ 1 かつ s + t = 1 なら、線分 AB 上にあります。

5. 解答付き例題：計算の途中まで分かる

例題 1

ベクトルの和と内積を求める

a = (3, 2)、b = (1, 3) とする。a + b と a · b を求めよ。

  1. ベクトルの和は、対応する成分どうしを足します。
  2. 内積は、対応する成分を掛けてから足します。
a + b = (3 + 1, 2 + 3) = (4, 5)
a · b = 3 × 1 + 2 × 3 = 9

答え：和は (4, 5)、内積は 9。

上のスライダーを a = (3, 2)、b = (1, 3) に設定すると、図でも確かめられます。

例題 2

2つのベクトルのなす角

例題1の a、b のなす角を θ とする。cos θ を求めよ。

  1. 長さを計算します。|a| = √(3²+2²) = √13、|b| = √(1²+3²) = √10。
  2. 内積の公式 a · b = |a||b| cos θ に代入します。
cos θ = 9√13 × √10 = 9√130

答え：cos θ = 9√130。正なので、なす角は鋭角です。

例題 3

線分を内分する点の位置ベクトル

A = (3, 2)、B = (1, 3) とし、線分 AB を AP : PB = 1 : 2 に内分する点 P の座標を求めよ。

内分点の公式より、A にかかる係数は 2、B にかかる係数は 1 です。

OP = 2OA + OB3
P = (2 × 3 + 13, 2 × 2 + 33)

答え： P = (73, 73)。

上の線形結合の図で s = 2/3、t = 1/3 とすると、この点の位置を確認できます（スライダーの刻みが0.1なので近い値で観察します）。

例題 4

垂直なベクトルを見つける

a = (3, 2) に垂直なベクトルを1つ求めよ。

内積が0なら、零ベクトルでない2つのベクトルは垂直です。

(3, 2) · (−2, 3) = 3 × (−2) + 2 × 3 = 0

答えの一例： (−2, 3)。

6. 公式の理由を証明する

内積の公式はなぜ成り立つのでしょうか

2つのベクトルを a、b、なす角を θ とします。三角形の余弦定理から、

|a − b|² = |a|² + |b|² − 2|a||b|cos θ

一方、成分で展開すると、

|a − b|² = |a|² + |b|² − 2(aₓbₓ + aᵧbᵧ)

この2つを比較すると、

aₓbₓ + aᵧbᵧ = |a||b|cos θ

したがって、成分で計算する内積と、角度から考える内積は一致します。

内分点の公式はなぜ成り立つのでしょうか

AP : PB = m : n（m, n は正）とします。P は A から B に向かって全体の m/(m+n) だけ進んだ点なので、

OP = OA + mm + n(OB − OA)

同類項をまとめれば、

OP = nOA + mOBm + n

となります。内分点の係数が「反対側の比」になる理由が分かります。

7. 練習問題と解答

練習① a = (−1, 4)、b = (2, 3) のとき、a + b と a · b を求めよ。

解答・途中計算を見る

a + b = (−1+2, 4+3) = (1, 7)。

a · b = (−1)×2 + 4×3 = −2+12 = 10。

練習② a = (2, −1)、b = (1, 2) は垂直か。

解答・途中計算を見る

a · b = 2×1 + (−1)×2 = 0。どちらも零ベクトルでないので、垂直です。

練習③ A = (0, 0)、B = (6, 3) とするとき、AB の中点 M を求めよ。

解答・途中計算を見る

M = ((0+6)/2, (0+3)/2) = (3, 32)。

8. 確認問題

問題：a = (3, 2), b = (1, 3) のとき、a · b はいくつでしょうか。

解説を読む

a · b = 3×1 + 2×3 = 9 です。対応する成分どうしを掛けて足します。
