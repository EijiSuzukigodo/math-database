第7問｜平面上の曲線と複素数平面

複素数の掛け算を「回転」で理解し、極形式・楕円の性質まで学ぶ
数学Ⅱ・B・C目次大学入試問題トップページ
教材の位置づけ：2026年度共通テストの学習に役立てるための独自の例題・解説・操作教材です。以下の例題の答えは学習用であり、本試験の各設問の正式解答ではありません。実際の問題と正答は大学入試センター公式の過去問題ページをご確認ください。

最初に：複素数平面とは？

複素数 z = x + yi を、横座標 x（実部）、縦座標 y（虚部）の点として表した平面です。ここで i² = −1 です。

原点から点までの距離を絶対値 |z|、実軸の正の方向から測った角度を偏角 θ と呼びます。

絶対値：|z|=x2+y2
極形式：z=r(cos⁡θ+isin⁡θ)

偏角はラジアンで扱います。偏角が 0 の複素数は実軸の正の方向にあります。z = 0 の偏角は定義されません。

1．複素数平面を動かそう

元の教材の「絶対値・偏角」を変えるスライダーとSVGの図を引き継ぎました。点の位置と直交形式 x + yi を同時に確認できます。

青い線の長さが |z|、線の傾きが偏角です。スライダーを動かして、実部と虚部の変化を比べましょう。

2．解答付き例題：複素数の計算

例題①

z = 1 + i、w = 1 − i とするとき、zw、|z|、|w| を求めましょう。

解答・途中計算

  1. 積を展開します：
    zw = (1 + i)(1 − i) = 1 − i² = 1 − (−1) = 2
  2. 絶対値を計算します：
    |z|=12+12=2、|w|=2
  3. 積の絶対値は |zw|=2=2×2 です。

答え：zw = 2、|z| = |w| = √2

z の偏角は π/4、w の偏角は −π/4 なので、掛け算すると偏角が足されて 0 になり、積 2 は実軸の正の方向にあります。

なぜ掛け算は「回転」になるのか

z₁ = r₁(cos α + i sin α)、z₂ = r₂(cos β + i sin β) を掛けると、三角関数の加法定理から次の式が成り立ちます。

z₁z₂ = r₁r₂ {cos(α + β) + i sin(α + β)}

つまり、絶対値は掛け算、偏角は足し算になります。これは極形式の最も重要な性質です。

3．ド・モアブルの定理と証明

(cos⁡θ+isin⁡θ)n=cos⁡nθ+isin⁡nθ
証明（数学的帰納法）を開く

① n = 1 のとき：両辺は cos θ + i sin θ で一致します。

② n = k で成り立つと仮定し、両辺に (cos θ + i sin θ) を掛けます。

(cos kθ + i sin kθ)(cos θ + i sin θ)
= [cos kθ cos θ − sin kθ sin θ] + i[sin kθ cos θ + cos kθ sin θ]

加法定理により cos((k+1)θ) + i sin((k+1)θ) となり、n = k+1 でも成り立ちます。したがって正の整数 n について成り立ちます。

例題②

(1 + i)⁴ を求めましょう。

1 + i = √2 (cos(π/4) + i sin(π/4)) より、ド・モアブルの定理を使うと、

(1+i)4=(2)4(cos⁡π+isin⁡π)=−4

答え：−4（直接展開しても確認できます）

4．複素数の方程式と軌跡

例題③

|z − (1 + i)| = 2 を満たす z = x + yi の点の軌跡を求めましょう。

z − (1 + i) = (x − 1) + (y − 1)i なので、

(x−1)2+(y−1)2=2(x−1)2+(y−1)2=4

答え：中心 (1, 1)、半径 2 の円です。複素数の絶対値は2点間の距離を表します。

5．楕円を動かして理解する

平面上の曲線として楕円も学びましょう。横半径 a、縦半径 b（a ≥ b > 0）の楕円は次の式で表されます。

x2a2+y2b2=1

楕円上の点 P から2つの焦点 F₁, F₂ までの距離の和は一定で、PF₁ + PF₂ = 2a です。スライダーを動かして確かめましょう。

楕円の焦点の性質を証明する

c² = a² − b²、P = (a cos t, b sin t)、F₁ = (−c,0)、F₂ = (c,0) とします。

PF₁² = (a cos t + c)² + b² sin² t = (a + c cos t)²、PF₂² = (a cos t − c)² + b² sin² t = (a − c cos t)² です。

a > c ≥ 0 なので PF₁ = a + c cos t、PF₂ = a − c cos t。したがって PF₁ + PF₂ = 2a が証明されます。

6．練習問題（タップで解答表示）

練習① (2 + i)(2 − i) を計算する

(2 + i)(2 − i) = 4 − i² = 4 + 1 = 5。

練習② z = −1 + √3i の絶対値を求める

|z| = √{(−1)² + (√3)²} = √4 = 2。偏角の一つは 2π/3 です。

練習③ 楕円 x²/9 + y²/4 = 1 の焦点間の距離は？

a = 3、b = 2、c = √(a² − b²) = √5。焦点は (±√5,0) だから焦点間の距離は 2√5 です。
