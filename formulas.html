公式データベース

高校数学から大学数学まで。公式の意味・条件・使い方を確認できます。

公式名・分野・説明から検索できます。公式の「計算例・使い方を見る」を押すと詳しく確認できます。

高校数学Ⅰ・A

展開公式

(a + b)² = a² + 2ab + b²

積を展開して多項式を整理します。

計算例・使い方を見る

(x + 3)² = x² + 6x + 9

平方差の因数分解

a² − b² = (a − b)(a + b)

2つの平方の差を積の形に直します。

計算例・使い方を見る

x² − 25 = (x − 5)(x + 5)

二次方程式の判別式

D = b² − 4ac

a ≠ 0 の実数係数の二次方程式で、D > 0 なら異なる2実数解、D = 0 なら重解、D < 0 なら実数解なし。

計算例・使い方を見る

x² − 4x + 3 = 0 では D = 16 − 12 = 4

正弦定理

a / sin A = b / sin B = c / sin C = 2R

三角形の辺と向かい合う角、外接円半径 R の関係です。

計算例・使い方を見る

A = 30°、a = 5 なら R = 5

余弦定理

c² = a² + b² − 2ab cos C

C は辺 a と b に挟まれた角です。

計算例・使い方を見る

a = 3、b = 4、C = 90° なら c = 5

順列

ₙPᵣ = n! / (n − r)!

異なる n 個から r 個を選び順序をつける場合の数。0 ≤ r ≤ n。

計算例・使い方を見る

₅P₂ = 5 × 4 = 20

確率の加法定理

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

A と B が同時に起こる部分を重複して数えない公式です。

計算例・使い方を見る

P(A)=0.5、P(B)=0.4、P(A∩B)=0.2 なら 0.7

二次方程式の解の公式

x = (−b ± √(b² − 4ac)) / 2a

ax² + bx + c = 0（a ≠ 0）の解。実数解を考えるときは判別式 D = b² − 4ac を確認します。

計算例・使い方を見る

x²−5x+6=0 の解は x=2, 3。

二次関数の頂点

y = a(x − p)² + q

a ≠ 0 のとき頂点は (p, q)、軸は x = p です。

計算例・使い方を見る

y=2(x−1)²+3 の頂点は (1,3)。

三平方の定理

a² + b² = c²

直角三角形で、c を斜辺とすると成り立ちます。

計算例・使い方を見る

直角を挟む辺が3,4なら斜辺は5。

組合せ

ₙCᵣ = n! / (r!(n − r)!)

n 個から順序を区別せず r 個選ぶ場合の数（0 ≤ r ≤ n）。

計算例・使い方を見る

₅C₂=10。

高校数学Ⅱ・B・C

二項定理

(a + b)ⁿ = Σₖ₌₀ⁿ ₙCₖ aⁿ⁻ᵏbᵏ

n は0以上の整数です。各項の係数は組合せで求めます。

計算例・使い方を見る

(a+b)³ = a³ + 3a²b + 3ab² + b³

余弦の加法定理

cos(α + β) = cosα cosβ − sinα sinβ

2つの角の和の余弦を計算します。

計算例・使い方を見る

cos(60°+30°) = 0

正弦の倍角公式

sin 2θ = 2sinθ cosθ

加法定理で α = β = θ と置いて得られます。

計算例・使い方を見る

θ = 30° なら sin 60° = √3/2

余弦の倍角公式

cos 2θ = cos²θ − sin²θ

cos 2θ = 2cos²θ − 1 = 1 − 2sin²θ とも表せます。

計算例・使い方を見る

θ = 45° なら cos 90° = 0

指数法則

aᵐaⁿ = aᵐ⁺ⁿ

a > 0、m、n は実数とします。

計算例・使い方を見る

2³ × 2⁴ = 2⁷ = 128

対数の底の変換公式

logₐ b = (log꜀ b) / (log꜀ a)

a、b、c > 0、a ≠ 1、c ≠ 1 のとき成立。

計算例・使い方を見る

log₂ 8 = log₁₀ 8 / log₁₀ 2 = 3

等差数列の一般項

aₙ = a₁ + (n − 1)d

初項 a₁、公差 d の等差数列です。

計算例・使い方を見る

初項3、公差2なら a₅ = 11

等比数列の一般項

aₙ = a₁rⁿ⁻¹

初項 a₁、公比 r の等比数列です。

計算例・使い方を見る

初項2、公比3なら a₄ = 54

ベクトルの内積

a · b = |a||b|cosθ

零ベクトルでない2つのベクトルのなす角を θ とします。成分では a₁b₁+a₂b₂。

計算例・使い方を見る

(1,2) · (3,4) = 11

円の方程式

(x − a)² + (y − b)² = r²

中心 (a,b)、半径 r > 0 の円です。

計算例・使い方を見る

中心 (2,−1)、半径3なら (x−2)²+(y+1)²=9

三角関数の加法定理

sin(α + β) = sinα cosβ + cosα sinβ

角の和の正弦を計算できます。角度の単位をそろえて使います。

計算例・使い方を見る

sin(30°+60°)=1。

三角関数の基本恒等式

sin²θ + cos²θ = 1

すべての実数 θ について成立します。

計算例・使い方を見る

sin²30°+cos²30°=1。

対数の積の公式

logₐ(MN) = logₐM + logₐN

a > 0、a ≠ 1、M > 0、N > 0 のとき成立します。

計算例・使い方を見る

log₂(4×8)=log₂4+log₂8=5。

等差数列の和

Sₙ = n(a₁ + aₙ) / 2

初項 a₁、末項 aₙ、項数 n の等差数列の和です。

計算例・使い方を見る

1+2+3+4+5=15。

等比数列の和

Sₙ = a(1 − rⁿ) / (1 − r)

初項 a、公比 r ≠ 1。r = 1 のとき Sₙ = na です。

計算例・使い方を見る

2+4+8+16=30。

高校数学Ⅲ・大学数学の基礎

商の微分法

(f/g)′ = (f′g − fg′) / g²

f、g が微分可能で g ≠ 0 の範囲で成立します。

計算例・使い方を見る

(x / (x+1))′ = 1 / (x+1)²

三角関数の微分

(sin x)′ = cos x, (cos x)′ = −sin x

x はラジアンで表します。

計算例・使い方を見る

(3sin x)′ = 3cos x

指数関数の微分

(eˣ)′ = eˣ

自然指数関数は微分しても同じ関数です。

計算例・使い方を見る

(e²ˣ)′ = 2e²ˣ

対数関数の微分

(ln x)′ = 1/x

x > 0 で成立します。

計算例・使い方を見る

(ln(2x))′ = 1/x （x > 0）

部分積分

∫ f(x)g′(x)dx = f(x)g(x) − ∫ f′(x)g(x)dx

f、g が必要な範囲で微分可能なときに使います。積分定数は最後に加えます。

計算例・使い方を見る

∫ x eˣ dx = (x−1)eˣ + C

置換積分

∫ f(g(x))g′(x)dx = ∫ f(u)du (u=g(x))

変数 u に置き換え、最後に x に戻します。

計算例・使い方を見る

∫ 2x cos(x²)dx = sin(x²) + C

対数の不定積分

∫ (1/x)dx = ln|x| + C

x ≠ 0 の区間で成立します。

計算例・使い方を見る

∫ (3/x)dx = 3ln|x| + C

2×2 行列の逆行列

A⁻¹ = (1/(ad−bc)) [[d,−b],[−c,a]]

A = [[a,b],[c,d]] で ad−bc ≠ 0 の場合です。

計算例・使い方を見る

A=[[2,0],[0,3]] なら A⁻¹=[[1/2,0],[0,1/3]]

偏微分の基本

∂(x²y + y³)/∂x = 2xy

偏微分では、微分する変数以外を定数として扱います。

計算例・使い方を見る

f(x,y)=x²y+y³ なら ∂f/∂y=x²+3y²

等比級数の和

Σₙ₌₀∞ arⁿ = a/(1−r)

|r| < 1 のとき収束します。

計算例・使い方を見る

1 + 1/2 + 1/4 + … = 2

微分可能なら連続

f が x=a で微分可能 ⇒ f は x=a で連続

逆は一般には成り立ちません。たとえば |x| は0で連続ですが微分不可能です。

計算例・使い方を見る

f(x)=x² はすべての実数で微分可能かつ連続

べき関数の微分

d(xⁿ)/dx = nxⁿ⁻¹

整数 n について、式が定義される範囲で成立します。

計算例・使い方を見る

(x³)′=3x²。

積の微分法

(fg)′ = f′g + fg′

f、g が微分可能なときに使います。

計算例・使い方を見る

(x²·sin x)′=2x sin x+x² cos x。

合成関数の微分

(f(g(x)))′ = f′(g(x))g′(x)

合成関数を内側と外側に分けて微分します。

計算例・使い方を見る

(sin(x²))′=2x cos(x²)。

べき関数の不定積分

∫xⁿ dx = xⁿ⁺¹/(n + 1) + C

n ≠ −1。C は積分定数です。実数指数では定義域にも注意します。

計算例・使い方を見る

∫x²dx=x³/3+C。

微積分学の基本定理

∫ₐᵇ f(x)dx = F(b) − F(a)

f が [a, b] で連続、F′ = f のとき成立します。

計算例・使い方を見る

∫₀¹2x dx=1。

2×2 行列の行列式

det [[a, b], [c, d]] = ad − bc

行列式が 0 でなければ、その行列は逆行列を持ちます。

計算例・使い方を見る

det [[1,2],[3,4]]=−2。

一致する公式がありません。別の言葉で検索してください。
