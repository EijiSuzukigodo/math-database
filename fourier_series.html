フーリエ級数を動かして学ぶ

正弦波を重ねると、四角い波が現れる！

1. フーリエ級数とは？

周期的な波を、さまざまな周波数の正弦波・余弦波の和で表す考え方です。ここでは、値が +1 と −1 の間で切り替わる「方形波」を近似します。

Sₙ(x) = (4/π) Σₖ₌₀ⁿ⁻¹ sin((2k+1)x)/(2k+1)

n は足し合わせる正弦波の個数です。最初は sin x だけ、次に sin 3x / 3 を足し、さらに sin 5x / 5 …と増やします。

2. グラフを動かしてみよう

現在は正弦波1個による近似です。

3. どこに注目する？

正弦波の個数を増やすと、平らな部分では方形波に近づきます。一方、ジャンプする点の近くには小さな波打ちと行き過ぎが残ります。これがギブズ現象です。

注意：不連続点 x = 0, ±π, ±2π … では、フーリエ級数は左右の値の平均である 0 に収束します。グラフの赤い方形波も、その点だけ 0 として扱っています。

4. 確認問題

問題1：正弦波を2個使うと、どんな式になりますか？

S₂(x) = (4/π)(sin x + sin 3x / 3) です。

問題2：項数を増やすと、すべての点で +1 または −1 に近づきますか？

いいえ。不連続点では 0 に収束します。また、不連続点の近くではギブズ現象による行き過ぎが見られます。

問題3：なぜ偶数倍の sin 2x や sin 4x がありませんか？

この方形波の対称性から、偶数倍の正弦波の係数は 0 になるためです。
