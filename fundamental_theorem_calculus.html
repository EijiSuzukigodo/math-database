面積関数と微分を目で理解する

微分積分学の基本定理・第1部｜面積の増え方が接線の傾きになる

今日の核心

上のグラフは f(t)=t² と横軸で囲まれた面積、下のグラフはその面積を x の関数として表した F(x)=x³/3 です。

F(x) = ∫₀ˣ t² dt = x³/3　　F′(x) = x² = f(x)

① スライダーを動かしてみよう

青い縦線の位置を変えると、面積・面積関数の点・接線の傾きが同時に変わります。

1.20

上：f(t)=t² と面積

下：F(x)=x³/3 と接線

面積 F(x)0.5760
接線の傾き F′(x)1.4400
元の関数 f(x)1.4400

接線の傾きと f(x) は一致します。

② なぜ一致するのか：証明の考え方

右端を x から x+h に動かしたとき、増える面積は次のように表せます。

F(x+h) − F(x) = ∫ₓˣ⁺ʰ f(t) dt

f が x で連続なら、幅 h が小さくなるにつれ、増えた面積を h で割った値は f(x) に近づきます。したがって、

limₕ→₀ [F(x+h)−F(x)] / h = f(x)

これが微分積分学の基本定理（第1部）です。一般には f が連続 であることが重要な条件です。

厳密な証明を開く

h>0 のとき、区間 [x,x+h] での最小値 mₕ と最大値 Mₕ により、mₕh ≤ ∫ₓˣ⁺ʰ f(t)dt ≤ Mₕh です。h で割り、連続性から mₕ,Mₕ→f(x) を用いると極限は f(x) です。h<0 のときも区間 [x+h,x] を使って同様に示せます。

③ 基本定理の第2部との関係

f の原始関数を G とすると、区間 [a,b] の定積分は G(b)−G(a) で求められます。

∫ₐᵇ f(x) dx = G(b) − G(a)

例：∫₀² x² dx = [x³/3]₀² = 8/3。これは区分求積法で求めた面積と同じ値です。

理解度チェック

f(x)=x² で x=2 のとき、面積関数の接線の傾きはいくつでしょう？

4 です。F′(2)=f(2)=2²=4。面積そのものは F(2)=8/3 なので、面積と傾きは区別しましょう。

④ 基本定理の証明を一歩ずつ

ここでは f が区間上で連続 で、x と x+h がその区間内にあるとします。F(x)=∫₀ˣ f(t)dt と定めます（一般の関数では基準点は a でも構いません）。

ステップ1：面積の差を積分で表す

積分の加法性から、h が正でも負でも次の等式が成立します。

F(x+h) − F(x) = ∫ₓˣ⁺ʰ f(t) dt

h が負なら、積分区間の向きが逆になります。f が負の値を取る場合は符号付き面積として考えます。

ステップ2：増えた面積の平均の高さを考える

h ≠ 0 に対して、差商は次のようになります。

[F(x+h) − F(x)] / h = (1/h) ∫ₓˣ⁺ʰ f(t) dt

これは幅 |h| の区間における f の平均値 です。x に近い場所で f(t) がほぼ f(x) なら、平均値も f(x) に近づきます。

ステップ3：連続性とはさみうちで厳密に示す

任意の ε > 0 に対し、f が x で連続なので、ある δ > 0 が存在し、|t−x| < δ なら |f(t)−f(x)| < ε です。

0 < |h| < δ とすると、x と x+h の間のすべての t についてこの不等式が成り立ちます。したがって、h の符号にかかわらず

| (1/h)∫ₓˣ⁺ʰ [f(t)−f(x)] dt | ≤ (1/|h|)∫ₘᵢₙ₍ₓ,ₓ₊ₕ₎ᵐᵃˣ₍ₓ,ₓ₊ₕ₎ |f(t)−f(x)| dt ≤ ε

つまり、差商と f(x) の差の絶対値は ε 以下になります。ε は任意なので、

lim(h→0) [F(x+h)−F(x)]/h = f(x)。ゆえに F′(x)=f(x)。

区間の端点では片側微分として解釈します。

⑤ 数値で極限を確かめる
