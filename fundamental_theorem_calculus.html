微分積分学の基本定理

定積分と面積の関係

定積分と面積

a<b とし、f は区間 [a,b] で連続とします。f(x)≧0 なら、グラフ y=f(x) と x 軸、2直線 x=a、x=b で囲まれた面積 S は次のように表せます。

S=∫abf(x)dx

区間を n 等分して、各小区間の幅を Δx=b−an、第 k 区間の右端を xk=a+kΔx とします。右端の関数値を高さに使うと、第 k 区間の長方形の面積は f(xk)Δx です。

分割を細かくすると、連続性により各小区間での高さの変化が小さくなり、長方形の面積の和は曲線の下の面積に近づきます。この和の極限が定積分です。

S=limn→∞∑k=1nf(xk)Δx =∫abf(x)dx

グラフが x 軸の下にある部分は、定積分では負として数えます。上下にまたがる領域の面積は、x 軸との交点で区間を分け、各部分の面積を正の値として足します。

第1部　積分で定めた関数の微分

積分の右端を x とし、積分の値を関数 A(x) として表します。

A(x)=∫axf(t)dt

区間の内部では A′(x)=f(x) です。f が非負の場合、これは面積の増加率が右端の高さに等しいことを表します。

証明

右端を x から x+h へ動かすと、定積分の加法性から次の式が成り立ちます。

A(x+h)−A(x)=∫xx+hf(t)dt

x と x+h の間での f の最小値を mh、最大値を Mh とします。h≠0 のとき、差商はその区間における f の平均値なので、次の不等式が成り立ちます。h<0 でも、積分の向きと h の符号がともに逆になるため、同じ不等式が成り立ちます。

mh≦A(x+h)−A(x)h≦Mh

f が連続なので、h→0 のとき最小値も最大値も f(x) に近づきます。はさみうちの原理より、

A′(x)=limh→0A(x+h)−A(x)h=f(x)

第2部　原始関数を使った定積分の計算

F′(x)=f(x) となる原始関数 F を使うと、定積分は次のように求められます。

∫abf(x)dx=F(b)−F(a)

証明

第1部より A′(x)=F′(x) です。したがって A(x)−F(x) は定数です。A(a)=0 なので、その定数は −F(a) です。よって A(b)=F(b)−F(a) となります。
