オイラー線と九点円

みんなの数学データベース｜図を動かして学ぶ

三角形を動かしてオイラー線と九点円を観察

頂点A・B・Cを指やマウスで動かしてください。外心O・重心G・垂心Hは一直線上に並び、OG:GH = 1:2（3点が異なる場合）。九点円の中心NはOHの中点です。

九点円は各辺の中点・各頂点から対辺への垂線の足・頂点と垂心の中点を通ります。

ベクトルで証明する：なぜO・G・Hは一直線上なのか

上の図で三角形を動かして確かめた性質を、今度は式で証明しましょう。高校数学Cのベクトルと内積を使います。

① 外心Oを原点にする

頂点A・B・Cの位置ベクトルを a, b, c とします。Oは外心なので、|a| = |b| = |c| が成立します。

② 垂心Hの位置ベクトルを求める

OH = a + b + c となる点Hを考えます。すると AH = b + c、BC = c − b です。

AH · BC = (b + c) · (c − b)
= |c|² − |b|² = 0

よって AH ⟂ BC。同様に BH ⟂ CA、CH ⟂ AB が成立するので、Hは3本の高さの交点、すなわち垂心です。

③ 重心Gの位置ベクトルを求める

重心の位置ベクトルは3頂点の平均なので、

OG = (a + b + c) / 3

②と比べると OH = 3 OG。したがって、O・G・Hは一直線上にあり、Gは線分OHを1：2に内分します。

OG : GH = 1 : 2
④ 九点円の中心Nも同じ直線上

九点円の中心NはOとHの中点です。したがって ON = OH / 2（ベクトル）で、Nもオイラー線上にあります。また、九点円の半径は外接円の半径の半分です。

注意：正三角形ではO・G・Hが一致するため、3点から1本の直線を一意に決めることはできません。また、頂点が一直線に並ぶと外心が定まりません。

確かめよう：上の図で三角形を二等辺三角形や鈍角三角形に変形し、O・G・Hの並び方がどう変わるか観察してください。
