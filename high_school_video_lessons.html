② 単元を選ぶ

数学Ⅰ

教科書の目次に沿った全5章・全28講。基本の定義から公式の説明、例題、練習問題まで順番に学べます。

第1章 数と式（6講）

  • 多項式の計算 →

    同類項をまとめ、分配法則を用いて多項式を整理します。

  • 乗法公式と因数分解 →

    展開と因数分解は逆向きの操作です。積の形に直すと方程式にも役立ちます。

  • 実数と平方根 →

    数直線上に表せる数を実数といいます。有理数と無理数に分類できます。

  • 根号を含む計算と分母の有理化 →

    根号の積・商と、分母を有理化する計算を学びます。

  • 一次不等式 →

    不等号を含む式の両辺に同じ操作を行い、解の範囲を求めます。

  • 絶対値と場合分け →

    絶対値は数直線上の距離を表すので、正負で場合分けします。

第2章 集合と命題（3講）

  • 集合とその表し方 →

    ある条件を満たすものの集まりを集合といい、要素の列挙や条件で表します。

  • 命題と条件 →

    真偽が定まる文を命題といいます。仮定と結論、逆・裏・対偶を整理しましょう。

  • 必要条件・十分条件と証明 →

    二つの条件の包含関係から、必要条件と十分条件を判断します。

第3章 2次関数（6講）

  • 関数と2次関数のグラフ →

    2次関数のグラフは放物線で、軸と頂点が特徴です。

  • 平方完成とグラフの移動 →

    一般形を平方完成すると、頂点と開く向きが見えてきます。

  • 2次関数の最大値・最小値 →

    定義域が区間のとき、頂点と区間の両端の値を比較します。

  • 2次方程式と解の公式 →

    2次方程式の解は因数分解、平方完成、解の公式で求めます。

  • 判別式とグラフの交点 →

    判別式は実数解の個数、すなわちx軸との交点の個数を決めます。

  • 2次不等式 →

    2次関数の正負をグラフの上下で判断して解きます。

第4章 図形と計量（7講）

  • 三角比の定義 →

    直角三角形の辺の比を使い、正弦・余弦・正接を定義します。

  • 三角比の相互関係 →

    三角比の三つの値は独立ではなく、関係式でつながっています。

  • 鈍角までの三角比 →

    座標平面の単位円を使うと、三角比を0°から180°へ拡張できます。

  • 正弦定理 →

    三角形の辺と向かい合う角の正弦には一定の比があります。

  • 余弦定理 →

    三平方の定理を一般の三角形へ拡張するのが余弦定理です。

  • 三角形の面積 →

    2辺とその間の角が分かれば面積が求まります。

  • 空間図形への応用 →

    三角比は高さ、距離、傾斜などの計測にも使えます。

第5章 データの分析（6講）

  • データの整理と代表値 →

    平均値・中央値・最頻値は、データの中心を異なる方法で表します。

  • 四分位数と箱ひげ図 →

    データの散らばりを四分位範囲で読み取ります。

  • 分散と標準偏差 →

    データの平均からのずれを2乗し、その平均をとると分散です。

  • 散布図と相関係数 →

    2変量の関係を散布図で調べ、相関係数で直線的な傾向を表します。

  • 仮説検定の考え方 →

    仮説と観測結果を比較し、偶然では説明しにくいかを判断します。

  • データの変換と総合演習 →

    すべてのデータに定数を足す・掛けると、平均と分散は規則的に変わります。

数学Ⅱ

教科書の目次に沿った全6章・全36教材。基本事項、公式の導出、例題、練習問題を順番に学べます。

第1章 式と証明

  • 3次式の展開と因数分解 →

    三次の乗法公式を理解し、展開と因数分解を往復する。

  • 二項定理 →

    二項係数を使って高次の展開を整理する。

  • 整式の除法 →

    整式も筆算で除算でき、商と余りに分けられる。

  • 分数式の計算 →

    分母をそろえて整理し、約分の条件も確認する。

  • 恒等式と係数比較 →

    すべての x について成立する等式が恒等式である。

  • 等式の証明と不等式の証明 →

    式変形の根拠を明示し、非負量を利用する。

第2章 複素数と方程式

  • 複素数の導入 →

    実数だけでは解けない方程式を扱うため、虚数単位を導入する。

  • 2次方程式の解と判別式 →

    判別式が負でも、複素数の範囲なら解を表せる。

  • 解と係数の関係 →

    二次方程式の2つの解の和と積を係数から求める。

  • 高次方程式と因数定理 →

    因数定理で三次以上の方程式の解を求める。

第3章 図形と方程式

  • 直線上の点と直線の方程式 →

    2点や傾きから直線の方程式を作る。

  • 平行・垂直な直線 →

    傾きの関係から直線の位置関係を判定する。

  • 2直線の関係と交点 →

    連立一次方程式を解くことで交点を求める。

  • 円の方程式 →

    中心からの距離が一定の点の集合を式で表す。

  • 円と直線の位置関係 →

    中心から直線までの距離と半径を比較する。

  • 軌跡と方程式 →

    条件を満たす点の集合を方程式で表す。

  • 不等式の表す領域 →

    不等式を満たす点の領域を座標平面で理解する。

第4章 三角関数

  • 一般角と弧度法 →

    度数法と弧度法の対応を理解する。

  • 三角関数の定義と性質 →

    単位円の座標から正弦・余弦を定める。

  • 三角関数のグラフ →

    周期、振幅、平行移動からグラフを読む。

  • 三角関数の方程式・不等式 →

    単位円を用いて範囲内の解を探す。

  • 加法定理 →

    角の和や差の三角関数を展開する。

  • 2倍角・半角の公式 →

    加法定理から様々な変形公式を導く。

  • 三角関数の合成 →

    正弦と余弦の和を1つの三角関数で表す。

第5章 指数関数と対数関数

  • 指数の拡張と指数法則 →

    指数を整数・有理数・実数へ拡張する。

  • 指数関数のグラフ →

    底によって増減が変わる指数関数を理解する。

  • 対数の定義と性質 →

    指数と対数は互いに逆の操作である。

  • 対数関数とグラフ →

    対数関数は指数関数の逆関数である。

  • 常用対数と桁数 →

    10を底とする対数で桁数を調べる。

第6章 微分法と積分法

  • 微分係数と導関数 →

    平均変化率の極限から瞬間の変化率を定義する。

  • 導関数の計算 →

    多項式の微分を規則に従って計算する。

  • 接線の方程式 →

    微分係数は曲線上の接線の傾きである。

  • 関数の増減・極値 →

    導関数の符号から増減表を作る。

  • 原始関数と不定積分 →

    微分の逆操作として不定積分を導入する。

  • 定積分と面積 →

    原始関数の端点での差から定積分を求める。

  • 放物線と直線で囲まれる面積 →

    上下の関数の差を積分して面積を求める。
