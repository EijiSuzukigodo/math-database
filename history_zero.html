0（ゼロ）の発見と歴史

位取りの工夫から、数としてのゼロへ

1. 0 がなかったら？

「12」と「102」は、どちらも 1 と 2 を使っています。しかし 0 が入ることで、百の位と一の位を区別できます。0 は、位取り記数法で「その位に数字がない」ことを表す大切な記号です。

2. 位取りを動かしてみよう

百・十・一の位の数字を変えると、数がどう変わるか確かめましょう。

百の位十の位一の位
102

3. 0 の歴史

古代バビロニアでは、位が空いていることを示すための記号が用いられました。マヤ文明でも独自にゼロを表す記号が発達しました。

インドでは、位取りのための記号としてだけでなく、0 を数として扱う考え方が発展しました。7世紀の数学者ブラーマグプタは、0 を含む計算規則を記述しています。その後、インドの数字と計算法はイスラーム世界を経てヨーロッパにも広がりました。

注意：「0 を発見した人」が一人だけいたわけではありません。地域や時代によって、空位の記号と数としての 0 は段階的に発達しました。

4. 考えてみよう

「205」の十の位の 0 を消して「25」にすると、数はいくつ小さくなりますか？

答えを見る

205 − 25 = 180 です。0 は、百の位に 2 があることを示すためにも重要です。
