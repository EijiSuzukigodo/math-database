2次関数の最大値・最小値

定義域が変化する場合

例題のねらい

放物線の軸と定義域の位置関係に注目し、場合分けが必要になる理由を動くグラフで理解する。

1．重要例題

実数 a に対し、2次関数 f(x) = x² − 4x + 5 の、定義域 a ≤ x ≤ a + 2 における最大値と最小値を求めよ。

着眼点

平方完成すると f(x) = (x − 2)² + 1。軸は x = 2。軸に最も近い点で最小、最も遠い点で最大となる。

3．段階的な解説

① 平方完成

f(x) = (x − 2)² + 1

頂点は (2, 1)、軸は x = 2。

② 最小値を求める

定義域が軸の左側なら右端、軸を含めば頂点、右側なら左端で最小となる。

③ 最大値を求める

両端の値を比較する。

f(a + 2) − f(a) = 4(a − 1)

したがって a = 1 を境に、最大値をとる端点が変わる。

4．類題

（1）y = (x − 3)² + 2（a ≤ x ≤ a + 2）の最大値・最小値を求めよ。

解答・解説を見る

軸 x = 3 が区間に入る条件は 1 ≤ a ≤ 3。最小値は a < 1 なら (a − 1)² + 2、1 ≤ a ≤ 3 なら 2、a > 3 なら (a − 3)² + 2。

両端の差は 4(a − 2)。最大値は a < 2 なら (a − 3)² + 2、a = 2 なら 3、a > 2 なら (a − 1)² + 2。

（2）y = −(x − 1)² + 4（a ≤ x ≤ a + 2）の最大値・最小値を求めよ。

解答・解説を見る

上に凸なので、軸に近い点で最大となる。最大値は a < −1 なら 4 − (a + 1)²、−1 ≤ a ≤ 1 なら 4、a > 1 なら 4 − (a − 1)²。

両端の差は −4a。最小値は a < 0 なら 4 − (a − 1)²、a = 0 なら 3、a > 0 なら 4 − (a + 1)²。
