重要例題

2次方程式 x2−2ax+a+2=0 の解が、選んだ条件を満たすような定数 a の範囲を求めよ。

動くグラフ

青：放物線　緑：実数解　橙：頂点　紫：判定に使う点　青い帯：対象区間


条件をグラフで確認する

解法の着眼点と段階的な解説

f(x) = x² − 2ax + a + 2 = (x − a)² − (a − 2)(a + 1)
軸：x = a　　D/4 = (a − 2)(a + 1)
異なる2実数解の条件：a < −1 または a > 2

類題

次の方程式について、指定された配置となる a の範囲を求めよ。

1. x² − 2ax + a + 2 = 0 が異なる2つの解をもち、両方とも 1 より大きい。

解答・解説

D > 0、a > 1、f(1) > 0 が必要十分。f(1) = 3 − a より a < 3。したがって 2 < a < 3。

2. x² − 2ax + a + 2 = 0 の2つの解が −1 の両側にある。

解答・解説

上に開く放物線なので f(−1) < 0 が必要十分。f(−1) = 3a + 3 より a < −1。
