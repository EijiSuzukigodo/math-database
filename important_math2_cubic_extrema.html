3次関数のグラフと極大・極小

重要例題のわかりやすい解説

学習のねらい

導関数の符号からグラフの形を読み取る

接線の傾きと増減の関係を理解し、極大・極小を求める。極値と最大値・最小値の違いにも注意する。

1　重要例題：極大値と極小値

関数 f(x) = x3 − 3x + 2 の極値を求め、グラフの概形をかけ。

① 導関数を求める

f′(x) = 3x2 − 3 = 3(x + 1)(x − 1)

② 増減表を作る

f′(x) = 0 となるのは x = −1, 1。導関数の符号を調べる。

x…−1…1…
f′(x)＋0−0＋
f(x)↗4↘0↗

③ 極値を求める

極大値 4（x = −1）
極小値 0（x = 1）

2　動く教材：接線と導関数

f(x) = x3 − 3ax + b の a, b と接点 t を変えよう。上の図は関数と接線、下の図は導関数。縦の破線は同じ x 座標を示す。

青：関数　橙：接線　緑：導関数

連動する増減表

a = 0 では x = 0 で接線が水平になるが、導関数の符号は変わらないため極値はない。a が負の場合も極値はない。

3　重要例題：区間内の最大値と最小値

f(x) = x3 − 3x + 2（−1 ≤ x ≤ 3）の最大値・最小値を求めよ。

区間の両端と内部の停留点を比較する。f(−1)=4、f(1)=0、f(3)=20。

最大値 20（x=3）
最小値 0（x=1）

極大値が区間内の最大値になるとは限らない。

4　類題

① f(x)=x3−12x の極値を求めよ。

解答・解説

f′(x)=3(x+2)(x−2)。符号は ＋、−、＋。極大値16（x=−2）、極小値−16（x=2）。

② f(x)=2x3−3x2 の極値を求めよ。

解答・解説

f′(x)=6x(x−1)。極大値0（x=0）、極小値−1（x=1）。

③ f(x)=x3−x の極値を求めよ。

解答・解説

f′(x)=3x2−1。停留点は x=±√33。符号は ＋、−、＋。

極大値 2√39（x=−√33）
極小値 −2√39（x=√33）
