3次方程式の実数解の個数

重要例題のわかりやすい解説

学習のねらい

方程式の実数解をグラフの交点として考える

極大値・極小値と水平線の位置関係を利用し、異なる実数解の個数を判断する。

1　重要例題

実数 k の値によって、方程式 x3 − 3x = k の異なる実数解の個数を調べよ。

① 関数の増減を調べる

f(x) = x3 − 3x
f′(x) = 3(x + 1)(x − 1)
x…−1…1…
f′(x)＋0−0＋
f(x)↗2↘−2↗

② 水平線 y = k との交点を考える

極大値は 2、極小値は −2。各増減区間で水平線との交点を数える。

k の範囲異なる実数解
−2 < k < 23個
k = ±22個
k < −2 または k > 21個

k = 2 のとき (x + 1)2(x − 2) = 0。重解 −1 は1個として数える。

2　動く教材：水平線と実数解

青い3次関数と橙色の水平線の交点を観察しよう。a を変えると極値も変化する。

y = x3 − 3ax　と　y = k

3　一般化

a > 0 なら、極大値は 2a√a、極小値は −2a√a。水平線がその間にあれば3個、等しければ2個、外側なら1個。a ≤ 0 では関数は単調増加なので常に1個。a = 0, k = 0 のときは3重解だが異なる実数解は1個である。

4　類題

問1　x3 − 12x = k の異なる実数解が3個となる k の範囲を求めよ。

解答・解説

導関数は 3(x + 2)(x − 2)。極大値16、極小値−16。よって −16 < k < 16。

問2　x3 − 3x + 1 = 0 の異なる実数解の個数を求めよ。

解答・解説

x3 − 3x = −1 と変形する。−2 < −1 < 2 より3個。

問3　x3 + 3x = k の異なる実数解の個数を求めよ。

解答・解説

導関数 3x2 + 3 は常に正。左右の極限はそれぞれ負・正の無限大なので、任意の実数 k に対して1個。
