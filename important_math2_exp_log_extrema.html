数学Ⅱ ／ 指数関数と対数関数

指数関数と対数関数の最大・最小

重要例題のわかりやすい解説

学習のねらい

増減と置換を使って最大値・最小値を求める

底が1より大きい場合と小さい場合を比較し、定義域に注意して考える。指数式や対数式を2次関数に置き換える方法を身につける。

1　重要例題：指数関数の最大・最小

y = (12)x （−1 ≤ x ≤ 2）の最大値・最小値を求めよ。

解き方

0 < 12 < 1 なので、この関数は単調に減少する。したがって左端で最大、右端で最小となる。

最大値 2（x = −1）
最小値 14（x = 2）

2　重要例題：対数関数の最大・最小

y = log2 x （12 ≤ x ≤ 4）の最大値・最小値を求めよ。

底が1より大きいので単調に増加する。定義域の左端で最小、右端で最大となる。

最大値 2（x = 4）
最小値 −1（x = 12）

動く教材：底と定義域を変える

青：関数全体　緑：指定された定義域　赤：最大点　橙：最小点

対数関数の定義域は x > 0。底 a は正で1ではない。底が1より小さいと最大点と最小点の左右が逆になる。

3　重要例題：置換による最大・最小

y = 4x − 4・2x + 3 （0 ≤ x ≤ 2）の最大値と最小値を求めよ。

解き方

t = 2x とおくと、1 ≤ t ≤ 4 である。4x = t² より

y = t² − 4t + 3 = (t − 2)² − 1

頂点 t = 2 は定義域に含まれる。端点の値は y(1) = 0、y(4) = 3。

最大値 3（x = 2）
最小値 −1（x = 1）

動く教材：指数関数と置換後の2次関数

t = 2ˣ の範囲は 1 ≤ t ≤ 4。頂点が範囲内にあるか確かめ、両端の値も比較する。

4　対数式の置換

y = (log₂ x)² − 2 log₂ x + 3 （12 ≤ x ≤ 8）の最大値・最小値を求めよ。

t = log₂ x とおくと −1 ≤ t ≤ 3。y = (t − 1)² + 2 より、最小値は2（t = 1、x = 2）。両端で y = 6 となるので、最大値は6（x = 12, 8）。

5　類題

問1　y = 3ˣ（−2 ≤ x ≤ 1）の最大値・最小値。

解答・解説

増加関数なので最大値3（x = 1）、最小値19（x = −2）。

問2　y = log12 x（14 ≤ x ≤ 8）の最大値・最小値。

解答・解説

減少関数なので最大値2（x = 14）、最小値 −3（x = 8）。

問3　y = 9ˣ − 6・3ˣ + 5（0 ≤ x ≤ 2）の最大値・最小値。

解答・解説

t = 3ˣ とおくと 1 ≤ t ≤ 9。y = (t − 3)² − 4。最小値 −4（x = 1）、最大値32（x = 2）。
