学習のねらい

2つの三角関数を1つにまとめる

加法定理を利用して振幅と位相を求め、最大値・最小値や方程式に応用します。

1　基本公式

a, b が同時に0でないとき、R = √(a²＋b²) とし、cos α = a/R、sin α = b/R を満たす角 α をとる。

a sin x ＋ b cos x = R sin(x ＋ α)

右辺を加法定理で展開すると、R cos α sin x ＋ R sin α cos x となり、元の式に一致します。a = b = 0 のときは恒等的に0です。

2　重要例題

y = √3 sin x ＋ cos x を合成し、0 ≤ x ＜ 2π で最大値・最小値とそのときの x を求めよ。

解き方

① R = √(3＋1) = 2
② cos α = √3/2、sin α = 1/2 より α = π/6
③ y = 2 sin(x＋π/6)

最大値 2：x = π/3
最小値 −2：x = 4π/3

振幅が2になり、正弦曲線が左へ π/6 だけ移動します。

3　動く教材：2つの波を重ねる

a、b を変えると、合成した波と係数ベクトルが変わります。自動再生では係数ベクトルが回転します。

━ a sin x　━ b cos x　━ 合成波

係数ベクトルと位相 α

横成分 a、縦成分 b、ベクトルの長さ R、正の横軸からの角度 α が合成公式に対応します。

4　方程式への応用

√3 sin x ＋ cos x = 1（0 ≤ x ＜ 2π）を解け。

2 sin(x＋π/6) = 1 より sin(x＋π/6) = 1/2。
π/6 ≤ x＋π/6 ＜ 13π/6 に注意すると、x＋π/6 = π/6, 5π/6。

答：x = 0, 2π/3

5　類題

① sin x ＋ cos x を合成せよ。

解答・解説

R = √2、α = π/4 より √2 sin(x＋π/4)。

② −sin x ＋ √3 cos x の最大値と最小値を求めよ。

解答・解説

2 sin(x＋2π/3) に合成できるので最大値2、最小値−2。

③ sin x − cos x = 0（0 ≤ x ＜ 2π）を解け。

解答・解説

√2 sin(x−π/4) = 0 より x = π/4, 5π/4。
