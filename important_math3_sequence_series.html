数学Ⅲ ／ 極限

数列の極限と無限級数

重要例題のわかりやすい解説

例題のねらい

数列の極限と部分和の極限を区別する

数列の各項と、初項から第 n 項までの和を動くグラフで比較し、無限等比級数が収束する条件を理解する。

重要例題

無限等比級数 \(1+\frac12+\frac14+\frac18+\cdots\) の和を求めよ。

第 n 項までの和を求める

\[S_n=\frac{1-(\frac12)^n}{1-\frac12}=2\left\{1-\left(\frac12\right)^n\right\}\]

極限を求める

\[\lim_{n\to\infty}\left(\frac12\right)^n=0\]
\[\therefore\quad \sum_{n=1}^{\infty}\left(\frac12\right)^{n-1}=2\]

各項は 0 に近づきますが、部分和は 2 に近づきます。二つの極限は異なるものです。

動く教材：各項と部分和の変化

\[a_n=r^{n-1},\qquad S_n=1+r+\cdots+r^{n-1}\]

公比と項数を変え、上の図の各項と下の図の部分和を比較してください。縦軸は図ごとに自動調整されます。

数列の各項 aₙ

部分和 Sₙ

青い点は各項、橙色の点は部分和、緑の破線は収束先を表します。

収束と発散の条件

\[\sum_{n=1}^{\infty} ar^{n-1}=\frac{a}{1-r}\quad (|r|<1)\]

初項が 0 でない場合、公比の絶対値が 1 未満なら収束し、それ以外なら発散します。初項が 0 の場合はすべての項が 0 です。

なお、一般の級数では各項が 0 に近づくことだけでは収束は保証されません。例えば調和級数 \(1+\frac12+\frac13+\cdots\) は発散します。

類題

問1

\(3+1+\frac13+\cdots\) の和を求めよ。

解答・解説

公比は \(\frac13\) なので \(\frac{3}{1-\frac13}=\frac92\)。

問2

\(2-1+\frac12-\frac14+\cdots\) の和を求めよ。

解答・解説

公比は \(-\frac12\) なので \(\frac{2}{1+\frac12}=\frac43\)。

問3

\(1-1+1-1+\cdots\) は収束するか。

解答・解説

部分和が 1 と 0 を交互にとるため発散する。
