不等式の証明を図とグラフで理解する

数学Ⅱ ｜ 式と証明

2つの数 a と b を動かし、不等式がいつも成り立つ理由を図とグラフで確かめましょう。

a² + b² ≥ 2ab

① 数直線で差を確認

差 a − b を数直線で表します。差の2乗は、負になりません。

② グラフで確かめる

横軸 x = a − b、縦軸 y = (a − b)² です。点を動かしてもグラフは横軸より下に行きません。

③ 式による証明

実数 a, b に対して、2乗は必ず0以上なので、

(a − b)² ≥ 0

左辺を展開すると、

a² − 2ab + b² ≥ 0

両辺に 2ab を加えて、

a² + b² ≥ 2ab

等号成立条件：a = b のとき、かつそのときに限ります。

考えてみよう

a と b を同じ値にすると、差の2乗はどうなるでしょうか。負の値にしても成立することを確かめてください。

※ a, b は −5 から 5 の範囲で変更できます。数学的な証明はすべての実数に対して成立します。
