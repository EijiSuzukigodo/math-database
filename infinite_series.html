無限級数とその収束

図とグラフで学ぶ、無限に足すということ

1. 無限級数とは？

次の数を順番に足してみましょう。

1 + 1/2 + 1/4 + 1/8 + … = 2

最初の n 項までの和を 部分和 Sₙ といいます。項を増やすと、部分和は2に近づいていきます。

2. 部分和を動かしてみよう

Sₙ = 2(1 − (1/2)ⁿ)

青い点は部分和、赤い線は極限値2です。

3. 面積で考えてみよう

長方形の幅を、1、1/2、1/4、…と足していくと、全体の幅2に近づきます。

どれだけ項を増やしても、有限個の和は2より小さくなります。しかし、2との差は限りなく0に近づきます。

4. 数学的な説明

初項1、公比1/2の等比数列の最初のn項の和は

Sₙ = (1 − (1/2)ⁿ) / (1 − 1/2) = 2(1 − (1/2)ⁿ)

n → ∞ のとき (1/2)ⁿ → 0 なので、Sₙ → 2 です。これを「無限級数が2に収束する」といいます。

一般に、初項 a、公比 r の等比級数は、|r| < 1 のとき a/(1−r) に収束します（a が0でない場合、|r| ≥ 1 では収束しません）。

5. 確認問題

1 + 1/3 + 1/9 + 1/27 + … の和はいくつでしょうか。

初項1、公比1/3なので、和は 1/(1−1/3) = 3/2 です。
