ラグランジュの未定乗数法

円周上の最大・最小を、等高線と接線で見つけよう

① 円周上の点を動かそう

制約条件 x² + y² = 4（半径2の円）の上で、f(x,y) = x + y の値を調べます。青い直線は等高線 x + y = c です。点を動かすと、その点を通る等高線も動きます。

緑色の点が最大、紫色の点が最小です。青い等高線が円に接するとき、極値になります。

② なぜ接すると極値なのか

等高線の法線ベクトルは ∇f = (1,1)、制約曲線 g(x,y)=x²+y²−4=0 の法線ベクトルは ∇g = (2x,2y) です。

円と等高線が接するとき、2つの法線ベクトルが平行になるため、ある実数 λ を使って

∇f = λ∇g

と表せます。これがラグランジュの未定乗数法の基本です。

③ 計算で確かめる

今回の例では、1 = 2λx、1 = 2λy なので x = y です。これを x²+y²=4 に代入すると、

(x,y) = (√2,√2), (−√2,−√2)

したがって、円周上の最大値は 2√2 ≈ 2.828、最小値は −2√2 ≈ −2.828 です。

円周は閉じた有界な集合で、f は連続なので最大値と最小値が存在します。上の2点がその候補であり、値を比べると結論が得られます。

確認問題：f(x,y)=x−y なら最大になる点は？

∇f=(1,−1) より x=−y。制約条件から (√2,−√2) で最大値 2√2 です。

注意：∇g ≠ 0 が必要です。この円周では常に ∇g ≠ 0 です。一般には、未定乗数法で得た候補を比較して最大・最小を判定します。
