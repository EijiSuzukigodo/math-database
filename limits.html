関数の極限を動かして学ぶ

左右から近づく様子をグラフと数値で確かめよう

1．観察する関数を選ぶ

青い点は左から、赤い点は右から x = 0 に近づきます。点線は x = 0 です。

2．極限の意味

関数の極限とは、x がある値に限りなく近づくとき、f(x) がどのような値に近づくかを考えるものです。x がその値と等しいときの関数値とは、区別して考えます。

limx→a f(x) = L

有限な両側極限が存在するためには、左側極限と右側極限が同じ値 L に近づく必要があります。

例① なぜ sin(x)/x の極限は1？

x はラジアンで測ります。0 < x < π/2 で sin x < x < tan x より cos x < sin x / x < 1。x→0⁺ で両端が1に近づくので、はさみうちの原理から右側極限は1です。左側も sin(x)/x が偶関数であることから同じです。

例② なぜ左右の極限が違うと極限は存在しない？

符号関数 f(x) = −1 (x<0), 1 (x>0) は、左から近づくと−1、右から近づくと1です。近づく方向によって結果が違うので、x→0 の両側極限は存在しません。

例③ 無限大への発散はどういう意味？

f(x)=1/x は x→0⁺ で +∞、x→0⁻ で −∞ に発散します。これは有限の値に収束することではありません。グラフの表示範囲外に出る点は、数値表示で確かめてください。

3．考えてみよう

① x を0に近づけたとき、sin(x)/x の値はどう変わりますか？

② 符号関数は x=0 での値を決めれば、両側極限が存在するようになりますか？

③ 1/x について、右からと左からで値はどのように変わりますか？

答えを表示

① 1に近づきます。② なりません。左右の極限が異なるためです。③ 右からは+∞、左からは−∞に発散します。
