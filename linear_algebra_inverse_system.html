2本の直線のグラフ

青：第1式　赤：第2式　●：交点（存在する場合）

係数を変えてみよう

第1式：x + y = 4
第2式：x − y = 0

各係数は −5 ～ 5、0.5刻みで調整できます。

計算結果

係数行列 A = [[1, 1], [1, −1]]
行列式 det(A) = ad − bc = −2

解は1組だけあります。

交点 (x, y) = (2, 2)

なぜ行列式が大切なの？

連立一次方程式 ax + by = e、cx + dy = f を行列で表すと、A(x, y)ᵀ = (e, f)ᵀ です。

det(A) ≠ 0 なら逆行列 A⁻¹ が存在し、解は (x, y)ᵀ = A⁻¹(e, f)ᵀ と求められます。このとき直線は1点で交わります。

det(A) = 0 なら逆行列は存在しません。2本の直線が平行で交わらない場合も、重なって解が無数にある場合もあります。つまり、行列式が0という情報だけでは、解がないか無数にあるかは決まりません。

※ 係数が両方0の式（例：0x + 0y = 0）は直線ではありません。グラフには描かず、計算結果で判定します。
