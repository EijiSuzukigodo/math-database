分散と標準偏差を計算して活用する

偏差・分散・標準偏差の意味を理解し、データの変換や散らばりの比較に活用しましょう。

1　偏差と分散

平均値からどれくらい離れているかを表す量を偏差といいます。偏差の合計は0になるので、偏差を2乗して平均をとったものを分散といいます。

偏差 = xi − x̄
分散 s² = 偏差の2乗の和データの個数 n = Σ (xᵢ − x̄)²n

標準偏差

分散の正の平方根を標準偏差といいます。標準偏差の単位は元のデータと同じです。

標準偏差 s = √(s²)

分散の計算公式

s² = Σ xᵢ²n − (x̄)²

つまり「2乗の平均 − 平均の2乗」で求められます。

2　例題と解説

例題：データ 2，4，6 の分散と標準偏差を求めましょう。

① 平均値は (2＋4＋6) ÷ 3 = 4

② 偏差は −2，0，2

③ 偏差の2乗は 4，0，4

④ 分散は (4＋0＋4) ÷ 3 = 8/3

⑤ 標準偏差は √(8/3) ≈ 1.633

4　データの変換

各データ x を y = ax + b に変換すると、平均値・分散・標準偏差は次のように変わります。

変換後の平均 = a x̄ + b
変換後の分散 = a² s²
変換後の標準偏差 = |a| s

例：2，4，6 をそれぞれ2倍して3を足すと、7，11，15 になります。

元の平均は4 → 新しい平均は11。元の分散は8/3 → 新しい分散は32/3。元の標準偏差は√(8/3) → 新しい標準偏差は2√(8/3)。

5　総合演習

問題：データ 1，3，5，7 の平均値・分散・標準偏差を求めましょう。さらに各データを3倍したときの分散を求めましょう。

解答と途中計算を表示

平均 = (1＋3＋5＋7)÷4 = 4。偏差は −3，−1，1，3 なので、分散 = (9＋1＋1＋9)÷4 = 5。標準偏差 = √5。3倍した後の分散は 3²×5 = 45。
