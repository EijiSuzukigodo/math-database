乗法公式と因数分解

数学I ／ 第1章 数と式 ／ 乗法公式・因数分解・発展公式

授業のねらい

展開と因数分解を往復できるようにする

乗法公式は、積の形を和の形へ直すための公式です。因数分解は、その逆に和の形を積の形へ直す操作です。

このページでは、教科書風に 公式 → 例題 → 練習 → 発展 の流れで整理します。

1 乗法公式

( a + b ) 2 = a 2 + 2 a b + b 2 ( a − b ) 2 = a 2 − 2 a b + b 2 ( a + b ) ( a − b ) = a 2 − b 2 ( x + a ) ( x + b ) = x 2 + ( a + b ) x + a b ( a x + b ) ( c x + d ) = a c x 2 + ( a d + b c ) x + b d
見方のポイント
展開では、分配法則を使って一つずつ掛けます。公式を覚えるだけでなく、どうしてそうなるかも確認しましょう。
例1 ( x + 3 ) 2 = x 2 + 6 x + 9
例2 ( 2 x − 5 ) 2 = 4 x 2 − 20 x + 25
例3 ( x + 4 ) ( x − 4 ) = x 2 − 16
例4 ( 3 x + 1 ) ( 2 x − 5 ) = 6 x 2 − 13 x − 5
例題 1

( x + 2 ) ( x 2 − 2 x + 4 ) を展開する。

これは立方和の公式につながる形です。

( x + 2 ) ( x 2 − 2 x + 4 ) = x 3 − 2 x 2 + 4 x + 2 x 2 − 4 x + 8 = x 3 + 8

2 因数分解の基本

因数分解では、まず 共通因数 がないかを見ます。その後、公式が使える形かどうかを考えます。

A 共通因数をくくり出す

A B + A C = A ( B + C )
例題 2

6 x 2 − 9 x を因数分解する。

6 x 2 − 9 x = 3 x ( 2 x − 3 )

B 因数分解の公式

a 2 + 2 a b + b 2 = ( a + b ) 2 a 2 − 2 a b + b 2 = ( a − b ) 2 a 2 − b 2 = ( a + b ) ( a − b ) x 2 + ( a + b ) x + a b = ( x + a ) ( x + b ) a c x 2 + ( a d + b c ) x + b d = ( a x + b ) ( c x + d )
例5 x 2 + 10 x + 25 = ( x + 5 ) 2
例6 9 x 2 − 24 x + 16 = ( 3 x − 4 ) 2
例7 4 x 2 − 25 = ( 2 x + 5 ) ( 2 x − 5 )
例8 x 2 + 7 x + 12 = ( x + 3 ) ( x + 4 )
例題 3

3 x 2 + 7 x + 2 を因数分解する。

( a x + b ) ( c x + d ) の形を意識して考えます。

3 x 2 + 7 x + 2 = ( 3 x + 1 ) ( x + 2 )

実際に展開すると 3 x 2 + 6 x + x + 2 = 3 x 2 + 7 x + 2 となり確かめられます。

3 式の特徴に着目した工夫

そのままでは公式が見えなくても、順序を入れ替える、1つの文字について整理する と因数分解できることがあります。

例題 4

x 2 − y 2 − 2 y − 1 を因数分解する。

y 2 + 2 y + 1 = ( y + 1 ) 2 に注目します。

x 2 − y 2 − 2 y − 1 = x 2 − ( y + 1 ) 2 = ( x + y + 1 ) ( x − y − 1 )
例題 5

2 x 2 + 7 x y + 6 y 2 + 5 x + 7 y − 3 を因数分解する。

x について整理すると 2次式になります。

2 x 2 + ( 7 y + 5 ) x + ( 6 y 2 + 7 y − 3 )

これを因数分解すると

2 x 2 + 7 x y + 6 y 2 + 5 x + 7 y − 3 = ( x + 2 y + 3 ) ( 2 x + 3 y − 1 )

5 練習問題

  1. ( x − 5 ) 2 を展開しなさい。
  2. 4 x 2 − 9 を因数分解しなさい。
  3. x 2 + 8 x + 16 を因数分解しなさい。
  4. 2 x 2 − 5 x − 3 を因数分解しなさい。
  5. a 3 − 64 を因数分解しなさい。
解答を見る
  1. x 2 − 10 x + 25
  2. ( 2 x − 3 ) ( 2 x + 3 )
  3. ( x + 4 ) 2
  4. ( 2 x + 1 ) ( x − 3 )
  5. ( a − 4 ) ( a 2 + 4 a + 16 )

6 まとめ

  • 展開は、積の形を和の形へ直す操作。
  • 因数分解は、その逆に和の形を積の形へ直す操作。
  • 因数分解では、まず共通因数、次に公式を確認する。
  • 式を整理したり見方を変えたりすると、因数分解できることがある。
  • 3次式でも、公式を使うと見通しよく計算できる。
