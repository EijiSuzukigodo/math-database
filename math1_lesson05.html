授業のねらい

不等号の向きに注意して、解の範囲を求める

不等式は、数の大小関係を表す式です。等式と同じように式変形できますが、負の数を掛けたり割ったりしたときは不等号の向きが逆になります。数直線で確かめながら学びましょう。

1 不等式の意味と性質

A 不等式

2つの数や式の大小関係を、不等号を使って表した式を不等式といいます。

a < b , a > b , a ≤ b , a ≥ b

たとえば「ある数の3倍から4を引いた数は5より小さい」は、次のように表せます。

3 x − 4 < 5

B 不等式の性質

実数について、次が成り立ちます。

a < b   ⟹   a + c < b + c
a < b ,   c > 0   ⟹   a c < b c
a < b ,   c < 0   ⟹   a c > b c
なぜ負の数を掛けると向きが逆になるのか

たとえば 2 < 5 ですが、両辺に − 3 を掛けると − 6 > − 15 です。数直線では、負の数を掛けると左右の順序が入れ替わるためです。

なお、両辺を0で割ることはできません。

2 一次不等式の解き方

A 移項して解く

不等式を成り立たせる文字の値の全体を不等式の解といいます。計算の順序は、一次方程式とほぼ同じです。

例題 1

3 x + 5 < 14 を解きましょう。

3 x + 5 < 14
3 x < 9
x < 3

3は正なので、両辺を3で割っても不等号の向きは変わりません。

例題 2

− 4 x − 2 ≤ 30 を解きましょう。

− 4 x − 2 ≤ 30
− 4 x ≤ 32
x ≥ − 8

−4で割ったので不等号を逆向きにします。

B 分母を払う

例題 3

2 x + 1 3 > x − 2 2 を解きましょう。

両辺に正の数6を掛けます。

2 ( 2 x + 1 ) > 3 ( x − 2 )
4 x + 2 > 3 x − 6
x > − 8
計算のポイント　負の数で割る場合だけでなく、移項するときにも符号を正確に変えましょう。

3 解を数直線に表す

不等式の解は1つの数とは限りません。数直線の範囲で表すと分かりやすくなります。

例： x < 3 の場合

例： x ≥ − 2 の場合

「<」「>」は端点を含まないので白丸、「≤」「≥」は端点を含むので黒丸で表します。

4 連立一次不等式

複数の不等式を同時に満たす範囲（共通部分）を求めます。

例題 4

次の連立不等式を解きましょう。

{ 2 x + 1 > 5 3 x − 4 ≤ 8

上の不等式は x > 2 、下の不等式は x ≤ 4 です。両方を満たすのは

2 < x ≤ 4
例題 5

− 1 ≤ 2 x + 3 < 9 を解きましょう。

− 1 ≤ 2 x + 3 < 9
− 4 ≤ 2 x < 6
− 2 ≤ x < 3

3つの項をまとめて計算する場合も、すべての項に同じ操作をします。

注意：不等式の向きを取り違えると、共通部分がなくなったり、求める範囲が逆になります。

5 練習問題

  1. 5 x − 8 ≤ 22 を解きなさい。
  2. − 3 x + 7 > 19 を解きなさい。
  3. x − 1 2 ≤ 2 x + 5 3 を解きなさい。
  4. { x + 3 > 1 2 x − 1 < 7 を解きなさい。
  5. 1 < 3 x + 4 ≤ 13 を解きなさい。
解答・途中計算を見る
  1. 5 x ≤ 30 より x ≤ 6 。
  2. − 3 x > 12 より、負の数で割って x < − 4 。
  3. 両辺に6を掛けて 3 x − 3 ≤ 4 x + 10 。したがって x ≥ − 13 。
  4. それぞれ x > − 2 、 x < 4 より − 2 < x < 4 。
  5. 各項から4を引き − 3 < 3 x ≤ 9 。よって − 1 < x ≤ 3 。
