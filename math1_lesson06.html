不等式を身近な問題や絶対値に活用する

文章から条件を読み取り、不等式を立てて解きます。また絶対値を含む方程式・不等式では、数直線上の距離に着目し、必要に応じて場合分けします。

1 一次不等式の文章題

A 料金と個数の問題

例題 1

1冊240円のノートを買います。送料が360円かかり、予算は3000円以内です。何冊まで買えますか。

ノートの冊数を x 冊とすると

240 x + 360 ≤ 3000

送料を移項して

240 x ≤ 2640 x ≤ 11

冊数は0以上の整数なので、最大11冊です。

B 距離と速さの問題

例題 2

駅までの道のりは1500mです。歩く速さが毎分75mのとき、18分以内に着くには何m以上の地点まで走っておく必要がありますか。ただし走る速さは毎分150mとします。

走る距離を x mとすると、所要時間は

x 150 + 1500 − x 75 ≤ 18

両辺に150を掛けると

x + 2 ( 1500 − x ) ≤ 2700 − x ≤ − 300 x ≥ 300

したがって、300m以上走る必要があります。

2 条件を同時に満たす数

文章題では、価格、個数、時間など複数の条件から連立不等式を立てることがあります。整数の条件も忘れないようにしましょう。

例題 3

ある整数 n は、3倍して5を加えると20以上、4倍して2を引くと30未満になります。このような整数 n をすべて求めましょう。

{ 3 n + 5 ≥ 20 4 n − 2 < 30

それぞれを解くと

n ≥ 5 , n < 8

よって 5 ≤ n < 8 を満たす整数は、5、6、7 です。

3 絶対値を含む方程式・不等式

絶対値 | x − a | は、数直線で x と a の間の距離を表します。

| x | = { x ( x ≥ 0 ) − x ( x < 0 )

A 絶対値の方程式

例題 4

| 2 x − 1 | = 3 を解きましょう。

絶対値が3になるのは、中の数が3または−3のときです。

2 x − 1 = 3 または 2 x − 1 = − 3

したがって、 x = 2 , − 1 です。

B 絶対値の不等式

| x | < c ⟺   − c < x < c | x | > c ⟺   x < − c   または   x > c ( c > 0 )
例題 5

| x − 4 | ≤ 3 を解きましょう。

4からの距離が3以下であることを意味するので

− 3 ≤ x − 4 ≤ 3

各項に4を加えると

1 ≤ x ≤ 7

端点を含む区間が解です。

4 場合分けを使って解く

絶対値の中に文字があるときは、中身が0以上か負かで分けて考えます。求めた解は最後にその場合の条件と照合しましょう。

例題 6

| x − 4 | ≤ 2 x を解きましょう。

① x ≥ 4 のとき

| x − 4 | = x − 4 なので

x − 4 ≤ 2 x ⟹ x ≥ − 4

条件 x ≥ 4 と合わせ、 x ≥ 4 。

② x < 4 のとき

| x − 4 | = 4 − x なので

4 − x ≤ 2 x ⟹ x ≥ 4 3

条件 x < 4 と合わせ、 4 3 ≤ x < 4 。

2つの範囲を合わせて、求める解は

x ≥ 4 3
確認のポイント　右辺が負の場合は、絶対値が0以上であることと矛盾することがあります。場合分けでは必ず、最初の条件に戻って確かめましょう。

5 練習問題

  1. 1本180円の鉛筆を買い、包装代120円を払います。合計を1200円以内にするには最大何本買えますか。
  2. 整数 n が 2 n + 1 > 7 、 3 n − 2 ≤ 16 を満たすとき、 n をすべて求めなさい。
  3. | x − 3 | = 5 を解きなさい。
  4. | 2 x + 1 | < 7 を解きなさい。
  5. | x − 2 | ≥ 4 を解きなさい。
解答・解説を見る
  1. 180 x + 120 ≤ 1200 より x ≤ 6 。最大 6本。
  2. n > 3 、 n ≤ 6 。よって 4、5、6。
  3. x − 3 = 5 または x − 3 = − 5 。よって x = 8 , − 2 。
  4. − 7 < 2 x + 1 < 7 より − 4 < x < 3 。
  5. x − 2 ≤ − 4 または x − 2 ≥ 4 。よって x ≤ − 2 または x ≥ 6 。
