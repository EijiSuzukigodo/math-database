集合を理解する

教科書の構成を参考に、定義・図・例題・練習問題の順に学習できます。数式はオフラインでも読める形で表示します。

集合とその表し方

「5以下の正の整数の集まり」のように、含まれるものがはっきり決まる集まりを集合といいます。集合に属する一つ一つのものを要素といいます。

A = { 1 , 2 , 3 , 4 , 5 } , 3 ∈ A , 8 ∉ A

集合は、要素を並べて書く方法と、条件で表す方法があります。

B = { 2 , 4 , 6 , 8 } = { x ∣ x  は  8  以下の正の偶数 }
例題：条件で表された集合
C = { x ∣ x  は自然数 ,   1 ≤ x < 7 ,   3 ∣ x }

3の倍数は3と6だから、

C = { 3 , 6 }
練習1
  1. { x ∣ x  は  12  の正の約数 } を要素を書き並べて表しなさい。
  2. D = { 2 , 4 , 6 , 8 } に対し、 4 ∈ D と 5 ∈ D の真偽を答えなさい。
解答・詳しい解説を見る
  1. { 1 , 2 , 3 , 4 , 6 , 12 } 。正の約数を小さい順に列挙します。
  2. 4 ∈ D は真、 5 ∈ D は偽。5は集合の要素ではありません。

部分集合・空集合・集合の相等

集合 A のすべての要素が集合 B に属するとき、 A は B の部分集合です。

A ⊆ B   ⟺   ( x ∈ A ⇒ x ∈ B )

要素を一つも持たない集合を空集合といい、 ∅ と書きます。集合が等しいとは、互いに相手の部分集合になることです。

A = B   ⟺   ( A ⊆ B   かつ   B ⊆ A )
例題：部分集合を求める

A = { 1 , 2 } の部分集合は次の4つです。

∅ ,   { 1 } ,   { 2 } ,   { 1 , 2 }

要素が n 個の有限集合の部分集合は、各要素を「選ぶ・選ばない」の2通りから考えて 2 n 個です。

練習2
  1. A = { a , b , c } の部分集合はいくつありますか。
  2. A = { 1 , 3 } ,   B = { 1 , 2 , 3 } のとき、 A ⊆ B が成り立つか答えなさい。
解答・詳しい解説を見る
  1. 2 3 = 8 個です。空集合と集合自身も含みます。
  2. 成り立ちます。Aの1と3はいずれもBに属します。

共通部分と和集合

両方に属する要素の集合が共通部分、少なくとも一方に属する要素の集合が和集合です。

A ∩ B = { x ∣ x ∈ A   かつ   x ∈ B }
A ∪ B = { x ∣ x ∈ A   または   x ∈ B }
例題：共通部分と和集合

A = { 1 , 2 , 3 , 5 } 、 B = { 2 , 4 , 5 , 6 } のとき、

A ∩ B = { 2 , 5 } , A ∪ B = { 1 , 2 , 3 , 4 , 5 , 6 }
練習3
  1. A = { 1 , 3 , 5 , 7 } 、 B = { 2 , 3 , 6 , 7 } の共通部分と和集合を求めなさい。
解答・詳しい解説を見る
  1. 共通部分は { 3 , 7 } 、和集合は { 1 , 2 , 3 , 5 , 6 , 7 } です。

補集合・ド・モルガンの法則

全体集合 U の中で集合 A に属さないものの集合を、 A の補集合といいます。

A ― = { x ∈ U ∣ x ∉ A }

補集合は次の重要な性質を満たします。

A ∩ A ― = ∅ , A ∪ A ― = U

共通部分と和集合の補集合は、ド・モルガンの法則で変換できます。

A ∪ B ― = A ― ∩ B ― , A ∩ B ― = A ― ∪ B ―
例題：補集合を求める

U = { 1 , 2 , 3 , 4 , 5 , 6 } 、 A = { 2 , 4 , 6 } のとき、

A ― = { 1 , 3 , 5 }
練習4
  1. U = { 1 , 2 , 3 , 4 , 5 , 6 , 7 } 、 A = { 1 , 2 , 4 } 、 B = { 2 , 3 , 5 } に対し A ∪ B ― を求めなさい。
解答・詳しい解説を見る
  1. A ∪ B = { 1 , 2 , 3 , 4 , 5 } より、 A ∪ B ― = { 6 , 7 } です。

集合の要素の個数とまとめ

有限集合で、重複する部分を一度だけ数えるときは次を使います。

n ( A ∪ B ) = n ( A ) + n ( B ) − n ( A ∩ B )
例題：人数の問題

数学が好きな人が18人、理科が好きな人が15人、両方好きな人が7人なら、少なくともどちらかが好きな人は

18 + 15 − 7 = 26   人
章末チェック
  1. 30人のクラスでAの条件を満たす人が20人、Bの条件を満たす人が18人、両方を満たす人が10人。どちらも満たさない人は何人ですか。
解答・詳しい解説を見る
  1. 少なくとも一方が28人なので、 30 − 28 = 2 人。
