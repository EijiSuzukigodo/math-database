命題と条件を理解する

教科書の構成を参考に、定義・図・例題・練習問題の順に学習できます。数式はオフラインでも読める形で表示します。

命題の真偽と反例

正しいか正しくないかを判断できる文や式を命題といいます。正しい命題は真、正しくない命題は偽です。

例題：命題の真偽

「すべての整数 n について、 n 2 ≥ 0 」は真です。一方「すべての実数 x について、 x 2 > x 」は偽です。 x = 1 2 なら 1 4 > 1 2 は成り立たないからです。

このように、全称命題を偽と示す具体例を反例といいます。

練習1
  1. 「すべての素数は奇数である」は真ですか。
  2. 「 x が実数なら x 2 + 1 > 0 」は真ですか。
解答・詳しい解説を見る
  1. 偽です。2は素数で偶数なので反例です。
  2. 真です。 x 2 ≥ 0 だから x 2 + 1 ≥ 1 > 0 。

条件と命題の関係

文字の値によって真偽が変わる文を条件といいます。2つの条件を p 、 q とすると、「 p ならば q 」を次のように書きます。

p ⇒ q

この命題が真であるのは、 p を満たす値が必ず q も満たすときです。 p の真理集合を P 、 q の真理集合を Q とすれば、

p ⇒ q  が真 ⟺ P ⊆ Q
例題：条件の包含

実数 x に対し p : x > 3 、 q : x > 1 とすると、 p ⇒ q は真です。 x > 3 は必ず x > 1 を満たすためです。

逆に q ⇒ p は偽です。例えば x = 2 が反例です。

必要条件・十分条件・必要十分条件

p ⇒ q が真なら、 p は q の十分条件、 q は p の必要条件です。

p ⇒ q ⇒ p : 十分条件 ,   q : 必要条件

p ⇒ q と q ⇒ p が両方真のとき、互いに必要十分条件です。

p ⟺ q
例題：正方形と長方形

「四角形が正方形である」は「長方形である」ための十分条件ですが、必要条件ではありません。長方形であっても正方形とは限らないからです。

練習2
  1. 実数 x について「 x = 2 」は「 x 2 = 4 」の何条件ですか。
  2. 実数 x について「 x > 0 」は「 x 2 > 0 」の何条件ですか。
解答・詳しい解説を見る
  1. 十分条件ですが必要条件ではありません。 x = − 2 も x 2 = 4 を満たすためです。
  2. 十分条件ですが必要条件ではありません。 x = − 1 も x 2 > 0 を満たします。

条件の否定と「かつ」「または」

「 x > 2 」の否定は「 x ≤ 2 」です。等号を含むかどうかにも注意します。

¬ ( p ∧ q ) ⟺ ( ¬ p ) ∨ ( ¬ q )
¬ ( p ∨ q ) ⟺ ( ¬ p ) ∧ ( ¬ q )

「かつ」を否定すると「または」に、「または」を否定すると「かつ」になります。

例題：条件を否定する

「 x > 1 かつ x < 4 」の否定は「 x ≤ 1 または x ≥ 4 」です。

練習3
  1. 「 x < − 2 または x ≥ 5 」の否定を答えなさい。
  2. 「 a > 0 かつ b > 0 」の否定を答えなさい。
解答・詳しい解説を見る
  1. x ≥ − 2 かつ x < 5 、すなわち − 2 ≤ x < 5 。
  2. a ≤ 0 または b ≤ 0 。

章末チェック

命題は真偽を判断し、偽なら反例を一つ示します。「ならば」の真偽は条件を満たす値の集合の包含関係で考えましょう。

確認問題
  1. 整数 n に対し、「 n は6の倍数」は「 n は3の倍数」の何条件ですか。
  2. 実数 x に対し「 x 2 = 9 」の否定を答えなさい。
解答・詳しい解説を見る
  1. 十分条件であり、必要条件ではありません。3は3の倍数ですが6の倍数ではありません。
  2. x 2 ≠ 9 、すなわち x ≠ 3 かつ x ≠ − 3 。
