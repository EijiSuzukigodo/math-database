命題と証明を理解する

教科書の構成を参考に、定義・図・例題・練習問題の順に学習できます。数式はオフラインでも読める形で表示します。

命題の逆・裏・対偶

命題 p ⇒ q に対して、次の3つの命題を考えます。

もとの命題 : p ⇒ q 逆 : q ⇒ p 裏 : ¬ p ⇒ ¬ q 対偶 : ¬ q ⇒ ¬ p

もとの命題と対偶は常に同じ真偽です。逆と裏も同じ真偽ですが、もとの命題と逆が同じ真偽になるとは限りません。

( p ⇒ q ) ⟺ ( ¬ q ⇒ ¬ p )
例題：逆・裏・対偶

整数 n に対し「 n が4の倍数なら n は偶数」の

  • 逆： n が偶数なら n は4の倍数（偽）
  • 裏： n が4の倍数でなければ n は偶数でない（偽）
  • 対偶： n が偶数でなければ n は4の倍数ではない（真）
練習1
  1. 「実数 x が x > 2 なら x > 0 」の対偶を書きなさい。
解答・詳しい解説を見る
  1. 「 x ≤ 0 なら x ≤ 2 」です。不等号と等号に注意します。

対偶を利用した証明

p ⇒ q を直接証明しにくいとき、対偶 ¬ q ⇒ ¬ p を証明します。

例題：命題を証明する

命題：整数 n について、 n 2 が偶数なら n も偶数である。

証明（対偶）

対偶「 n が奇数なら n 2 も奇数」を示す。

奇数 n はある整数 k を使い n = 2 k + 1 と書ける。よって

n 2 = ( 2 k + 1 ) 2 = 4 k 2 + 4 k + 1 = 2 ( 2 k 2 + 2 k ) + 1

2 k 2 + 2 k は整数だから n 2 は奇数。対偶が真なので、元の命題も真。■

練習2
  1. 整数 n に対し、「 n 2 が3の倍数なら n は3の倍数」を対偶で証明しなさい。
解答・詳しい解説を見る
  1. 対偶は「 n が3の倍数でなければ n 2 も3の倍数でない」。整数 n は 3 k + 1 または 3 k + 2 の形。平方はそれぞれ 3 ( 3 k 2 + 2 k ) + 1 、 3 ( 3 k 2 + 4 k + 1 ) + 1 だから3で割った余りは1。したがって対偶は真。

背理法

証明したい結論が偽だと仮定し、既知の事実と矛盾することを導いて、元の結論が真だと示す方法を背理法といいます。

例題：√2 が無理数であることを証明する
証明（背理法）

2 が有理数であると仮定する。既約分数を使い、互いに素な正整数 a , b で

2 = a b

と表せる。両辺を2乗して

a 2 = 2 b 2

よって a 2 は偶数。前節の対偶の証明から a は偶数だから a = 2 c とおける。代入すると

4 c 2 = 2 b 2 ⇒ b 2 = 2 c 2

よって b も偶数となる。しかし、 a , b がともに偶数なのは「互いに素」に矛盾する。

したがって 2 は無理数である。■

練習3
  1. 3 が無理数であることを、背理法を使って説明しなさい。
解答・詳しい解説を見る
  1. 3 = a / b （ a , b は互いに素な正整数）と仮定すると、 a 2 = 3 b 2 。 a 2 が3の倍数なら a は3の倍数なので a = 3 c 。すると b 2 = 3 c 2 から b も3の倍数となり矛盾します。

「すべて」と「ある」の否定

量化された命題の否定では、「すべて」⇔「ある」 が入れ替わります。

¬ ( ∀ x   P ( x ) )   ⟺   ∃ x   ¬ P ( x )
¬ ( ∃ x   P ( x ) )   ⟺   ∀ x   ¬ P ( x )
例題：否定をつくる

「すべての実数 x について x 2 > 0 」の否定は「 x 2 ≤ 0 を満たす実数 x がある」です。例えば x = 0 が当てはまります。

練習4
  1. 「ある整数 n について n 2 < 0 」の否定を述べなさい。
解答・詳しい解説を見る
  1. 「すべての整数 n について n 2 ≥ 0 」です。これは真です。

命題と証明のまとめ

証明方法の選び方を整理します。

直接証明

仮定から結論を順に導く。

対偶による証明

結論を否定した側から仮定の否定を導く。

背理法

結論の否定を仮定し、矛盾を導く。

章末チェック
  1. 「 p ⇒ q が真なら、その逆も真である」という主張は正しいですか。
  2. 2 が無理数であることを利用し、 1 + 2 も無理数であることを証明しなさい。
解答・詳しい解説を見る
  1. 正しくありません。例えば「4の倍数なら偶数」は真ですが、その逆は偽です。
  2. もし 1 + 2 が有理数なら、そこから有理数1を引いた 2 も有理数となって矛盾します。
