関数とグラフ

数学Ⅰ ／ 第3章 2次関数 ／ 関数・定義域・値域・座標

関数とは定義域・値域・変域座標と関数のグラフグラフを動かしてみよう

関数とは

ある数値 x を決めると、それに対応する数値 y がただ1つ決まるとき、yはxの関数といいます。 y = f ( x ) と表します。

y = f ( x )
例題：気温と高度

地上の気温を20℃とし、高度が100m増すごとに0.6℃下がるとします。高度を x km、気温を y ℃とすると、

y = 20 − 6 x ( 0 ≤ x ≤ 10 )

高度5kmでは y = 20 − 6 × 5 = − 10 ℃です。

練習1
  1. f ( x ) = 3 x − 2 の f ( 0 ) , f ( 2 ) , f ( − 1 ) を求めなさい。
  2. 正方形の1辺の長さを x cm、面積を y cm²とするとき関係式を作りなさい。
解答・途中計算を見る
  1. f ( 0 ) = − 2 ,   f ( 2 ) = 4 ,   f ( − 1 ) = − 5 。代入して計算します。
  2. y = x 2 （ x > 0 ）。長さのため x は正です。

定義域・値域・変域

関数の x が動ける範囲が定義域、対応する y の範囲が値域です。

y = x 2 ( − 2 ≤ x ≤ 3 )

この場合、 x = 0 で最小値0、 x = 3 で最大値9なので、値域は 0 ≤ y ≤ 9 です。

例題：一次関数の値域

y = 2 x − 1 （ − 1 ≤ x ≤ 3 ）では、 x が増えると y も増えます。

− 3 ≤ y ≤ 5

座標と関数のグラフ

横軸を x 軸、縦軸を y 軸とする座標平面に、点 ( x , f ( x ) ) を描いた全体が関数のグラフです。

( a , b )  が  y = f ( x )  上 ⟺ b = f ( a )

点 ( 2 , 5 ) が y = 2 x + 1 上にあるのは、 2 i m e s 2 + 1 = 5 だからです。

例題：点の判定

点 ( 3 , 7 ) は y = x 2 − 2 のグラフ上にあります。 3 2 − 2 = 7 だからです。

練習2
  1. 点 ( 2 , 6 ) は y = x 2 + 2 上にあるか調べなさい。
  2. y = − x + 3 について x = 0 , 1 , 3 の3点を求めなさい。
解答・途中計算を見る
  1. 2 2 + 2 = 6 なので、あります。
  2. ( 0 , 3 ) , ( 1 , 2 ) , ( 3 , 0 ) 。
