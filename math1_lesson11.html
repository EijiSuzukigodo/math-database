2次関数とグラフ

数学Ⅰ ／ 第3章 2次関数 ／ 放物線・平行移動・平方完成

2次関数のグラフ平行移動と頂点平方完成動く放物線

2次関数のグラフ

2次関数のグラフは放物線です。基本形 y = a x 2 （ a e 0 ）は y 軸を対称軸とし、頂点が原点にあります。

y = a x 2 ( a ≠ 0 )
a > 0

下に凸。頂点が最も低い点です。

a < 0

上に凸。頂点が最も高い点です。

| a | が大きいほど放物線は細く、 | a | が小さいほど広がります。

平行移動と頂点

y = a ( x − p ) 2 + q は、 y = a x 2 を横に p 、縦に q だけ平行移動した放物線です。頂点と対称軸がすぐに分かります。

y = a ( x − p ) 2 + q 頂点 : ( p , q ) 軸 : x = p
例題：平行移動を読む

y = 2 ( x − 3 ) 2 + 4 は、 y = 2 x 2 を右に3、上に4平行移動したもの。頂点 ( 3 , 4 ) 、軸 x = 3 です。

練習1
  1. y = − ( x + 2 ) 2 + 1 の頂点と軸を求めなさい。
  2. y = 3 x 2 を右に1、下に2移動した式を求めなさい。
解答・途中計算を見る
  1. 頂点は ( − 2 , 1 ) 、軸は x = − 2 。
  2. y = 3 ( x − 1 ) 2 − 2 。

平方完成

一般形 y = a x 2 + b x + c を頂点の形に直す操作を平方完成といいます。

y = a x 2 + b x + c = a ( x + b 2 a ) 2 − b 2 − 4 a c 4 a
例題：平方完成の手順

y = 2 x 2 − 8 x + 5 を変形します。

y = 2 ( x 2 − 4 x ) + 5 = 2 { ( x − 2 ) 2 − 4 } + 5 = 2 ( x − 2 ) 2 − 3

よって頂点は ( 2 , − 3 ) 、軸は x = 2 です。

練習2
  1. y = x 2 + 6 x + 2 を平方完成しなさい。
  2. y = − x 2 + 4 x + 1 の頂点を求めなさい。
解答・途中計算を見る
  1. y = ( x + 3 ) 2 − 7 。
  2. y = − ( x − 2 ) 2 + 5 なので ( 2 , 5 ) 。

動く放物線

係数 a 、頂点の横座標 p 、縦座標 q を変えて、放物線の形と移動を確かめましょう。

放物線 y = a(x − p)² + q の変化を確認しましょう（a = 0 は表示しません）。
