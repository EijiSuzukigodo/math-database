2次関数の最大と最小

最大値・最小値の考え方

関数の値のうち最大のものを最大値、最小のものを最小値といいます。2次関数では、放物線の向きと頂点を調べます。

y = a ( x − p ) 2 + q

定義域がすべての実数のとき、 a > 0 なら最小値 q （ x = p ）、最大値なし。 a < 0 なら最大値 q （ x = p ）、最小値なしです。

例題：定義域に制限がない場合

y = − 2 ( x − 1 ) 2 + 5 は上に凸なので、 x = 1 で最大値5をとり、最小値はありません。

定義域が閉区間の場合

定義域 l ≤ x ≤ r に限るとき、両端と頂点を調べます。頂点が区間内にあれば、その値も候補です。

例題：頂点が区間内

y = ( x − 1 ) 2 − 4 （ − 1 ≤ x ≤ 3 ）を考えます。

y ( − 1 ) = 0 y ( 1 ) = − 4 y ( 3 ) = 0

x = 1 で最小値 − 4 、 x = − 1 , 3 で最大値0。

例題：頂点が区間外

y = ( x − 4 ) 2 + 2 （ 0 ≤ x ≤ 2 ）では頂点の横座標4は範囲外です。

y ( 0 ) = 18 , y ( 2 ) = 6

x = 0 で最大値18、 x = 2 で最小値6。

定義域と頂点の位置で場合分け

文字を含む区間では、頂点 x = p が区間の左か中か右かを比較して場合分けします。特に最大値は区間の両端の値の大小を調べます。

例題：動く区間の例

y = ( x − 1 ) 2 を t ≤ x ≤ t + 2 で考えます。最小値は

{ ( t − 1 ) 2 t > 1 0 − 1 ≤ t ≤ 1 ( t + 1 ) 2 t < − 1

です。頂点 x = 1 が区間に入るかどうかで決まります。

練習1
  1. y = − x 2 + 4 x （ 0 ≤ x ≤ 5 ）の最大値と最小値を求めなさい。
  2. y = ( x + 1 ) 2 + 2 （ 1 ≤ x ≤ 3 ）の最大値と最小値を求めなさい。
解答・途中計算を見る
  1. y = − ( x − 2 ) 2 + 4 。頂点の x = 2 で最大値4、端点 x = 5 で最小値 − 5 （ y ( 0 ) = 0 ）。
  2. 区間では増加するので x = 1 で最小値6、 x = 3 で最大値18。

グラフで考える

スライダーで頂点と開く向きを変えると、どこで最大・最小をとるかが見えてきます。目盛りを参考に端点も比較してみましょう。

放物線 y = a(x − p)² + q の変化を確認しましょう（a = 0 は表示しません）。

練習問題とまとめ

練習2
  1. y = 2 ( x − 2 ) 2 − 1 （ 0 ≤ x ≤ 3 ）の最大・最小を求めなさい。
  2. y = − 3 ( x + 1 ) 2 + 7 （実数全体）の最大・最小を求めなさい。
解答・途中計算を見る
  1. y ( 0 ) = 7 , y ( 2 ) = − 1 , y ( 3 ) = 1 。最大値7（ x = 0 ）、最小値 − 1 （ x = 2 ）。
  2. 最大値7（ x = − 1 ）、最小値なし。
ポイント

平方完成 → 軸と頂点 → 定義域を確認 → 頂点と両端の値を比較、の順番で解くと確実です。
