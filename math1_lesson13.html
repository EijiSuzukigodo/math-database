2次方程式と因数分解

2次方程式は、未知数の2次の項を含む方程式です。次の形に整理して解きます。

a x 2 + b x + c = 0 ( a ≠ 0 )

積が0になる条件

積が0なら、少なくとも一方の因数が0です。

A B = 0 ⟺ A = 0   または   B = 0
例題｜因数分解による解法

x 2 − 2 x − 3 = 0 を解く。

x 2 − 2 x − 3 = ( x + 1 ) ( x − 3 ) = 0 x + 1 = 0   または   x − 3 = 0 x = − 1 ,   3
練習問題

1. x 2 − 6 x + 5 = 0 を解きなさい。

解答と途中計算を開く

( x − 1 ) ( x − 5 ) = 0 なので、 x = 1 , 5 。

2. 2 x 2 + 5 x + 2 = 0 を解きなさい。

解答と途中計算を開く

( 2 x + 1 ) ( x + 2 ) = 0 なので、 x = − 1 2 , − 2 。

平方完成と解の公式の導出

因数分解できない2次方程式には解の公式を使います。公式は平方完成から導けます。

a x 2 + b x + c = 0 x 2 + b a x = − c a ( x + b 2 a ) 2 = b 2 − 4 a c 4 a 2

右辺が0以上のとき平方根をとり、整理すると、

x = − b ± b 2 − 4 a c 2 a

となります（ a e 0 、 b 2 − 4 a c ≥ 0 ）。

例題｜解の公式で解く

3 x 2 − 5 x + 1 = 0 では、 a = 3 , b = − 5 , c = 1 。

x = 5 ± ( − 5 ) 2 − 4 ⋅ 3 ⋅ 1 2 ⋅ 3 = 5 ± 13 6
練習問題

1. 2 x 2 + 3 x − 1 = 0 を解きなさい。

解答と途中計算を開く

D = 3 2 − 4 ⋅ 2 ⋅ ( − 1 ) = 17 。したがって

x = − 3 ± 17 4

2. x 2 + 2 x + 5 = 0 は実数解をもつか。

解答と途中計算を開く

D = 2 2 − 4 ⋅ 1 ⋅ 5 = − 16 < 0 なので実数解をもちません。

判別式と解の個数

解の公式の根号の中にある数を判別式といいます。

D = b 2 − 4 a c
判別式実数解個数
D > 0異なる2つの実数解2個
D = 0重解1個
D < 0実数解なし0個
例題｜文字を含む方程式

x 2 − 6 x + m = 0 が異なる2つの実数解をもつ条件は、

D = 36 − 4 m > 0 ⟺ m < 9
練習問題

1. x 2 + 4 x + m = 0 が重解をもつmを求めなさい。

解答と途中計算を開く

D = 16 − 4 m = 0 なので m = 4 。そのとき重解は x = − 2 。

2. 2 x 2 − 4 x + m = 0 が実数解をもたないmの範囲を求めなさい。

解答と途中計算を開く

D = 16 − 8 m < 0 なので m > 2 。

まとめ

解法の順序

① まず因数分解できるか確認 → ② 難しければ解の公式 → ③ 実数解の個数は判別式で判定、という流れで整理します。
