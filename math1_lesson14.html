2次方程式とx軸の交点

放物線 y = a x 2 + b x + c とx軸の共有点では y = 0 となるので、そのx座標は2次方程式の実数解です。

a x 2 + b x + c = 0

判別式 D = b 2 − 4 a c により、グラフとx軸の共有点の個数が分かります。

例題｜x軸との交点

y = x 2 − 4 x + 3 の交点は、

x 2 − 4 x + 3 = ( x − 1 ) ( x − 3 ) = 0

より ( 1 , 0 ) , ( 3 , 0 ) です。

放物線と直線の共有点

放物線と直線の共有点は2つの式を連立し、yを消去して求めます。

例題｜異なる2つの共有点

放物線 y = x 2 − 4 x + 5 と直線 y = x + 1 を連立します。

x 2 − 4 x + 5 = x + 1 x 2 − 5 x + 4 = 0 ( x − 1 ) ( x − 4 ) = 0

x = 1 , 4 を y = x + 1 に代入し、共有点は ( 1 , 2 ) , ( 4 , 5 ) です。

例題｜接する条件

放物線 y = x 2 − 1 と直線 y = 2 x + k が接するkを求めます。

x 2 − 1 = 2 x + k ⟺ x 2 − 2 x − ( k + 1 ) = 0

重解をもつので D = 4 + 4 ( k + 1 ) = 4 ( k + 2 ) = 0 より k = − 2 。接点は ( 1 , 0 ) です。

練習問題

1. y = x 2 − 2 x + 2 と y = x の共有点を求めなさい。

解答と途中計算を開く

x 2 − 3 x + 2 = 0 より x = 1 , 2 。共有点は ( 1 , 1 ) , ( 2 , 2 ) 。

2. y = x 2 + 1 と y = 2 x + k が接するkを求めなさい。

解答と途中計算を開く

x 2 − 2 x + 1 − k = 0 の判別式を0にする。 D = 4 − 4 ( 1 − k ) = 4 k より k = 0 。接点 ( 1 , 2 ) 。

応用とまとめ

大切な視点

2次方程式の実数解の個数と、放物線とx軸との共有点の個数は一致します。直線との共有点でも、連立して得られた2次方程式の判別式を使えます。
