グラフを利用して2次不等式を解く

2次不等式は a x 2 + b x + c の符号が正か負かを、放物線がx軸より上か下かで考えます。

グラフを動かして確かめよう

例題｜異なる2つの根をもつ場合

x 2 − 2 x − 3 < 0 を解きます。

( x + 1 ) ( x − 3 ) < 0

上に開く放物線がx軸より下にあるのは根の間なので、

− 1 < x < 3

です。 ( x + 1 ) ( x − 3 ) ≥ 0 なら逆に x ≤ − 1 または x ≥ 3 です。

重解の場合と実数解がない場合

重解（D = 0）のとき

( x − 2 ) 2 ≥ 0 はすべての実数で成立

等号が成り立つのは x = 2 です。 ( x − 2 ) 2 > 0 は x e 2 、 ( x − 2 ) 2 < 0 は解なしです。

実数解がない（D < 0）とき

x 2 + 2 x + 3 = ( x + 1 ) 2 + 2 > 0

したがって x 2 + 2 x + 3 > 0 の解はすべての実数で、 x 2 + 2 x + 3 < 0 は解なしです。

負の係数と不等号の向き

2次の係数が負のときは、両辺に − 1 を掛けてから考えると確実です。不等号の向きが逆になる点に注意しましょう。

例題｜負の係数

− x 2 + 3 x + 4 ≥ 0 を解く。

− x 2 + 3 x + 4 ≥ 0 x 2 − 3 x − 4 ≤ 0 ( x − 4 ) ( x + 1 ) ≤ 0

上に開く放物線でx軸以下の範囲なので、 − 1 ≤ x ≤ 4 。

練習問題

1. x 2 − 5 x + 6 < 0 を解きなさい。

解答と途中計算を開く

( x − 2 ) ( x − 3 ) < 0 より 2 < x < 3 。

2. 2 x 2 − 3 x − 2 ≥ 0 を解きなさい。

解答と途中計算を開く

( 2 x + 1 ) ( x − 2 ) ≥ 0 より x ≤ − 1 2 または x ≥ 2 。

3. − x 2 + 4 x − 4 > 0 を解きなさい。

解答と途中計算を開く

− ( x − 2 ) 2 > 0 は不可能なので、解なし。

連立2次不等式

複数の不等式が同時に成立する範囲は、各々の解の共通範囲を求めます。

例題｜連立不等式

x 2 + x − 2 < 0 かつ x 2 − 4 ≥ 0 を解きます。

( x + 2 ) ( x − 1 ) < 0 ⟹ − 2 < x < 1 ( x − 2 ) ( x + 2 ) ≥ 0 ⟹ x ≤ − 2   または   x ≥ 2

両者の共通範囲はないので、解なしです。

例題｜共通範囲がある例

x 2 − 1 < 0 と x 2 − x − 2 < 0 の共通範囲を求めます。

− 1 < x < 1 − 1 < x < 2

共通範囲は − 1 < x < 1 です。

2次不等式の応用

文章題では、求める範囲を不等式で表し、時間や長さなどの条件も併せて確認します。

例題｜物体を投げ上げる問題

ある物体の高さを h = − 5 t 2 + 50 t （m、 t ≥ 0 ）とします。高さが80m以上120m以下となる時間を求めます。

80 ≤ − 5 t 2 + 50 t ≤ 120

まず h ≥ 80 から

− 5 t 2 + 50 t ≥ 80 ⟺ ( t − 2 ) ( t − 8 ) ≤ 0

すなわち 2 ≤ t ≤ 8 。一方 h ≤ 120 から

− 5 t 2 + 50 t ≤ 120 ⟺ ( t − 4 ) ( t − 6 ) ≥ 0

ゆえに t ≤ 4 または t ≥ 6 。共通範囲は

2 ≤ t ≤ 4 または 6 ≤ t ≤ 8
練習問題

1. x 2 − 4 x + 3 ≤ 0 の解を求めなさい。

解答と途中計算を開く

( x − 1 ) ( x − 3 ) ≤ 0 より 1 ≤ x ≤ 3 。

2. x 2 + 2 x + 5 < 0 の解を求めなさい。

解答と途中計算を開く

( x + 1 ) 2 + 4 < 0 は不可能。解なし。
