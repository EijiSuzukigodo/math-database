数学Ⅰ ／ 第4章 図形と計量

授業のねらい

公式を証明して使う

三角比には、三平方の定理から得られる重要な相互関係があります。等式の成り立つ理由を理解し、1つの三角比からほかの値を求めましょう。

正弦・余弦・正接の相互関係

直角三角形の各辺と角 θ
tan θ = sin θcos θ

sin²θ + cos²θ = 1

1 + tan²θ = 1cos²θ

証明

sinθ＝y/r、cosθ＝x/r より、sin θcos θ＝y/rx/r＝y/x＝tanθ。

三平方の定理 x²+y²＝r² の両辺を r² で割ると、x²/r²＋y²/r²＝1。すなわち sin²θ＋cos²θ＝1。

この式の両辺を cos²θ（cosθ≠0）で割ると、tan²θ＋1＝1/cos²θ。

cosθ＝0となる90°ではtanθは定義されず、tanを含む式は使用できません。

三角比の値を求める

例題｜cosθ から求める

θ は鋭角、cosθ＝3/5 のとき sinθ、tanθ を求めなさい。

sin²θ＝1−(3/5)²＝16/25。

θ は鋭角なので sinθ＞0。したがって sinθ＝4/5。

tanθ＝sinθ/cosθ＝(4/5)/(3/5)＝4/3。

答：sinθ＝4/5、tanθ＝4/3

例題｜tanθ から求める

θ は鋭角、tanθ＝2 のとき sinθ、cosθ を求めなさい。

斜辺を√5、隣辺を1、対辺を2と考えると、1²＋2²＝5。

答：sinθ＝2√5＝2√55、cosθ＝1√5＝√55

余角の三角比

直角三角形の2つの鋭角の和は90°なので、対辺と隣辺を入れ替えると次の公式が得られます。

sin(90°−θ) = cosθ
cos(90°−θ) = sinθ
tan(90°−θ) = 1tanθ　（0°＜θ＜90°）

例えば sin65°＝cos25°、tan80°＝1/tan10° です。

練習問題と解答

練習問題
  1. θ は鋭角で sinθ＝5/13。cosθ と tanθ を求めなさい。
  2. θ は鋭角で tanθ＝√3。sinθ と cosθ を求めなさい。
  3. sin70° と等しい三角比をcosを用いて表しなさい。
  4. sin²θ＝9/25でθは鋭角。cos²θ と tan²θ を求めなさい。
解答・解説を開く
  1. cosθ＝√(1−25/169)＝12/13、tanθ＝5/12。
  2. tanθ＝√3 より cos²θ＝1/4。cosθ＝1/2、sinθ＝√3/2。
  3. sin70°＝cos20°。
  4. cos²θ＝16/25、tan²θ＝(9/25)/(16/25)＝9/16。
