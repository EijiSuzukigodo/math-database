2次関数の決定

数学Ⅰ ／ 第3章 2次関数 ／ 頂点・軸・通過点から式を決める

2次関数の式を決める考え方頂点と1点が与えられた場合軸と2点が与えられた場合3点を通る場合x軸との交点が与えられた場合グラフと練習問題

2次関数の式を決める考え方

2次関数は、求める条件に応じて式の形を選ぶと効率的です。

頂点が分かる
y = a ( x − p ) 2 + q

未知数は a だけ。

3点を通る
y = a x 2 + b x + c

未知数 a , b , c を連立方程式で求めます。

頂点と1点が与えられた場合

例題：頂点 (2, -3)、点 (0, 5) を通る

頂点から y = a ( x − 2 ) 2 − 3 とおき、点 ( 0 , 5 ) を代入します。

5 = a ( 0 − 2 ) 2 − 3 ⇒ 4 a = 8 ⇒ a = 2

したがって、求める関数は

y = 2 ( x − 2 ) 2 − 3
練習1
  1. 頂点 ( − 1 , 2 ) をもち点 ( 1 , 10 ) を通る2次関数を求めなさい。
解答・途中計算を見る
  1. y = a ( x + 1 ) 2 + 2 に ( 1 , 10 ) を代入して 10 = 4 a + 2 、 a = 2 。よって y = 2 ( x + 1 ) 2 + 2 。

軸と2点が与えられた場合

例題：軸 x=1、点 (0,2),(2,6) に関する注意

軸が x = 1 で2点 ( 0 , 2 ) , ( 2 , 6 ) を通る放物線は存在しません。軸に対称な横座標0と2では、縦座標が等しくなる必要があるからです。

例題：軸 x=1、点 (0,2),(3,8) を通る

y = a ( x − 1 ) 2 + q とおいて代入すると、

{ a + q = 2 4 a + q = 8 ⇒ a = 2 ,   q = 0

したがって y = 2 ( x − 1 ) 2 。

3点を通る場合

例題：3点 (0,1),(1,2),(2,7) を通る

一般形 y = a x 2 + b x + c に各座標を代入します。

{ c = 1 a + b + c = 2 4 a + 2 b + c = 7

c = 1 、 a + b = 1 、 4 a + 2 b = 6 。後者を2で割ると 2 a + b = 3 なので a = 2 , b = − 1 。

y = 2 x 2 − x + 1
練習2
  1. 3点 ( 0 , 2 ) , ( 1 , 3 ) , ( 2 , 8 ) を通る2次関数を求めなさい。
解答・途中計算を見る
  1. c = 2 、 a + b = 1 、 4 a + 2 b = 6 なので a = 2 , b = − 1 。求める式は y = 2 x 2 − x + 2 。

x軸との交点が与えられた場合

x 軸との交点の横座標が α , β のとき、

y = a ( x − α ) ( x − β )

とおけます。

例題：交点が -1 と3、点 (0,6) を通る

y = a ( x + 1 ) ( x − 3 ) 。点 ( 0 , 6 ) を代入すると 6 = − 3 a なので、 a = − 2 。

y = − 2 ( x + 1 ) ( x − 3 )

グラフと練習問題

頂点の形で式を決定した後、次のスライダーでグラフを確認できます。

放物線 y = a(x − p)² + q の変化を確認しましょう（a = 0 は表示しません）。

確認問題
  1. 頂点 ( 1 , 4 ) 、点 ( 3 , − 4 ) を通る2次関数を求めなさい。
  2. x 軸と x = − 2 , 4 で交わり、点 ( 0 , 8 ) を通る2次関数を求めなさい。
解答・途中計算を見る
  1. y = a ( x − 1 ) 2 + 4 に ( 3 , − 4 ) を代入。 − 4 = 4 a + 4 より a = − 2 。したがって y = − 2 ( x − 1 ) 2 + 4 。
  2. y = a ( x + 2 ) ( x − 4 ) に ( 0 , 8 ) を代入。 8 = − 8 a より a = − 1 。したがって y = − ( x + 2 ) ( x − 4 ) 。
