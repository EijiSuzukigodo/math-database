関数の最大と最小

数学Ⅲ ／ 第4章 微分法の応用 ／ 第4講　｜　みんなの数学データベース

授業のねらい

導関数を使って最大値・最小値を求める

閉区間の端点と停留点を比較する手順を身につけ、極大・極小との違いをグラフで理解します。

1. 最大値・最小値と極値の違い

関数 \(f(x)\) の定義域内で取る値のうち、最も大きいものを最大値、最も小さいものを最小値といいます。一方、極大・極小は、その点の近くでの値の比較です。極大値が必ず最大値になるとは限りません。

閉区間 \([a,b]\) で連続な関数は、必ず最大値と最小値を取ります。

\[\boxed{\text{候補： }f'(x)=0\text{ となる点と区間の両端}}\]

2. 閉区間で最大・最小を求める手順

① 導関数 \(f'(x)\) を求める。② 区間内で \(f'(x)=0\) を解く。③ その解と両端での関数値を求め、比較する。

例題1　\(f(x)=x^3-3x\) の \(-2\le x\le 2\) における最大値と最小値を求めよ。

解説

\[f'(x)=3x^2-3=3(x-1)(x+1)\]

よって、候補は \(x=-2,-1,1,2\)。それぞれの値は

\[f(-2)=-2,\quad f(-1)=2,\quad f(1)=-2,\quad f(2)=2\]

答え：最大値は \(2\)（\(x=-1,2\)）、最小値は \(-2\)（\(x=-2,1\)）。

例題2　\(f(x)=x^2-4x+1\) の \(0\le x\le 3\) における最大値と最小値を求めよ。

\(f'(x)=2x-4=0\) より \(x=2\)。

\[f(0)=1,\quad f(2)=-3,\quad f(3)=-2\]

答え：最大値 \(1\)（\(x=0\)）、最小値 \(-3\)（\(x=2\)）。

3. 動くグラフで確認

\(f(x)=x^3-3x\) の区間 \([-2,b]\) の右端 \(b\) を動かし、最大値・最小値の候補がどう変わるか観察しましょう。黄色の点は区間内の最大、緑色の点は最小を表します。

右端を動かしてみましょう。

4. 練習問題

問題1　\(f(x)=x^2-2x+3\) の \(-1\le x\le 3\) での最大値と最小値を求めよ。
解答・解説を表示\[f'(x)=2x-2\]候補は \(x=-1,1,3\)。\(f(-1)=6,\ f(1)=2,\ f(3)=6\) なので、最大値6、最小値2です。
問題2　\(f(x)=x^3-3x^2\) の \(-1\le x\le 3\) での最大値と最小値を求めよ。
解答・解説を表示\[f'(x)=3x(x-2)\]候補は \(x=-1,0,2,3\)。\(f(-1)=-4,\ f(0)=0,\ f(2)=-4,\ f(3)=0\)。最大値0、最小値−4です。
問題3（発展）　\(x>0\) における \(x+\dfrac{4}{x}\) の最小値を求めよ。
解答・解説を表示\[f'(x)=1-\frac4{x^2}\] \(x=2\) で符号は負から正へ変化するため、最小値は \(f(2)=4\) です（最大値はありません）。

5. まとめ

閉区間で最大・最小を求めるときは、微分して求めた停留点だけでなく、区間の両端も必ず比較しましょう。導関数が存在しない内点があれば、その点も候補に含めます。
