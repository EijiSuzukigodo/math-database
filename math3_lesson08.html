微分係数と導関数

授業のねらい

微分係数と導関数の意味を理解する

平均変化率から微分係数を導き、曲線の接線の傾きとの関係を理解する。さらに、導関数の定義を用いて基本的な関数を微分できるようになる。

基本事項

1. 平均変化率

関数 \(y=f(x)\) について、\(x\) が \(a\) から \(a+h\) に変わるとき、関数の値の変化を \(x\) の変化量で割ったものを平均変化率といいます（\(h\ne0\)）。

\[\frac{f(a+h)-f(a)}{h}\]

この値は、グラフ上の2点 \(P(a,f(a))\)、\(Q(a+h,f(a+h))\) を結ぶ直線（割線）の傾きです。

例題1　平均変化率

\(f(x)=x^2\) について、\(x\) が \(1\) から \(1+h\) に変わるときの平均変化率を求めなさい。

\[\begin{aligned}\frac{f(1+h)-f(1)}{h}&=\frac{(1+h)^2-1}{h}\\&=\frac{2h+h^2}{h}=2+h\end{aligned}\]

したがって、平均変化率は \(2+h\) です。

2. 微分係数

\(h\) を0に近づけたとき、平均変化率が一定の値に近づくなら、その値を \(x=a\) における微分係数といい、\(f'(a)\) と表します。

\[\boxed{f'(a)=\lim_{h\to0}\frac{f(a+h)-f(a)}{h}}\]
ここでの極限は、\(h\to0^+\) と \(h\to0^-\) の両方から同じ値に近づく必要があります。微分係数は、曲線の接線の傾きに対応します。

前の例題では、\(2+h\to2\) なので、\(f'(1)=2\) です。

動く図

3. 割線が接線へ近づく様子

点 \(P\) を固定し、点 \(Q\) を近づけると、橙色の割線が緑色の接線へ近づきます。\(h\) をプラス側・マイナス側から変化させてみましょう。

青：曲線　橙：割線　緑破線：接線（近似ではなく理論上の接線）

割線の傾きと接線の傾きを表示します。

※ \(h=0\) では2点が重なり、割線は定義できません。このとき図では接線だけを示します。

基本事項

4. 導関数

微分係数を点 \(a\) ごとに求め、\(a\) を変数 \(x\) に置き換えて得られる関数を導関数といいます。

\[\boxed{f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}}\]

導関数を定義から求める

\(f(x)=x^2\) の場合は次のようになります。

\[\begin{aligned}f'(x)&=\lim_{h\to0}\frac{(x+h)^2-x^2}{h}\\&=\lim_{h\to0}(2x+h)\\&=2x\end{aligned}\]

ここで \(x=1\) とすれば微分係数 \(f'(1)=2\) が得られます。

微分可能と連続

点 \(x=a\) で微分係数が存在するとき、関数はその点で微分可能といいます。微分可能なら連続ですが、連続だからといって必ず微分可能とは限りません。

\[f(x)=|x|\quad\Rightarrow\quad\begin{cases}\displaystyle\lim_{h\to0^+}\frac{|h|}{h}=1\\[5pt]\displaystyle\lim_{h\to0^-}\frac{|h|}{h}=-1\end{cases}\]

左右の極限が異なるため、\(f(x)=|x|\) は \(x=0\) で微分可能ではありません。

例題

5. 例題と詳しい解説

例題2　導関数を定義から求める

\(f(x)=x^2-2x+3\) の導関数を求めなさい。

解答・解説

まず差を計算します。

\[\begin{aligned}f(x+h)-f(x)&=(x+h)^2-2(x+h)+3\\&\quad -(x^2-2x+3)\\&=2xh+h^2-2h\end{aligned}\]

これを \(h\) で割り、極限をとります。

\[\begin{aligned}f'(x)&=\lim_{h\to0}\frac{2xh+h^2-2h}{h}\\&=\lim_{h\to0}(2x+h-2)\\&=\boxed{2x-2}\end{aligned}\]
例題3　微分係数と接線の傾き

曲線 \(y=x^3\) の \(x=2\) における接線の傾きを求めなさい。

解答・解説を表示
\[\begin{aligned}f'(2)&=\lim_{h\to0}\frac{(2+h)^3-8}{h}\\&=\lim_{h\to0}(12+6h+h^2)\\&=\boxed{12}\end{aligned}\]

接線の傾きは12です。

例題4　微分可能性の判定

\(f(x)=|x-1|\) は \(x=1\) で微分可能ですか。

解答・解説を表示
\[\frac{f(1+h)-f(1)}{h}=\frac{|h|}{h}=\begin{cases}1&(h>0)\\-1&(h<0)\end{cases}\]

左右の極限値が異なるので、微分可能ではありません。

練習問題

6. 練習問題（解答・解説付き）

練習1

\(f(x)=3x^2+2x\) の導関数を定義から求めなさい。

解答・解説を表示
\[\begin{aligned}\frac{f(x+h)-f(x)}{h}&=\frac{6xh+3h^2+2h}{h}\\&=6x+3h+2\end{aligned}\]

\(h\to0\) として \(\boxed{f'(x)=6x+2}\) です。

練習2

\(f(x)=x^2-4x\) の \(x=1\) における微分係数を求めなさい。

解答・解説を表示
\[f'(x)=2x-4,\quad f'(1)=\boxed{-2}\]
練習3

\(f(x)=\dfrac{1}{x}\) （\(x\ne0\)）の導関数を定義から求めなさい。

解答・解説を表示
\[\begin{aligned}\frac{f(x+h)-f(x)}{h}&=\frac{\frac1{x+h}-\frac1x}{h}\\&=-\frac{1}{x(x+h)}\end{aligned}\]

\(h\to0\) より \(\boxed{f'(x)=-\dfrac1{x^2}}\) です。

練習4

\(f(x)=|x+2|\) が \(x=-2\) で微分可能か調べなさい。

解答・解説を表示

差商は \(\dfrac{|h|}{h}\) となり、右からの極限は1、左からの極限は−1です。よって微分可能ではありません。

発展問題

7. 発展：係数を含む関数の微分可能性

関数 \(f(x)\) を次で定めます。

\[f(x)=\begin{cases}x^2 &(x\geq 1)\\ax+b &(x<1)\end{cases}\]

\(x=1\) で微分可能となるように \(a,b\) を求めなさい。

解答・解説を表示

微分可能なら連続なので、\(a+b=1\) です。右側の微分係数は2、左側の微分係数は \(a\) なので \(a=2\) となります。

\[\boxed{a=2,\qquad b=-1}\]

これらの値では連続であり、左右の微分係数も一致するため、確かに微分可能です。

学習のまとめ

平均変化率は割線の傾き、微分係数はその極限、導関数は各点の微分係数を表す関数です。微分できるかを判断するときは、左右からの差商の極限を確認しましょう。
