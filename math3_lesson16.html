導関数を使って、関数の増減と極値を調べる

導関数の符号から関数の増加・減少を判断し、増減表を作って極大・極小を求めます。動くグラフで接線の傾きと関数の値の変化を結びつけ、例題・練習問題で解法を身につけます。

基本事項

1. 導関数の符号と増加・減少

微分可能な関数 \(f(x)\) について、ある区間で導関数が正なら関数は増加、負なら減少します。

\[f'(x)>0\ \Longrightarrow\ f(x)\text{ は増加}\]
\[f'(x)<0\ \Longrightarrow\ f(x)\text{ は減少}\]

これは平均値の定理から説明できます。\(a0\) なら \(f(b)>f(a)\) です。

注意：\(f'(a)=0\) であっても、必ず極大・極小になるとは限りません（例：\(f(x)=x^3\) の \(x=0\)）。
解法の手順

2. 増減表と極大・極小

増減表の作り方は、①微分して \(f'(x)\) を求める → ②\(f'(x)=0\) の解と導関数が存在しない点を調べる → ③区間ごとの符号を決める → ④増減と極値をまとめる、の順です。

例題1　\(f(x)=x^3-3x\) の増減と極値

\(f'(x)=3x^2-3=3(x+1)(x-1)\)。したがって \(f'(x)=0\) は \(x=-1,1\) です。

\(x\)\(x<-1\)\(-1\)\(-1\(1\)\(x>1\)
\(f'(x)\)＋0−0＋
\(f(x)\)↗極大 2↘極小 −2↗

\(f(-1)=2\)、\(f(1)=-2\)。したがって \(x=-1\) で極大値 2、\(x=1\) で極小値 \(-2\) をとります。

重要：導関数の符号が「＋から−」に変わる点では極大、「−から＋」に変わる点では極小になります。符号が変わらない点は極値とは限りません。

例題

4. 例題で手順を確かめる

例題2　\(f(x)=x^4-4x^2\)

\(f'(x)=4x^3-8x=4x(x^2-2)\) より、停留点は \(x=-\sqrt2,0,\sqrt2\) です。符号を左から調べると「−，＋，−，＋」。

よって \(x=-\sqrt2,\sqrt2\) で極小値 \(-4\)、\(x=0\) で極大値 0 です。

例題3　\(f(x)=x^3\)

\(f'(x)=3x^2\ge0\) で、\(x=0\) の前後で符号は変わりません。したがって全体で増加し、\(x=0\) は極値ではありません。

例題4　\(f(x)=\log x-x\) （\(x>0\)）

\(f'(x)=\frac1x-1=\frac{1-x}{x}\)。\(01\) で負。よって \(x=1\) で極大値 \(f(1)=-1\) をとります。

例題5　\(f(x)=xe^{-x}\) （\(x\in\mathbb R\)）

積の微分法より \(f'(x)=e^{-x}(1-x)\)。\(e^{-x}>0\) より、\(x<1\) で増加、\(x>1\) で減少。したがって \(x=1\) で極大値 \(\frac1e\) です。

練習問題

5. 練習問題（解答・解説付き）

まず自分で増減表を書き、解答を開いて確かめましょう。

問題1　\(f(x)=x^2-4x+1\) の極値

\(f'(x)=2x-4\)。\(x<2\) で負、\(x>2\) で正。よって \(x=2\) で極小値 \(-3\)。

問題2　\(f(x)=x^3-12x\) の極値

\(f'(x)=3(x-2)(x+2)\)。符号は「＋，−，＋」。\(x=-2\) で極大値 \(16\)、\(x=2\) で極小値 \(-16\)。

問題3　\(f(x)=x^3+3x\) の増減

\(f'(x)=3x^2+3>0\) です。すべての実数で増加し、極値はありません。

問題4　\(f(x)=x+\frac1x\) （\(x>0\)）の極値

\(f'(x)=1-\frac1{x^2}=\frac{(x-1)(x+1)}{x^2}\)。\(01\) で増加。\(x=1\) で極小値 2。

\(f'(x)=\cos x\)。\(x=\frac\pi2\) で極大値 1、\(x=\frac{3\pi}2\) で極小値 \(-1\)。

問題6　\(f(x)=x^4\) の \(x=0\) の極値

\(f'(x)=4x^3\) は \(x=0\) で負から正に変わるので、\(x=0\) で極小値 0 です。

発展・まとめ

6. よくある誤りと発展

\(f'(x)=0\) となる点を見つけただけでは極値と判断できません。その点の左右で導関数の符号が変わるかを必ず確かめましょう。
