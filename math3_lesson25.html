面積

第1講　第6章 積分法の応用

授業のねらい

定積分を使って曲線に囲まれた部分の面積を求められるようになる

曲線と座標軸、2つの曲線に囲まれた部分について、交点を求め、上下関係と積分区間を調べて面積を計算する方法を学びます。

1．定積分と面積

連続な関数 \(y=f(x)\) と \(x\) 軸、直線 \(x=a,\ x=b\) に囲まれる部分を考えます。区間内で \(f(x)\ge0\) なら、面積 \(S\) は次のようになります。

\[\boxed{S=\int_a^b f(x)\,dx}\]

一方 \(f(x)\le0\) なら、面積は定積分の符号を反転させて求めます。関数が \(x\) 軸を横切る場合は、符号が変わる点で区間を分けます。

\[\boxed{S=\int_a^b |f(x)|\,dx}\]
注意：定積分の値は符号付き面積です。「図形の面積」は必ず0以上になるので、グラフの位置と符号を確認します。

2．2曲線で囲まれた部分の面積

区間 \([a,b]\) で \(f(x)\ge g(x)\) なら、上下の関数を引き算して積分します。

\[\boxed{S=\int_a^b\{f(x)-g(x)\}\,dx}\]

交点は \(f(x)=g(x)\) を解いて求めます。途中で上下が入れ替わるときは、交点で積分区間を分割します。

動くグラフ：\(y=x\) と \(y=x^2\)

\(0\le x\le 1\) では \(x\ge x^2\) です。右端 \(b\) を動かして、面積の変化を調べましょう。

面積は 0.166667 です。
\[\begin{aligned}S(b)&=\int_0^b(x-x^2)\,dx\\&=\frac{b^2}{2}-\frac{b^3}{3}\end{aligned}\]

3．面積を求める手順

① 図を描く・概形を確認する　② 交点を求める　③ 上側と下側の曲線を判定する　④ 必要なら区間を分けて積分する　⑤ 面積が正になっていることを確認する。

積分区間が分かれているとき

交点 \(x=c\) で上下が入れ替わるなら、

\[S=\int_a^c\{f(x)-g(x)\}\,dx+\int_c^b\{g(x)-f(x)\}\,dx\]

のように、各区間で「上−下」の順に計算します。

4．詳しい例題

例題1　放物線と \(x\) 軸

\(y=4-x^2\) と \(x\) 軸で囲まれる部分の面積を求めなさい。

交点は \(4-x^2=0\) より \(x=-2,2\)。この区間で関数は0以上です。

\[\begin{aligned}S&=\int_{-2}^{2}(4-x^2)\,dx\\&=\left[4x-\frac{x^3}{3}\right]_{-2}^{2}=\boxed{\frac{32}{3}}\end{aligned}\]

例題2　2曲線で囲まれる部分

\(y=x\) と \(y=x^2\) で囲まれる部分の面積を求めなさい。

交点は \(x=x^2\) より \(x=0,1\)。区間 \([0,1]\) では \(x\ge x^2\) です。

\[S=\int_0^1(x-x^2)\,dx=\left[\frac{x^2}{2}-\frac{x^3}{3}\right]_0^1=\boxed{\frac16}\]

例題3　符号が変わる関数

\(y=x^2-1\)、\(x\) 軸、\(x=-2,\ x=2\) で囲まれる部分の面積の和を求めなさい。

\(x=-1,1\) で符号が変わります。偶関数であることを使うと、

\[\begin{aligned}S&=2\left\{\int_0^1(1-x^2)\,dx+\int_1^2(x^2-1)\,dx\right\}\\&=2\left(\frac23+\frac43\right)=\boxed4\end{aligned}\]

例題4　2曲線の上下が途中で変わる

\(y=x\) と \(y=x^3\) の間で、\(-1\le x\le1\) にある部分の面積を求めなさい。

交点は \(-1,0,1\)。\([-1,0]\) では \(x^3\ge x\)、\([0,1]\) では \(x\ge x^3\) なので、

\[\begin{aligned}S&=\int_{-1}^0(x^3-x)\,dx+\int_0^1(x-x^3)\,dx\\&=\frac14+\frac14=\boxed{\frac12}\end{aligned}\]

例題5　曲線と接線で囲まれる面積

\(y=x^2\) と、その点 \((1,1)\) での接線、および \(y\) 軸で囲まれる部分の面積を求めなさい。

接線の傾きは \(2x\) に \(x=1\) を代入して2。接線は \(y=2x-1\)。\(x^2-(2x-1)=(x-1)^2\ge0\) より、

\[S=\int_0^1(x-1)^2\,dx=\left[\frac{(x-1)^3}{3}\right]_0^1=\boxed{\frac13}\]

5．練習問題

まずは自分で解き、あとから解答・解説を開きましょう。

問1　\(y=9-x^2\) と \(x\) 軸で囲まれる部分の面積を求めなさい。
解答・解説

交点は \(-3,3\)。

\[S=\int_{-3}^3(9-x^2)\,dx=\boxed{36}\]
問2　\(y=2x\) と \(y=x^2\) で囲まれる部分の面積を求めなさい。
解答・解説

交点は \(0,2\)。

\[S=\int_0^2(2x-x^2)\,dx=\boxed{\frac43}\]
問3　\(-1\le x\le2\) における \(y=x\) と \(x\) 軸の間の面積を求めなさい。
解答・解説

原点で符号が変わるので、

\[S=-\int_{-1}^{0}x\,dx+\int_0^2x\,dx=\boxed{\frac52}\]
問4　\(y=\sin x\) と \(x\) 軸の間の \(0\le x\le\pi\) の面積を求めなさい。
解答・解説
\[S=\int_0^\pi\sin x\,dx=[-\cos x]_0^\pi=\boxed2\]
問5　\(y=x^2\) と \(y=2-x^2\) で囲まれる部分の面積を求めなさい。
解答・解説

交点は \(x=\pm1\)。上側は \(2-x^2\) です。

\[S=\int_{-1}^1(2-2x^2)\,dx=\boxed{\frac83}\]
問6　\(y=x^3-x\) と \(x\) 軸で囲まれる部分全体の面積を求めなさい。
解答・解説

交点は \(-1,0,1\)。原点対称なので、

\[S=2\int_0^1(x-x^3)\,dx=\boxed{\frac12}\]

6．発展問題とまとめ

発展：面積から定積分を考える

連続な関数 \(f(x)\) に対し、\(S(t)=\int_a^t f(x)\,dx\) と置くと、微分積分学の基本定理より次の関係が得られます。

\[\boxed{S'(t)=f(t)}\]

関数が負になる場合、\(S(t)\) は図形の面積そのものではなく、符号付き面積の累積であることに注意しましょう。

まとめ：面積の計算では、必ず交点・区間・上下関係を確認します。必要に応じて絶対値を使うか、区間を分割して「上−下」を積分します。
