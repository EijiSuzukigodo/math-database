面積

数学Ⅲ ／ 高校生のための問題演習
演習のねらい

定積分を利用して曲線で囲まれた部分の面積を求められるようになる

全14問（基本3問・標準4問・応用4問・発展3問）。交点、上下関係、符号による区間分割、置換積分を確認します。まず自分で考え、必要に応じて着眼点と詳しい解説を開いてください。

基本問題（3問）

問題1　曲線と x 軸

\(y=x^2,\ x=0,\ x=2\) で囲まれる部分の面積を求めよ（x 軸も境界とする）。

着眼点を見る
関数は区間全体で非負。
解答・詳しい解説を見る
関数は区間全体で非負。
\[S=\int_0^2 x^2\,dx=\left[\frac{x^3}{3}\right]_0^2=\boxed{\frac83}\]

問題2　負の部分の面積

\(y=x^2-4,\ x=-2,\ x=2\) で囲まれる部分の面積を求めよ（x 軸も境界とする）。

着眼点を見る
曲線は x 軸の下側にあるので符号を反転する。
解答・詳しい解説を見る
曲線は x 軸の下側にあるので符号を反転する。
\[S=\int_{-2}^2(4-x^2)\,dx=2\left[4x-\frac{x^3}{3}\right]_0^2=\boxed{\frac{32}{3}}\]

問題3　放物線と直線

\(y=x^2,\ y=x\) で囲まれる部分の面積を求めよ。

着眼点を見る
交点は x=0,1。区間内では直線が上側。
解答・詳しい解説を見る
交点は x=0,1。区間内では直線が上側。
\[S=\int_0^1(x-x^2)\,dx=\left[\frac{x^2}{2}-\frac{x^3}{3}\right]_0^1=\boxed{\frac16}\]

標準問題（4問）

問題4　三角関数

\(y=\sin x,\ x=0,\ x=\pi\) で囲まれる部分の面積を求めよ（x 軸も境界とする）。

着眼点を見る
この区間では正弦は非負。
解答・詳しい解説を見る
この区間では正弦は非負。
\[S=\int_0^\pi\sin x\,dx=[-\cos x]_0^\pi=\boxed{2}\]

問題5　指数関数と直線

\(y=e^x,\ y=1,\ x=1\) で囲まれる部分の面積を求めよ。

着眼点を見る
交点は x=0。指数関数が上側。
解答・詳しい解説を見る
交点は x=0。指数関数が上側。
\[S=\int_0^1(e^x-1)\,dx=[e^x-x]_0^1=\boxed{e-2}\]

問題6　対数関数

\(y=\log x,\ x=1,\ x=e\) で囲まれる部分の面積を求めよ（x 軸も境界とする）。

着眼点を見る
部分積分を利用する。
解答・詳しい解説を見る
部分積分を利用する。
\[S=\int_1^e\log x\,dx=[x\log x-x]_1^e=\boxed{1}\]

問題7　符号の変化

\(y=x^3-x,\ x=-1,\ x=1\) と x 軸で囲まれる2つの部分の面積の和を求めよ。

着眼点を見る
x=0 で符号が変わる。奇関数の対称性を使う。
解答・詳しい解説を見る
x=0 で符号が変わる。奇関数の対称性を使う。
\[S=2\int_0^1(x-x^3)\,dx=2\left[\frac{x^2}{2}-\frac{x^4}{4}\right]_0^1=\boxed{\frac12}\]

応用問題（4問）

問題8　三角関数の交点

\(y=\sin x,\ y=\cos x,\ x=0\) で囲まれる部分の面積を求めよ。ただし、0≤x≤π/2 とする。

着眼点を見る
0≤x≤π/2 の範囲で交点は π/4。余弦が上側。
解答・詳しい解説を見る
0≤x≤π/2 の範囲で交点は π/4。余弦が上側。
\[S=\int_0^{\pi/4}(\cos x-\sin x)\,dx=[\sin x+\cos x]_0^{\pi/4}=\boxed{\sqrt2-1}\]

問題9　円の面積

\(x^2+y^2=4\) の内部の面積を求めよ。

着眼点を見る
第1象限の面積を4倍。x=2 sin t と置換する。
解答・詳しい解説を見る
第1象限の面積を4倍。x=2 sin t と置換する。
\[\begin{aligned}S&=4\int_0^2\sqrt{4-x^2}\,dx\\&=16\int_0^{\pi/2}\cos^2t\,dt=\boxed{4\pi}\end{aligned}\]

問題10　指数関数と接線

\(y=e^x,\ y=x+1,\ x=1\) で囲まれる部分の面積を求めよ。

着眼点を見る
凸性より指数関数が上側。接点は x=0。
解答・詳しい解説を見る
凸性より指数関数が上側。接点は x=0。
\[S=\int_0^1(e^x-x-1)\,dx=\left[e^x-\frac{x^2}{2}-x\right]_0^1=\boxed{e-\frac52}\]

問題11　対数関数と x 軸

\(y=\log x,\ x=\frac1e,\ x=e\) と x 軸で囲まれる部分の面積の和を求めよ。

着眼点を見る
x=1 で区間を分ける。
解答・詳しい解説を見る
x=1 で区間を分ける。
\[\begin{aligned}S&=-\int_{1/e}^1\log x\,dx+\int_1^e\log x\,dx\\&=1-\frac2e+1=\boxed{2-\frac2e}\end{aligned}\]

発展問題（3問）

問題12　媒介変数表示

\(x=t^2,\ y=t-t^2\quad(0\le t\le1)\) で表される曲線と x 軸で囲まれる部分の面積を求めよ。

着眼点を見る
x は単調増加。dx=2t dt として x 軸との面積を求める。
解答・詳しい解説を見る
x は単調増加。dx=2t dt として x 軸との面積を求める。
\[S=\int_0^1(t-t^2)2t\,dt=\left[\frac{2t^3}{3}-\frac{t^4}{2}\right]_0^1=\boxed{\frac16}\]

問題13　文字を含む面積

\(y=x^2,\ y=ax\quad(a>0)\) で囲まれる部分の面積を a で表せ。

着眼点を見る
交点は x=0,a。直線が上側。
解答・詳しい解説を見る
交点は x=0,a。直線が上側。
\[S=\int_0^a(ax-x^2)\,dx=\left[\frac{ax^2}{2}-\frac{x^3}{3}\right]_0^a=\boxed{\frac{a^3}{6}}\]

問題14　楕円の面積

\(\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\quad(a,b>0)\) の内部の面積を求めよ。

着眼点を見る
第1象限を4倍。x=a sin t と置換する。
解答・詳しい解説を見る
第1象限を4倍。x=a sin t と置換する。
\[\begin{aligned}S&=4\int_0^a b\sqrt{1-\frac{x^2}{a^2}}\,dx\\&=4ab\int_0^{\pi/2}\cos^2t\,dt=\boxed{\pi ab}\end{aligned}\]
