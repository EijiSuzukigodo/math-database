体積

数学Ⅲ ／ 高校生のための問題演習
演習のねらい

定積分を利用して立体の体積を求められるようになる

全14問（基本3問・標準4問・応用4問・発展3問）。回転体の断面積、外半径と内半径、回転軸、媒介変数表示を確認します。まず自分で考え、必要に応じて着眼点と詳しい解説を開いてください。

基本問題（3問）

問題1　円柱

\(y=2,\ 0\le x\le3\) と x 軸および区間の両端の直線で囲まれた領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
高さが一定の円柱。半径は2。
解答・詳しい解説を見る
高さが一定の円柱。半径は2。
\[V=\pi\int_0^3 4\,dx=\boxed{12\pi}\]

問題2　円すい

\(y=x,\ 0\le x\le3\) と x 軸および区間の両端の直線で囲まれた領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
断面の半径は x。
解答・詳しい解説を見る
断面の半径は x。
\[V=\pi\int_0^3 x^2\,dx=\pi\left[\frac{x^3}{3}\right]_0^3=\boxed{9\pi}\]

問題3　放物線

\(y=x^2,\ 0\le x\le2\) と x 軸および区間の両端の直線で囲まれた領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
半径の2乗は x の4乗。
解答・詳しい解説を見る
半径の2乗は x の4乗。
\[V=\pi\int_0^2 x^4\,dx=\pi\left[\frac{x^5}{5}\right]_0^2=\boxed{\frac{32\pi}{5}}\]

標準問題（4問）

問題4　平方根の関数

\(y=\sqrt{x},\ 0\le x\le4\) と x 軸および区間の両端の直線で囲まれた領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
半径を2乗すると x になる。
解答・詳しい解説を見る
半径を2乗すると x になる。
\[V=\pi\int_0^4 x\,dx=\pi\left[\frac{x^2}{2}\right]_0^4=\boxed{8\pi}\]

問題5　三角関数

\(y=\sin x,\ 0\le x\le\pi\) と x 軸および区間の両端の直線で囲まれた領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
半角の公式で正弦の2乗を積分する。
解答・詳しい解説を見る
半角の公式で正弦の2乗を積分する。
\[V=\frac{\pi}{2}\int_0^\pi(1-\cos 2x)\,dx=\boxed{\frac{\pi^2}{2}}\]

問題6　指数関数

\(y=e^x,\ 0\le x\le1\) と x 軸および区間の両端の直線で囲まれた領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
半径の2乗は指数が2倍になる。
解答・詳しい解説を見る
半径の2乗は指数が2倍になる。
\[V=\pi\int_0^1 e^{2x}\,dx=\frac{\pi}{2}[e^{2x}]_0^1=\boxed{\frac{\pi(e^2-1)}2}\]

問題7　穴のある回転体

\(y=x,\ y=x^2\) で囲まれる領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
交点は 0 と 1。外半径は x、内半径は x²。
解答・詳しい解説を見る
交点は 0 と 1。外半径は x、内半径は x²。
\[V=\pi\int_0^1(x^2-x^4)\,dx=\pi\left[\frac{x^3}3-\frac{x^5}5\right]_0^1=\boxed{\frac{2\pi}{15}}\]

応用問題（4問）

問題8　球

\(x^2+y^2=9\) の内部を x 軸のまわりに回転してできる立体の体積を求めよ。

着眼点を見る
上半円を回転すると球になる。断面積は π(9−x²)。
解答・詳しい解説を見る
上半円を回転すると球になる。断面積は π(9−x²)。
\[V=\pi\int_{-3}^3(9-x^2)\,dx=2\pi[9x-x^3/3]_0^3=\boxed{36\pi}\]

問題9　y軸のまわりの回転

\(y=x^2,\ x=0,\ y=4\) で囲まれる領域を y 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
高さ y の断面の半径は √y。
解答・詳しい解説を見る
高さ y の断面の半径は √y。
\[V=\pi\int_0^4 y\,dy=\boxed{8\pi}\]

問題10　断面が正方形の立体

x 軸に垂直な断面が正方形で、断面積が \(A(x)=(4-x^2)^2\quad(-2\le x\le2)\) である立体の体積を求めよ。

着眼点を見る
断面積を積分する。偶関数なので半分を2倍する。
解答・詳しい解説を見る
断面積を積分する。偶関数なので半分を2倍する。
\[V=2\int_0^2(16-8x^2+x^4)\,dx=2\left[16x-\frac{8x^3}{3}+\frac{x^5}{5}\right]_0^2=\boxed{\frac{512}{15}}\]

問題11　回転軸がずれる場合

\(y=x^2,\ y=0,\ x=1\) で囲まれる領域を直線 \(y=2\) のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
直線 y=2 を軸とすると外半径2、内半径2−x²。
解答・詳しい解説を見る
直線 y=2 を軸とすると外半径2、内半径2−x²。
\[V=\pi\int_0^1\{4-(2-x^2)^2\}\,dx=\pi\left[\frac{4x^3}{3}-\frac{x^5}{5}\right]_0^1=\boxed{\frac{17\pi}{15}}\]

発展問題（3問）

問題12　回転楕円体

\(\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\quad(a,b>0)\) の内部を x 軸のまわりに回転してできる立体の体積を求めよ。

着眼点を見る
断面積は πb²(1−x²/a²)。
解答・詳しい解説を見る
断面積は πb²(1−x²/a²)。
\[V=2\pi b^2\int_0^a\left(1-\frac{x^2}{a^2}\right)dx=\boxed{\frac{4\pi ab^2}{3}}\]

問題13　球冠の体積

\(x^2+y^2=R^2,\ R-h\le x\le R\quad(0<h<R)\) の条件を満たす円の内部を x 軸のまわりに回転してできる球冠の体積を求めよ。

着眼点を見る
半径の2乗は R²−x²。積分区間に注意。
解答・詳しい解説を見る
半径の2乗は R²−x²。積分区間に注意。
\[\begin{aligned}V&=\pi\int_{R-h}^R(R^2-x^2)\,dx\\&=\pi\left[R^2x-\frac{x^3}{3}\right]_{R-h}^R\\&=\boxed{\pi h^2\left(R-\frac h3\right)}\end{aligned}\]

問題14　媒介変数表示

\(x=t^2,\ y=t-t^2\quad(0\le t\le1)\) で表される曲線と x 軸で囲まれる領域を x 軸のまわりに1回転してできる立体の体積を求めよ。

着眼点を見る
x は単調増加し、dx=2t dt。半径は t−t²。
解答・詳しい解説を見る
x は単調増加し、dx=2t dt。半径は t−t²。
\[\begin{aligned}V&=\pi\int_0^1(t-t^2)^2\cdot2t\,dt\\&=2\pi\left[\frac{t^4}{4}-\frac{2t^5}{5}+\frac{t^6}{6}\right]_0^1=\boxed{\frac{\pi}{30}}\end{aligned}\]
