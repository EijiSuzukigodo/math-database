教科書対応：複素数平面

1. 複素数と点の対応

複素数 z = a + bi には、平面上の点 (a, b) を対応させます。横軸が実軸、縦軸が虚軸です。すべての複素数は平面のただ一つの点に対応します。

z = a + bi　⟷　点 (a, b)

実部は a、虚部は b です。例えば 3 + 2i は点 (3, 2) に対応し、−2 − i は点 (−2, −1) に対応します。

z = 3 + 2i

原点は 0、実軸上の複素数は実数、虚軸上の原点以外の点は純虚数です。

確認：実部が −3、虚部が 2 の複素数は何ですか？
−3 + 2i です。対応する点は (−3, 2) です。
教科書対応：複素数の実数倍

2. 実数倍で点はどう動く？

複素数 z = 2 + i に実数 k をかけると、kz = 2k + ki です。原点からの向きと距離に注目しましょう。

k > 0：同じ向き　／　k = 0：原点　／　k < 0：反対向き

kz = 3 + 1.5i

なぜ同一直線上にあるのでしょう。z = a + bi なら kz = ka + (kb)i で、点 (a,b) の両座標を同じ k 倍にするためです。
教科書対応：加法・減法

3. 加法と減法の幾何学的意味

複素数の和は、対応する矢印をつなぐことで表せます。平行四辺形の対角線が α + β に対応します。

α = 2 + i、β = 1 + 2i　⇒　α + β = 3 + 3i

α + β = 3 + 3i

差 α − β は、「β を取り消す向き」つまり −β を加えることと同じです。点 β から点 α への矢印にも対応します。

α = a + bi、β = c + di とすると、α ± β = (a ± c) + (b ± d)i。実部と虚部をそれぞれ計算します。
教科書対応：共役な複素数

4. 共役複素数と対称移動

z = a + bi の共役複素数は z̄ = a − bi です。虚部の符号だけが反対になります。図では実軸に関する鏡映です。

z̄ = a − bi ／ z + z̄ = 2a ／ z − z̄ = 2bi ／ z z̄ = a² + b²

z = 2 + 3i ／ z̄ = 2 − 3i

証明：z = a + bi とすると (a + bi)(a − bi) = a² − (bi)² = a² + b²。ここで i² = −1 を使いました。

−z は原点対称、−z̄ は虚軸対称。これらを混同しないようにしましょう。

教科書対応：絶対値

5. 複素数の絶対値

複素数 z = a + bi の絶対値 |z| は、複素数平面の原点から点 (a,b) までの距離です。三平方の定理から求められます。

|z| = √(a² + b²) ／ |z|² = z z̄

|3 + 4i| = 5

たとえば z = 3 + 4i のとき、|z| = √(9 + 16) = 5 です。実数の絶対値とも自然につながります。
教科書対応：2点間の距離

6. 2点間の距離は差の絶対値

点 A(α)、B(β) に対応する複素数があるとき、AB の長さは |β − α| です。引き算によって原点からのベクトルに直しているのです。

AB = |β − α|

点 A は α = −1 − i に固定しています。

AB = 5

A = (a,b)、B = (c,d) なら AB = √((c−a)² + (d−b)²) = |(c+di)−(a+bi)| となります。
練習・理解の確認

7. 自分で考えてみよう

問1　z = −2 + 3i に対応する点、実部、虚部を答えましょう。
点 (−2,3)、実部 −2、虚部 3 です。
問2　α = 1 − 2i、β = −3 + i のとき、α + β、α − β を求めましょう。
α + β = −2 − i、α − β = 4 − 3i。実部同士、虚部同士を計算します。
問3　z = −4 + 3i の共役複素数と絶対値を求めましょう。
共役複素数は −4 − 3i、絶対値は √(16+9) = 5 です。
問4　α = 1 + 2i、β = 4 − 2i の間の距離を求めましょう。
β−α = 3−4i より、距離は |3−4i| = 5 です。

まとめ

複素数は単なる計算の道具ではなく、点や矢印として図形的に考えられます。この見方が、次の第2講「極形式・乗法と除法」に進むための土台です。
