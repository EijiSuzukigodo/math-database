1. 極形式と複素数の積を復習しよう

0でない複素数 z の絶対値を r、偏角を θ とすると、極形式は次のように表せます。

z = r(cos θ + i sin θ)　（r > 0）

2つの複素数 z₁=r₁(cos α+i sin α) と z₂=r₂(cos β+i sin β) の積は、三角関数の加法定理を使うと次の形になります。

z₁z₂ = r₁r₂ {cos(α+β) + i sin(α+β)}

絶対値は掛け算、偏角は足し算。 これがド・モアブルの定理の土台です。

2. ド・モアブルの定理と証明

{cos θ + i sin θ}ⁿ = cos(nθ) + i sin(nθ)

n が整数のとき成立します。したがって一般の複素数については次のようになります。

{r(cos θ + i sin θ)}ⁿ = rⁿ{cos(nθ) + i sin(nθ)}

まず自然数 n の場合を証明

  1. n = 1 のとき、両辺は同じなので成立します。
  2. n = k で成り立つと仮定します。
    (cos θ + i sin θ)ᵏ = cos(kθ) + i sin(kθ)
  3. 両辺に cos θ + i sin θ を掛け、積の公式を使うと
    (cos θ + i sin θ)ᵏ⁺¹ = cos((k+1)θ) + i sin((k+1)θ)
  4. 数学的帰納法により、すべての自然数 n で成立します。

0と負の整数の場合

0でない複素数の0乗は1です。負の整数については逆数の偏角が −θ になることを用いれば示せます。

3. 累乗を動く図で理解しよう

橙色：z（もとの複素数）　青色：zⁿ（累乗後）

偏角を動かすと、累乗後の点は元の点よりn倍の角度だけ回ります。絶対値が1でない場合は、距離も rⁿ に変わることを確かめましょう。

4. 1の n 乗根はどこにある？

zⁿ = 1 を満たす複素数は、単位円上に n 個あります。1の偏角は2πの整数倍なので、解の偏角は次のようになります。

zₖ = cos(2πk/n) + i sin(2πk/n)
（k = 0, 1, …, n−1）

たとえば n=6 のとき、単位円周上の6個の点は、中心角60°ずつ等間隔に並びます。これらは正六角形の頂点です。

すべての解が異なる理由：2πk/n は k=0,…,n−1 の範囲で、互いに2πの整数倍だけ異なることがありません。

5. 一般の方程式 zⁿ = a を解こう

右辺を a=R(cos φ+i sin φ)（R>0）とすると、n個の解は次の形です。

zₖ = R¹⁄ⁿ {cos((φ+2πk)/n) + i sin((φ+2πk)/n)}
（k = 0, 1, …, n−1）

例題：z² = 1 + √3 i

右辺の絶対値は2、偏角はπ/3です。したがって各解の絶対値は√2、偏角はπ/6と7π/6です。

z = √2 {cos(π/6)+i sin(π/6)}
または
z = √2 {cos(7π/6)+i sin(7π/6)}

直交形式で書くと、z = (√6 + √2 i)/2 または z = (−√6 − √2 i)/2 です。

6. 例題・演習問題

教科書と同じ学習事項を扱う、独自の問題です。答えを見る前に紙に計算してみましょう。

問題1： z = cos(π/5) + i sin(π/5) のとき、z⁵ を求めよ。

ド・モアブルの定理より、z⁵ = cos π+i sin π = −1。

問題2： (1+i)⁸ を求めよ。

1+i=√2{cos(π/4)+i sin(π/4)} なので、8乗すると (√2)⁸{cos 2π+i sin 2π}=16。

問題3： z⁴ = 1 を満たすすべての複素数を求めよ。

zₖ = cos(kπ/2)+i sin(kπ/2)（k=0,1,2,3）より、1、i、−1、−i。

問題4： z³ = −8 を解け。

−8=8{cos π+i sin π} なので、絶対値2、偏角は π/3、π、5π/3。したがって 1+√3 i、−2、1−√3 i。

問題5： 1の5乗根を複素数平面に描くと、どのような図形になるか。

単位円に内接する正五角形の頂点。隣り合う偏角の差は 2π/5=72°。

学習のまとめ

複素数の積は回転と拡大・縮小を表します。ド・モアブルの定理は、その性質を繰り返し用いた結果です。n乗根は、角度を等分することで求められます。
