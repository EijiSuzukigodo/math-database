複素数平面では、複素数が点の位置を表し、差の絶対値が２点間の距離を表します。この２つの見方を使うと、内分点・外分点・直線・円・軌跡を１つの考え方で理解できます。

この教材は教科書の学習範囲を参考に、説明・図・例題を独自に構成したものです。教科書の紙面を複製したものではありません。

教科書対応：線分の内分点・外分点

1. 線分の内分点・外分点

２点 A(α)、B(β) を結ぶ線分を、AP:PB = m:n の比で内分する点 P を考えます。内分点は、A と B の間にあります。

p = (nα + mβ) / (m+n)

例えば、α=1+i、β=5+3i を 1:3 に内分すると、

p = (3(1+i) + (5+3i)) / 4 = 2 + 1.5i

外分点 Q は直線 AB 上の線分の外側にあり、m≠n のとき、次の式で表せます。

q = (mβ − nα) / (m−n)　(m ≠ n)

● A・Bは固定。青いPが内分点、赤いQが外分点です。m=nでは外分点が有限の位置に存在しません。

なぜこの式になるのか

ベクトルで考えれば、内分点について p = α + [m/(m+n)](β−α) です。分母を払って整理すると上の公式が得られます。外分も同様に、AからBへの向きに延長して考えると求められます。

教科書対応：直線と円の方程式

2. 距離を用いて直線や円を表す

複素数 z と α が表す２点の距離は |z−α| です。したがって、α を中心とする半径 r の円は、次の式になります。

|z − α| = r　(r > 0)

また、異なる２点 α、β から等距離にある点 z 全体は、線分 AB の垂直二等分線です。

|z − α| = |z − β|

式を座標で確かめる

z=x+yi、α=a+bi とすれば、|z−α|=r を両辺２乗して、(x−a)²+(y−b)²=r²。これは、座標平面で学ぶ円の標準形と同じです。

教科書対応：アポロニウスの円

3. ２点からの距離の比が一定の軌跡

異なる２点 A(α)、B(β) に対して、|z−α|=k|z−β| を満たす点 z の集合を考えます。k=1 なら垂直二等分線、k≠1 なら円です（k>0）。後者をアポロニウスの円といいます。

|z − α| = k |z − β|

α=−2、β=2 と置き、z=x+yi として２乗して整理すると、k≠1 のとき円になります。

(x + 2)² + y² = k²{(x − 2)² + y²}

k=1 では直線、それ以外では円になることを見比べましょう。大きな円は画面の外まで広がります。

計算の要点

両辺を２乗して展開し、x²+y² の係数がゼロかどうかを調べます。k=1 なら２次項が消えて直線に、k≠1 なら平方完成で円の方程式に変形できます。

復習：複素数の積と回転

4. 複素数の積で図形を回転する

複素数 z に、絶対値が1の複素数 cosθ+i sinθ を掛けると、原点からの距離を変えずに、偏角を θ だけ増やすことができます。

w = (cosθ + i sinθ) z

点 z=3+i が、青い矢印の点 w に回転します。回転前後で原点からの距離は同じです。

原点以外の点 α を中心に回転する場合は、一度 α を引き、回転してから α を足します。w = α + (cosθ+i sinθ)(z−α)。

理解度チェック

5. 例題・練習問題

例題1　中点を求める

複素数 α=2+i、β=−4+3i が表す２点の中点を求めましょう。

解答と解説を表示
中点 p=(α+β)/2 だから、p=[(2+i)+(−4+3i)]/2=−1+2i。

例題2　円の中心と半径

|z−(1−2i)|=3 を満たす点の集合を図形で説明しましょう。

解答と解説を表示
中心が (1,−2)、半径が3の円。z=x+yi と置けば (x−1)²+(y+2)²=9 です。

例題3　距離が等しい点の軌跡

|z−2|=|z+2| を満たす点 z=x+yi の集合を求めましょう。

解答と解説を表示
(x−2)²+y²=(x+2)²+y² より −4x=4x、ゆえに x=0。虚軸全体です。

例題4　アポロニウスの円

|z+2|=2|z−2| を満たす点の集合を求めましょう。

解答と解説を表示
(x+2)²+y²=4{(x−2)²+y²} より 3x²+3y²−20x+12=0。平方完成して (x−10/3)²+y²=(8/3)²。中心 (10/3,0)、半径 8/3 の円です。

例題5　回転する点

z=1+i を原点中心に90°反時計回りに回転した点を求めましょう。

解答と解説を表示
i(1+i)=−1+i。座標では (1,1) が (−1,1) に移ります。
