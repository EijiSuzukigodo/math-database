数学C・平面上の曲線｜第1講 放物線

焦点・準線・方程式を、証明と動く図で理解する

今日の目標

放物線は、「ある定点（焦点）」と「ある定直線（準線）」からの距離が等しい点の集まりです。この定義から方程式を自分で導き、放物線の向きや広がりを説明できるようになりましょう。

公式の導出動く図例題と演習

1. 定義から公式を導く

① 縦向きの放物線

焦点を F(0, p)、準線を y = −p とします。点 P(x, y) が放物線上にあるための条件は、焦点までの距離と準線までの距離が等しいことです。

√[x² + (y − p)²] = |y + p|

両辺を2乗して展開すると、

x² + y² − 2py + p² = y² + 2py + p²
∴ x² = 4py

逆に、p ≠ 0 のもとでこの方程式を満たす点は、距離の平方が等しいため、焦点と準線から等距離にあります。したがって、これは放物線の方程式です。

頂点は原点。p が正なら上向き、負なら下向きです。

② 横向きの放物線

焦点を F(p, 0)、準線を x = −p とすると、同様に

√[(x − p)² + y²] = |x + p|
∴ y² = 4px

p が正なら右向き、負なら左向きの放物線になります。

※ p = 0 では焦点が準線上に位置するため、この教材では p = 0 を除いて考えます。

2. 動く図で焦点と準線を確かめる

向きを変え、p の大きさや符号を変えてください。曲線上の赤い点 P から、焦点 F と準線上の垂線の足 H までの距離が等しいことを確認できます。

青：放物線　橙：焦点 F　緑の破線：準線　赤：点 P　紫の線：距離 PF と PH

p のスライダーが0になる場合、図では0.25に自動調整します。

3. 公式の見分け方

縦向き

x² = 4py

焦点 (0, p)、準線 y = −p

2乗されるのは x です。

横向き

y² = 4px

焦点 (p, 0)、準線 x = −p

2乗されるのは y です。

放物線の式を覚えるときは、どの文字が2乗されているかに注目します。エックスの2乗が4ピー・ワイなら縦向き。ワイの2乗が4ピー・エックスなら横向きです。ピーの符号によって開く方向が変わります。

4. 例題と練習問題

例題1　x² = 8y の焦点と準線を求めましょう。
解答・解説を見る

4p = 8 より p = 2。焦点は (0, 2)、準線は y = −2 です。

例題2　焦点 F(−3, 0)、準線 x = 3 の放物線の方程式を求めましょう。
解答・解説を見る

p = −3 なので、y² = 4px より y² = −12x です。左向きの放物線になります。

練習1　y² = 12x の焦点と準線を求めましょう。
解答・解説を見る

4p = 12 なので p = 3。焦点は (3, 0)、準線は x = −3 です。

練習2　焦点 F(0, −2)、準線 y = 2 の放物線の方程式を求めましょう。
解答・解説を見る

p = −2 より、x² = −8y です。

例題の解き方を確認しましょう。標準形の4ピーの値を係数から読み取り、4で割ればピーが求まります。ピーが分かれば、焦点と準線はすぐに決まります。最後に、グラフがどちらに開くかも確認しましょう。

5. まとめ

放物線は焦点と準線から等距離にある点の軌跡です。x² = 4py と y² = 4px の違いを、焦点と準線の向きから説明できれば、暗記に頼らず理解できます。
