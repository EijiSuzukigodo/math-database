数学C 第2講｜楕円の定義と方程式

平面上の曲線　｜　焦点・長軸と短軸・円の伸縮・軌跡

教科書の学習順に沿った独自解説。グラフは指で操作でき、日本語読み上げも利用できます。

学習の道順

① 楕円の定義　→　② 方程式の導出　→　③ 縦長の楕円　→　④ 円の伸縮　→　⑤ 内分点の軌跡　→　⑥ 練習問題

定義と動く図方程式の導出縦長の楕円円の伸縮軌跡練習問題
1　楕円の定義

2つの焦点からの距離の和が一定

異なる2点 F₁, F₂ からの距離の和が一定 2a となる点 P の軌跡を、楕円といいます。焦点を F₁(−c, 0), F₂(c, 0) として考えます。

PF₁ + PF₂ = 2a　（a > c > 0）

計算中…

青い曲線が楕円です。オレンジ色と緑色の線分を合わせた長さは、Pをどこへ動かしても 2a のままです。焦点間の距離が大きいほど細長い楕円になります。

2　公式の導出

楕円の方程式を定義から導こう

焦点を F₁(−c, 0), F₂(c, 0) とし、P(x, y) から焦点までの距離をそれぞれ r₁, r₂ とおきます。

r₁ = √{(x+c)² + y²},　r₂ = √{(x−c)² + y²}

①定義より r₁ + r₂ = 2a です。

②平方の差を計算すると、r₁² − r₂² = 4cx です。そこで

(r₁ − r₂)(r₁ + r₂) = 4cx
r₁ − r₂ = 2cx/a

③和と差を解くと、r₁ = a + cx/a、r₂ = a − cx/a が得られます。

④例えば r₁² = (x+c)² + y² に代入して整理すると、

a²y² + (a²−c²)x² = a²(a²−c²)

ここで b² = a² − c² とおくと、標準形になります。

x²/a² + y²/b² = 1
（a > b > 0、c² = a² − b²）

逆に、この式上の点では上の距離の式が成立し、2つの焦点からの距離の和が 2a になります。

長軸と短軸

横長の楕円では長軸は x 軸方向で長さ 2a、短軸は y 軸方向で長さ 2b です。

中心・頂点・対称性

中心は原点。頂点は (±a, 0) と (0, ±b)。x 軸、y 軸、原点について対称です。

3　縦長の楕円

長軸が y 軸上にある場合

長半径が b、短半径が a（b > a > 0）の場合も同じ考え方です。焦点は (0, ±c)、ただし c² = b² − a² です。

x²/a² + y²/b² = 1　（b > a > 0）

例題1：横長

x²/9 + y²/4 = 1

a=3、b=2、c=√(9−4)=√5

焦点：(±√5, 0)、長軸 6、短軸 4。

例題2：縦長

x²/9 + y²/16 = 1

長半径 4、短半径 3、c=√(16−9)=√7

焦点：(0, ±√7)、長軸 8、短軸 6。

4　円と楕円

円を縮小・拡大すると楕円になる

円 x²+y²=9 の各点の y 座標を k 倍してみましょう。新しい点を (X,Y) とすると X=x、Y=ky より、

X²/9 + Y²/(3k)² = 1

灰色の破線：元の円／青色：伸縮後。k=1 では円、k が1未満なら横長、1より大きければ縦長になります。

5　軌跡と楕円

線分の内分点が描く軌跡

長さ L=5 の線分 AB の端点 A は x 軸上、端点 B は y 軸上を動きます。P は AB を AP:PB = 2:3 に内分するとします。

A=(s, 0)、B=(0, t) とすれば、s²+t²=25。内分点の公式から P=(3s/5, 2t/5) なので、

x²/3² + y²/2² = 1

点Pの軌跡は、半径 3 と 2 の楕円です。内分点の位置を座標で表し、端点の条件を代入するのがポイントです。

6　例題・確認問題

解いて理解を確かめよう

問題1　焦点と軸の長さ

x²/25 + y²/9 = 1 の焦点、長軸・短軸の長さを求めましょう。

解答と考え方を表示

a=5、b=3。c²=25−9=16 より c=4。焦点は (±4,0)、長軸は 10、短軸は 6 です。

問題2　定義から方程式

焦点が (±3,0)、2つの焦点からの距離の和が10の楕円の方程式を求めましょう。

解答と考え方を表示

2a=10 より a=5。c=3 なので b²=25−9=16。答えは x²/25 + y²/16 = 1 です。

問題3　縦長の楕円

9x²+4y²=36 の焦点を求めましょう。

解答と考え方を表示

x²/4+y²/9=1 だから長半径は3、短半径は2。c²=9−4=5。焦点は (0,±√5) です。

※図の数値は学習用に四捨五入して表示しています。楕円が円になる場合など、特別な場合もスライダーで試してみましょう。

学習のまとめ

楕円は2焦点からの距離の和が一定の点の集まり。標準形と焦点、長軸・短軸の関係を押さえ、円の伸縮や内分点の軌跡とも結び付けましょう。
