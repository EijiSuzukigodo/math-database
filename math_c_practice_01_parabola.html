第1回 放物線の基本問題

数学C｜平面上の曲線｜全5問・ヒントと詳しい解答付き

学習の進め方

問題を自分で考えた後に「ヒントを見る」を開き、それでも難しい場合は「解答・解説を見る」を押しましょう。下のグラフで、焦点・準線と放物線の関係を動かして確認できます。

この教材は授業第1講「放物線と焦点・準線」の内容に対応しています。

動く図で理解する：放物線と焦点・準線

下の図は \(y^{2} = 4px\)（\(p > 0\)）の放物線です。青い点Pと赤い焦点F、緑の準線を確認しましょう。

点P焦点F準線距離

y² = 8x

焦点：F(p, 0)
準線：\(x = -p\)
点P：\((\frac{y^{2}}{4}p, y)\)

※ この図は定義を学ぶためのモデルです。pは正の数とし、放物線上の点Pから焦点・準線までの距離が等しいことを確認できます。

基本問題 1

焦点と準線から方程式を求める

焦点が \(F(2, 0)\)、準線が \(x = -2\) の放物線の方程式を求めなさい。

ヒントを見る

焦点が (p, 0)、準線が \(x = -p\) のとき、方程式は \(y^{2} = 4px\) です。p の値を決めましょう。

解答・詳しい解説を見る

焦点が \((2, 0)\) だから \(p = 2\) です。準線 \(x = -2\) とも一致します。

公式 \(y^{2} = 4px\) に代入して、\(y^{2} = 4 \times 2 \times x = 8x\)。

答え：\(y^{2} = 8x\)
基本問題 2

方程式から焦点と準線を求める

放物線 \(y^{2} = 12x\) の焦点と準線を求めなさい。

ヒントを見る

\(y^{2} = 4px\) と比較すると、\(4p = 12\) です。

解答・詳しい解説を見る

\(4p = 12\) より \(p = 3\)。焦点は (p, 0)、準線は \(x = -p\) です。

答え：焦点 \((3, 0)\)、準線 \(x = -3\)
基本問題 3

左に開く放物線

焦点が \(F(-1, 0)\)、準線が \(x = 1\) の放物線の方程式を求めなさい。

ヒントを見る

左に開くときも \(y^{2} = 4px\) の形を使えます。ただし p は負の値になります。

解答・詳しい解説を見る

焦点は (p, 0) なので \(p = -1\)。準線 \(x = -p = 1\) と一致します。これを代入すると \(y^{2} = 4(-1)x\)。

答え：\(y^{2} = -4x\)

動く図では右に開く場合（\(p > 0\)）を示しています。左に開く場合は \(p < 0\) に対応します。

標準への橋渡し 4

頂点が原点でない放物線

頂点が \(V(1, -2)\)、焦点が \(F(1, 0)\) の放物線の方程式を求めなさい。

ヒントを見る

頂点 (h, k) から上へ距離 p のところに焦点がある放物線は \((x - h)^{2} = 4p(y - k)\) です。

解答・詳しい解説を見る

頂点 \((1, -2)\) から焦点 \((1, 0)\) までは上向きに 2 進むので \(p = 2\) です。

\((x - h)^{2} = 4p(y - k)\) に \(h = 1\)、\(k = -2\)、\(p = 2\) を代入します。

答え：\((x - 1)^{2} = 8(y + 2)\)

準線は頂点から下へ 2 の位置なので \(y = -4\) です。

確認問題 5

通る点から係数を求める

放物線 \(y^{2} = 4px\) が点 \((2, 4)\) を通るとき、p の値と放物線の方程式を求めなさい。

ヒントを見る

\(x = 2\)、\(y = 4\) を式に代入しましょう。

解答・詳しい解説を見る

\(4^{2} = 4p \times 2\) より \(16 = 8p\) です。したがって \(p = 2\)。

答え：\(p = 2\)、\(y^{2} = 8x\)

このとき焦点は \((2, 0)\)、準線は \(x = -2\) です。
