数学Ⅰ

各章の授業を教科書形式で学べます。定義・証明・図・例題・練習問題と解説を順に確認しましょう。

第1章 数と式

  • 多項式の基礎 →

    ▶ 多項式の基礎（11枚・自動スライド授業）を見る →

    文字式の用語と次数を丁寧に整理し、同類項をまとめる手順を学びます。

    ▶ この単元のビデオ授業を見る →

  • 多項式の加法・減法・乗法 →

    符号の扱い、指数法則、分配法則と展開の工夫を式変形から理解します。

  • 乗法公式と因数分解 →

    乗法公式、因数分解の公式、共通因数による因数分解、2次式の因数分解、3次式の展開と因数分解まで教科書風に詳しく学びます。

  • 実数 →

    有理数・無理数、循環小数、数直線、絶対値を丁寧に学びます。

  • 根号を含む式の計算 →

    平方根、根号の四則計算、分母の有理化、式の値、二重根号まで学びます。

  • 一次不等式 →

    不等式の性質・解法・連立一次不等式を、数直線と詳しい途中計算で学びます。

  • 一次不等式の応用 →

    文章題・整数条件・絶対値を含む方程式と不等式を、場合分けして学びます。

第2章 集合と命題

  • 集合 →

    集合の表し方・部分集合・共通部分・和集合・補集合・ド・モルガンの法則をベン図で学びます。

  • 命題と条件 →

    命題の真偽・条件の包含関係・必要条件と十分条件・条件の否定を学びます。

  • 命題と証明 →

    逆・裏・対偶の関係、対偶を用いた証明、背理法を丁寧に学びます。

第3章 2次関数

  • 関数とグラフ →

    関数の意味、定義域・値域、座標とグラフの読み取りを学びます。

  • 2次関数とグラフ →

    放物線の形、係数による開き方の変化、平行移動、平方完成と頂点を学びます。

  • 2次関数の最大と最小 →

    定義域の有無と場合分けに注目し、最大値・最小値をグラフで求めます。

  • 2次関数の決定 →

    頂点・軸・通る点・3点などの条件から2次関数の式を決めます。

  • 2次方程式 →

    因数分解・平方完成・解の公式とその導出、判別式による実数解の個数を学びます。

  • グラフと2次方程式 →

    放物線とx軸の交点、判別式、放物線と直線の共有点・接する条件をグラフで学びます。

  • グラフと2次不等式 →

    放物線の正負を用いた2次不等式、重解・実数解なしの場合、連立不等式と応用を学びます。

  • 2次関数の応用問題 →

    長方形の面積や売上の最大化、定義域が動く場合の最大値・最小値を、動くグラフと例題で学びます。

第4章 図形と計量

  • 三角比 →

    直角三角形の三角比、30°・45°・60°の値、三角比の表、測量への応用を学びます。

  • 三角比の相互関係 →

    三角比の相互関係を証明し、補角の公式や値の計算に応用します。

  • 三角比の拡張 →

    半円と座標を使って三角比を0°から180°へ拡張し、符号・値・グラフを学びます。

  • 正弦定理 →

    外接円を動かして公式を確かめ、基本の証明・例題・発展まで学びます。

  • 余弦定理 →

    辺と角を動かして余弦定理を理解し、鋭角・直角・鈍角の場合を比較します。

  • 正弦定理と余弦定理の応用 →

    定理を組み合わせた問題、内接円、ヘロンの公式、円に内接する四角形を学びます。

  • 三角形の面積 →

    高さ・三角比・内接円・ヘロンの公式を動く図形と例題で学びます。

  • 空間図形への応用 →

    三角比は高さ、距離、傾斜などの計測にも使えます。

第5章 データの分析

  • データの整理 →

    度数分布表・相対度数・ヒストグラムを動く図で学びます。

  • データの代表値 →

    平均値・中央値・最頻値の違いをデータを変えて確かめます。

  • データの散らばりと四分位範囲 →

    範囲・四分位数・四分位範囲・箱ひげ図を学びます。

  • 分散と標準偏差 →

    偏差・分散・標準偏差を教科書形式で学び、データの変換と総合演習まで取り組みます。

  • 2つの変量の間の関係 →

    散布図・正負の相関・共分散・相関係数を、動く散布図と例題で学びます。

  • 仮説検定の考え方 →

    帰無仮説・有意水準・確率による判断を、例題と動く確率分布で学びます。
