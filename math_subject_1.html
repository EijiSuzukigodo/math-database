数学Ⅰ

教科書の目次に沿った全5章・全28講。基本の定義から公式の説明、例題、練習問題まで順番に学べます。

第1章 数と式（6講）

  • 多項式の計算 →

    同類項をまとめ、分配法則を用いて多項式を整理します。

  • 乗法公式と因数分解 →

    展開と因数分解は逆向きの操作です。積の形に直すと方程式にも役立ちます。

  • 実数と平方根 →

    数直線上に表せる数を実数といいます。有理数と無理数に分類できます。

  • 根号を含む計算と分母の有理化 →

    根号の積・商と、分母を有理化する計算を学びます。

  • 一次不等式 →

    不等号を含む式の両辺に同じ操作を行い、解の範囲を求めます。

  • 絶対値と場合分け →

    絶対値は数直線上の距離を表すので、正負で場合分けします。

第2章 集合と命題（3講）

  • 集合とその表し方 →

    ある条件を満たすものの集まりを集合といい、要素の列挙や条件で表します。

  • 命題と条件 →

    真偽が定まる文を命題といいます。仮定と結論、逆・裏・対偶を整理しましょう。

  • 必要条件・十分条件と証明 →

    二つの条件の包含関係から、必要条件と十分条件を判断します。

第3章 2次関数（6講）

  • 関数と2次関数のグラフ →

    2次関数のグラフは放物線で、軸と頂点が特徴です。

  • 平方完成とグラフの移動 →

    一般形を平方完成すると、頂点と開く向きが見えてきます。

  • 2次関数の最大値・最小値 →

    定義域が区間のとき、頂点と区間の両端の値を比較します。

  • 2次方程式と解の公式 →

    2次方程式の解は因数分解、平方完成、解の公式で求めます。

  • 判別式とグラフの交点 →

    判別式は実数解の個数、すなわちx軸との交点の個数を決めます。

  • 2次不等式 →

    2次関数の正負をグラフの上下で判断して解きます。

第4章 図形と計量（7講）

  • 三角比の定義 →

    直角三角形の辺の比を使い、正弦・余弦・正接を定義します。

  • 三角比の相互関係 →

    三角比の三つの値は独立ではなく、関係式でつながっています。

  • 鈍角までの三角比 →

    座標平面の単位円を使うと、三角比を0°から180°へ拡張できます。

  • 正弦定理 →

    三角形の辺と向かい合う角の正弦には一定の比があります。

  • 余弦定理 →

    三平方の定理を一般の三角形へ拡張するのが余弦定理です。

  • 三角形の面積 →

    2辺とその間の角が分かれば面積が求まります。

  • 空間図形への応用 →

    三角比は高さ、距離、傾斜などの計測にも使えます。

第5章 データの分析（6講）

  • データの整理と代表値 →

    平均値・中央値・最頻値は、データの中心を異なる方法で表します。

  • 四分位数と箱ひげ図 →

    データの散らばりを四分位範囲で読み取ります。

  • 分散と標準偏差 →

    データの平均からのずれを2乗し、その平均をとると分散です。

  • 散布図と相関係数 →

    2変量の関係を散布図で調べ、相関係数で直線的な傾向を表します。

  • 仮説検定の考え方 →

    仮説と観測結果を比較し、偶然では説明しにくいかを判断します。

  • データの変換と総合演習 →

    すべてのデータに定数を足す・掛けると、平均と分散は規則的に変わります。
