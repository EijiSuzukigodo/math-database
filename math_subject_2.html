数学Ⅱ

教科書の目次に沿った全6章・全37教材。基本事項、公式の導出、例題、練習問題を順番に学べます。

第1章 式と証明

  • 3次式の展開と因数分解 →

    三次の乗法公式を理解し、展開と因数分解を往復する。

  • 二項定理 →

    二項係数を使って高次の展開を整理する。

  • 整式の除法 →

    整式も筆算で除算でき、商と余りに分けられる。

  • 分数式の計算 →

    分母をそろえて整理し、約分の条件も確認する。

  • 恒等式と係数比較 →

    すべての x について成立する等式が恒等式である。

  • 等式の証明と不等式の証明 →

    式変形の根拠を明示し、非負量を利用する。

第2章 複素数と方程式

  • 複素数の導入 →

    実数だけでは解けない方程式を扱うため、虚数単位を導入する。

  • 2次方程式の解と判別式 →

    判別式が負でも、複素数の範囲なら解を表せる。

  • 解と係数の関係 →

    二次方程式の2つの解の和と積を係数から求める。

  • 剰余の定理と因数定理 →

    剰余の定理・因数定理・組立除法を学ぶ。

  • 高次方程式 →

    3次・4次方程式、重解、複素数の解と係数の関係を学ぶ。

第3章 図形と方程式

  • 直線上の点 →

    数直線上の距離、内分点・外分点、中点

  • 平面上の点 →

    2点間の距離、内分点・外分点、重心、対称な点

  • 直線の方程式 →

    傾き、2点を通る直線、一般形

  • 2直線の関係 →

    平行・垂直・交点、点と直線の距離

  • 円の方程式 →

    中心からの距離が一定の点の集合を式で表す。

  • 2つの円 →

    2つの円の位置関係、共有点、共通弦、交点を通る円の方程式を学びます。

  • 軌跡と方程式 →

    条件を満たす点の集合を方程式で表す。

  • 不等式の表す領域 →

    不等式を満たす点の領域を座標平面で理解する。

第4章 三角関数

  • 一般角と弧度法 →

    度数法と弧度法の対応を理解する。

  • 三角関数の定義と性質 →

    単位円の座標から正弦・余弦を定める。

  • 三角関数のグラフ →

    周期、振幅、平行移動からグラフを読む。

  • 三角関数の方程式・不等式 →

    単位円を用いて範囲内の解を探す。

  • 加法定理 →

    角の和や差の三角関数を展開する。

  • 2倍角・半角の公式 →

    加法定理から様々な変形公式を導く。

  • 三角関数の合成 →

    正弦と余弦の和を1つの三角関数で表す。

第5章 指数関数と対数関数

  • 指数の拡張と指数法則 →

    指数を整数・有理数・実数へ拡張する。

  • 指数関数のグラフ →

    底によって増減が変わる指数関数を理解する。

  • 対数の定義と性質 →

    指数と対数は互いに逆の操作である。

  • 対数関数とグラフ →

    対数関数は指数関数の逆関数である。

  • 常用対数と桁数 →

    10を底とする対数で桁数を調べる。

第6章 微分法と積分法

  • 微分係数と導関数 →

    平均変化率の極限から瞬間の変化率を定義する。

  • 導関数の計算 →

    多項式の微分を規則に従って計算する。

  • 接線の方程式 →

    微分係数は曲線上の接線の傾きである。

  • 関数の増減・極値 →

    導関数の符号から増減表を作る。

  • 原始関数と不定積分 →

    微分の逆操作として不定積分を導入する。

  • 定積分と面積 →

    原始関数の端点での差から定積分を求める。

  • 放物線と直線で囲まれる面積 →

    上下の関数の差を積分して面積を求める。
