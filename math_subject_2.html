授業のねらい

数学Ⅱを体系的に学ぶ

教材名を押して学習を始めましょう。各教材の下に学習内容を示しています。

数学Ⅱ

単元名を押すと教材が開きます。

  • 第1章 式と証明

  • 3次式の展開と因数分解 →

    三次の乗法公式を理解し、展開と因数分解を往復する。

  • 二項定理 →

    二項係数を使って高次の展開を整理する。

  • 整式の除法 →

    整式も筆算で除算でき、商と余りに分けられる。

  • 分数式の計算 →

    分母をそろえて整理し、約分の条件も確認する。

  • 恒等式と係数比較 →

    すべての x について成立する等式が恒等式である。

  • 等式の証明と不等式の証明 →

    式変形の根拠を明示し、非負量を利用する。

  • 第2章 複素数と方程式

  • 複素数の導入 →

    実数だけでは解けない方程式を扱うため、虚数単位を導入する。

  • 2次方程式の解と判別式 →

    判別式が負でも、複素数の範囲なら解を表せる。

  • 解と係数の関係 →

    二次方程式の2つの解の和と積を係数から求める。

  • 剰余の定理と因数定理 →

    剰余の定理・因数定理・組立除法を学ぶ。

  • 高次方程式 →

    3次・4次方程式、重解、複素数の解と係数の関係を学ぶ。

  • 第3章 図形と方程式

  • 直線上の点 →

    数直線上の距離、内分点・外分点、中点

  • 平面上の点 →

    2点間の距離、内分点・外分点、重心、対称な点

  • 直線の方程式 →

    傾き、2点を通る直線、一般形

  • 2直線の関係 →

    平行・垂直・交点、点と直線の距離

  • 円の方程式 →

    中心からの距離が一定の点の集合を式で表す。

  • 2つの円 →

    2つの円の位置関係、共有点、共通弦、交点を通る円の方程式を学びます。

  • 軌跡と方程式 →

    条件を満たす点の集合を方程式で表す。

  • 不等式の表す領域 →

    不等式を満たす点の領域を座標平面で理解する。

  • 第4章 三角関数

  • 一般角と弧度法 →

    度数法と弧度法の対応を理解する。

  • 三角関数 →

    単位円から正弦・余弦・正接を定義し、値を求める。

  • 三角関数の性質 →

    相互関係・対称性・周期性を単位円で理解する。

  • 三角関数のグラフ →

    周期、振幅、平行移動からグラフを読む。

  • 三角関数の応用 →

    方程式・不等式を単位円とグラフで解き、最大値・最小値を考える。

  • 加法定理 →

    角の和や差の三角関数を展開する。

  • 加法定理の応用 →

    2倍角・半角、積と和・差の変換公式を導き、問題に応用する。

  • 三角関数の合成 →

    正弦と余弦の和を1つの三角関数で表す。

  • 第5章 指数関数と対数関数

  • 指数の拡張 →

    0乗・負の指数・累乗根・実数指数を、証明と動くグラフで学ぶ。

  • 指数関数 →

    底をスライダーで変え、増減・方程式・不等式を理解する。

  • 対数とその性質 →

    対数の定義・対数法則・底の変換公式を証明付きで学ぶ。

  • 対数関数 →

    指数関数との対称性、真数条件、方程式・不等式、最大・最小を学ぶ。

  • 常用対数 →

    常用対数・桁数・小数首位・実生活の応用を学ぶ。

  • 第6章 微分法と積分法

  • 微分係数 →

    微分係数の定義と割線から接線への変化

  • 導関数 →

    導関数の定義と多項式の微分公式

  • 接線 →

    接線の傾きと接線の方程式

  • 関数の値の変化 →

    増減表、極大値・極小値

  • 最大値・最小値 →

    閉区間での最大値・最小値と応用

  • 関数のグラフと方程式・不等式 →

    グラフと方程式の実数解、不等式の解

  • 不定積分 →

    原始関数と積分定数

  • 定積分 →

    定積分の計算と符号

  • 面積 →

    放物線と直線などで囲まれる面積

  • 放物線と直線で囲まれた図形の面積 →

    放物線と直線の交点を求め、定積分で面積を計算する例題へ
