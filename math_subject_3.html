数学Ⅲの授業

みんなの数学データベース｜高校生のための授業

授業のねらい

数学Ⅲを体系的に学ぶ

教材名を押して学習を始めましょう。各教材の下に学習内容を示しています。

第1章　関数

各教材のタイトルから学習を始められます。

  • 分数関数 →

    分母が0となる値は定義域に入らず、漸近線やグラフの動きを調べます。

  • 無理関数 →

    根号の中の条件を調べ、定義域・値域とグラフの形を理解します。

  • 逆関数と合成関数 →

    逆関数と合成関数の求め方、グラフとの関係を学びます。

第2章　極限

各教材のタイトルから学習を始められます。

  • 数列の極限 →

    数列の収束・発散と極限の計算法を学びます。

  • 無限等比数列 →

    公比による収束・発散の違いを調べます。

  • 無限級数 →

    部分和の極限と無限級数の和を学びます。

  • 関数の極限 →

    片側極限と極限の計算法を学びます。

  • 三角関数と極限 →

    三角関数の重要な極限とその応用を学びます。

  • 関数の連続性 →

    連続の定義と中間値の定理を学びます。

第3章　微分法

各教材のタイトルから学習を始められます。

  • 微分係数と導関数 →

    導関数は変化の割合の極限です。

  • 積・商の微分法 →

    積と商の微分法の公式を学びます。

  • 合成関数の微分法 →

    合成関数を微分する連鎖律を学びます。

  • 三角関数の導関数 →

    ラジアンを用いた三角関数の導関数を学びます。

  • 指数・対数関数の導関数 →

    指数関数と対数関数の微分公式を学びます。

  • 高次導関数と陰関数の微分 →

    高次導関数と陰関数の微分を学びます。

第4章　微分法の応用

各教材のタイトルから学習を始められます。

  • 接線・法線の方程式 →

    接線と法線の傾きを求めます。

  • 平均値の定理 →

    平均変化率と微分係数の関係を学びます。

  • 関数の増減・極値 →

    導関数の符号と増減・極値を調べます。

  • グラフの凹凸と変曲点 →

    第2次導関数と曲線の凹凸を学びます。

  • 最大・最小と方程式への応用 →

    最大・最小と方程式への応用を学びます。

  • 速度・加速度 →

    位置・速度・加速度の関係を学びます。

第5章　積分法

各教材のタイトルから学習を始められます。

  • 不定積分と基本公式 →

    原始関数と不定積分を学びます。

  • 置換積分法 →

    式の一部分を変数に置き換えます。

  • 部分積分法 →

    積の微分公式を積分に応用します。

  • 定積分の意味と計算 →

    定積分と符号付き面積を学びます。

  • 定積分の置換積分・部分積分 →

    定積分への置換・部分積分を学びます。

第6章　積分法の応用

各教材のタイトルから学習を始められます。

  • 面積 →

    曲線に囲まれた部分の面積を求めます。

  • 回転体の体積 →

    回転体の体積を積分で求めます。

  • 曲線の長さ →

    曲線の長さを積分で求めます。

  • 速度と道のり →

    速さの積分で道のりを求めます。
