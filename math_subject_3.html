授業のねらい

数学Ⅲを体系的に学ぶ

教材名を押して学習を始めましょう。各教材の下に学習内容を示しています。

第1章　関数

各教材のタイトルから学習を始められます。

分数関数 →

分数式の定義域、漸近線とグラフを調べます。

無理関数 →

根号を含む関数の定義域と値域を考えます。

逆関数と合成関数 →

逆関数と合成関数の求め方を学びます。

第2章　極限

各教材のタイトルから学習を始められます。

数列の極限 →

数列の収束・発散と極限の計算を学びます。

無限等比数列 →

公比と収束・発散の関係を学びます。

無限級数 →

部分和と無限級数の和を理解します。

関数の極限 →

左右からの極限と極限の計算を学びます。

三角関数と極限 →

三角関数の重要な極限公式を学びます。

関数の連続性 →

連続性の条件と中間値の定理を学びます。

第3章　微分法

各教材のタイトルから学習を始められます。

微分係数と導関数 →

平均変化率、微分係数、導関数の意味と接線を学びます。

導関数の計算 →

積・商の微分法と合成関数の微分法を学びます。

いろいろな関数の導関数 →

三角・指数・対数関数の導関数を学びます。

第n次導関数 →

高次導関数の規則性と第n次導関数を求めます。

関数のいろいろな表し方と導関数 →

陰関数・媒介変数表示・逆関数の微分を学びます。

第4章　微分法の応用

各教材のタイトルから学習を始められます。

接線、法線 →

微分係数から接線と法線の方程式を求めます。

平均値の定理 →

平均変化率と接線の傾きの関係を学びます。

関数の値の変化 →

導関数の符号から関数の増減と極値を判定します。

関数の最大と最小 →

閉区間での最大値と最小値を微分で調べます。

関数のグラフ →

第2次導関数から凹凸や変曲点を調べます。

方程式、不等式への応用 →

グラフの増減を利用して解の個数や不等式を調べます。

速度と加速度 →

位置・速度・加速度の微分関係を学びます。

近似式 →

微分係数を使って関数の値を近似します。

第5章　積分法

各教材のタイトルから学習を始められます。

不定積分とその基本性質 →

原始関数、不定積分の意味、積分定数と基本公式を学びます。

置換積分法 →

変数を置き換えて複雑な不定積分を計算します。

部分積分法 →

積の微分法を利用して不定積分を求めます。

いろいろな関数の不定積分 →

三角関数、指数・対数関数、分数関数などの積分を学びます。

定積分とその基本性質 →

定積分の意味、性質、微積分の基本定理を学びます。

定積分の置換積分法 →

変数とともに積分区間も置き換える方法を学びます。

定積分の部分積分法 →

定積分での部分積分公式と端点の代入を学びます。

定積分の種々の問題 →

対称性、絶対値、積分で定義された関数などを学びます。

第6章　積分法の応用

各教材のタイトルから学習を始められます。

面積 →

曲線に囲まれた部分の面積を求めます。

体積 →

回転体の体積や断面積を利用する体積の求め方を学びます。

曲線の長さ →

微小な線分を積分し曲線の長さを求めます。

速度と道のり →

速度・速さと道のりを積分で考えます。
