数学Ⅲの授業

みんなの数学データベース｜高校生のための授業

授業のねらい

数学Ⅲを体系的に学ぶ

教材名を押して学習を始めましょう。各教材の下に学習内容を示しています。

第1章　関数

各教材のタイトルから学習を始められます。

  • 分数関数 →

    分母が0となる値は定義域に入らず、近づいたときの振る舞いも調べます。

  • 無理関数 →

    根号の中が0以上であることを利用して定義域を決めます。

  • 逆関数と合成関数 →

    逆関数は入力と出力を交換し、合成関数は関数を順番に適用します。

第2章　極限

各教材のタイトルから学習を始められます。

  • 数列の極限 →

    数列の項がある値へ近づくことを収束といいます。

  • 無限等比数列と無限級数 →

    等比級数は公比の絶対値が1未満なら収束します。

  • 関数の極限 →

    左からと右からの極限が等しいとき、その点での極限が存在します。

  • 連続関数と中間値の定理 →

    区間で連続な関数は、両端の関数値の間の値をすべてとります。

第3章　微分法

各教材のタイトルから学習を始められます。

  • 微分係数と導関数 →

    導関数は変化の割合の極限です。

  • 積・商の微分法 →

    積では二項に分けて微分し、商では分母の二乗が現れます。

  • 合成関数の微分法 →

    外側の関数の微分に、内側の関数の微分を掛けます。

  • 三角関数の導関数 →

    角度をラジアンで測ると、三角関数の微分公式が簡潔になります。

  • 指数・対数関数の導関数 →

    自然対数の底 e を使う指数関数は微分しても同じ形です。

  • 高次導関数と陰関数の微分 →

    導関数を繰り返し求めたものを高次導関数といいます。

第4章　微分法の応用

各教材のタイトルから学習を始められます。

  • 接線・法線の方程式 →

    微分係数が接線の傾きです。法線の傾きは接線と垂直になります。

  • 平均値の定理 →

    ある区間の平均変化率に等しい微分係数をもつ点が存在します。

  • 関数の増減・極値 →

    導関数の符号により単調増加・減少が判定できます。

  • グラフの凹凸と変曲点 →

    第2次導関数を使うとグラフの凹凸が分かります。

  • 最大・最小と方程式への応用 →

    端点や導関数が0になる点を調べ、候補の関数値を比較します。

  • 速度・加速度 →

    位置を時間で微分したものが速度、速度を微分したものが加速度です。

第5章　積分法

各教材のタイトルから学習を始められます。

  • 不定積分と基本公式 →

    微分すると元の関数になる関数を原始関数といいます。

  • 置換積分法 →

    式の一部分を新しい変数に置き換えます。

  • 部分積分法 →

    積の微分公式を積分に応用します。

  • 定積分の意味と計算 →

    定積分は符号付きの面積と対応します。

  • 定積分の置換積分・部分積分 →

    定積分では置換後の積分区間も新しい変数に合わせます。

第6章　積分法の応用

各教材のタイトルから学習を始められます。

  • 面積 →

    上側の関数から下側の関数を引いて積分します。

  • 回転体の体積 →

    x軸のまわりに回転する回転体は断面の円の面積を積分します。

  • 曲線の長さ →

    微小な線分の長さを積分して曲線の長さを求めます。

  • 速度と道のり →

    速さは速度の絶対値であり、移動距離はその積分です。
