数学Bの授業

みんなの数学データベース｜高校生のための授業

授業のねらい

数学Bを体系的に学ぶ

教材名を押して学習を始めましょう。各教材の下に学習内容を示しています。

第1章　数列

各教材のタイトルから学習を始められます。

  • 数列 →

    一定の順に並ぶ数を数列といい、各数を項といいます。

  • 等差数列とその和 →

    隣り合う項の差が一定の数列を等差数列といいます。

  • 等比数列とその和 →

    隣り合う項の比が一定の数列を等比数列といいます。

  • 和の記号Σ →

    Σは項を指定した範囲で足し合わせる記号です。

  • 階差数列 →

    隣り合う項の差を取ると規則が見えることがあります。

  • いろいろな数列の和 →

    和の公式と式の変形を組み合わせて求めます。

  • 漸化式と数列 →

    漸化式は前の項から次の項を定める関係式です。

  • 漸化式の応用 →

    図形の個数や確率の変化を漸化式で解きます。

  • 数学的帰納法 →

    初期値の成立とnからn+1への移行を示します。

第2章　統計的な推測

各教材のタイトルから学習を始められます。

  • 確率変数と確率分布 →

    確率変数が取る値と確率の対応を確率分布といいます。

  • 確率変数の期待値と分散 →

    期待値が中心、分散が散らばりを表します。

  • 確率変数の変換 →

    定数を足すと期待値は移動し、定数倍は分散に二乗で影響します。

  • 確率変数の和と期待値 →

    確率変数の和の期待値は、独立性にかかわらず各期待値の和になります。

  • 独立な確率変数と期待値・分散 →

    独立である2変数の和の分散は各分散の和になります。

  • 二項分布 →

    成功確率pの独立なベルヌーイ試行をn回繰り返します。

  • 正規分布 →

    平均μ、分散σ²の左右対称な釣鐘型の確率分布です。

  • 母集団と標本 →

    全体を母集団、そこから選んだ一部を標本といいます。

  • 標本平均とその分布 →

    独立な無作為標本の平均の分散は標本サイズに反比例します。

  • 推定 →

    母標準偏差が既知などの条件下で、信頼区間を使って母平均を推定します。

  • 仮説検定 →

    帰無仮説を置き、観測結果がそれと矛盾する程度を評価します。

第3章　数学と社会生活

各教材のタイトルから学習を始められます。

  • 数学を活用した問題解決 →

    数量の関係をモデル化し、結果を現実の状況に照らして検討します。

  • 社会の中にある数学 →

    割合や指数的な変化など、日常の問題を数学で記述します。

  • 移動平均 →

    時間系列の短期的なばらつきを平滑化して傾向を調べます。

  • 回帰分析 →

    2変数の関係を直線で近似し、残差を確認します。
