数学Cの授業一覧

高校生のための授業｜単元から教材を選ぶ

授業のねらい

数学Cを体系的に学ぶ

教材名を押して学習を始めましょう。各教材の下に学習内容を示しています。

平面上のベクトル

ベクトルの基本から図形・方程式への応用まで

  • 平面上のベクトル →

    ベクトルの意味・向き・大きさと、等しいベクトルを学びます。

  • ベクトルの演算 →

    ベクトルの和・差・実数倍を、図と計算で学びます。

  • ベクトルの成分 →

    成分表示とベクトルの大きさ、成分による計算を学びます。

  • ベクトルの内積 →

    内積の定義・成分計算・垂直条件を学びます。

  • 位置ベクトル →

    位置ベクトルと内分点・外分点の表し方を学びます。

  • ベクトルと図形 →

    一直線上の証明、交点の位置ベクトル、内積の利用を学びます。

  • ベクトル方程式 →

    直線・円のベクトル方程式を、動く図と例題で学びます。

空間のベクトル

空間座標とベクトルから、直線・平面の方程式まで

  • 空間の座標 →

    空間座標の読み方、座標平面への射影、2点間の距離と中点を動く立体図で学びます。

  • 空間のベクトル →

    空間ベクトルの向きと大きさ、等しいベクトル、和・差・実数倍を立体図で学びます。

  • ベクトルの成分 →

    空間ベクトルの3成分、成分の計算、ベクトルの大きさ、2点を結ぶベクトルを動く立体図で学びます。

  • ベクトルの内積 →

    空間ベクトルの内積と成分計算、なす角、垂直条件、射影を動く立体図で学びます。

  • 位置ベクトル →

    点の位置をベクトルで表し、中点・内分点・外分点の位置ベクトルを動く立体図で学びます。

  • ベクトルと図形 →

    同一直線上・同一平面上の証明、直線と平面の交点、内積による証明、点と直線の距離を学びます。

  • 座標空間における図形 →

    球面の方程式、平面・直線との位置関係、距離や共有点を動く立体図と例題で学びます。

  • 平面の方程式 →

    法線ベクトル、3点を通る平面、直線と平面の交点、点と平面の距離を動く立体図で学びます。

  • 直線の方程式 →

    方向ベクトルと媒介変数による直線の表し方、2点を通る直線、2直線の位置関係、直線と平面の交点を学びます。

複素数平面

複素数の図形的な意味から極形式・回転まで

  • 複素数平面 →

    複素数と点の対応、加減算、共役複素数、絶対値と距離を動く図で学びます。

  • 複素数の極形式と乗法・除法 →

    偏角と極形式、積と商の性質、回転と拡大縮小を動く図と例題で学びます。

  • ド・モアブルの定理 →

    累乗と偏角の関係を理解し、複素数の累乗や方程式への応用を学びます。

  • 複素数と図形 →

    複素数を使った回転、点の移動、図形の性質を学びます。

式と曲線

2次曲線、媒介変数表示、極座標と多様な曲線

  • 放物線 →

    焦点と準線による定義、標準形、動く図で放物線を学びます。

  • 楕円 →

    2つの焦点からの距離と楕円の方程式を学びます。

  • 双曲線 →

    2焦点からの距離の差、標準形と漸近線を学びます。

  • 2次曲線の平行移動 →

    平行移動による頂点・中心と方程式の変化を学びます。

  • 2次曲線と直線 →

    直線との共有点、判別式、放物線・楕円・双曲線の接線を1ページで学びます。

  • 2次曲線の性質 →

    離心率と焦点・準線の関係を学びます。

  • 曲線の媒介変数表示 →

    媒介変数による曲線の表し方と、動く点の軌跡を学びます。

  • 極座標と極方程式 →

    極座標と直交座標の関係、極方程式を学びます。

  • コンピュータといろいろな曲線 →

    サイクロイド、アステロイド、リサージュ曲線、カージオイドを動くグラフと媒介変数表示で学びます。
