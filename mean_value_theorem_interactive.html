📈 平均値の定理を動かして理解する

割線と接線が平行になる瞬間を探そう

数学Ⅱ・数学Ⅲ｜微分法

1. 平均値の定理とは？

関数 f(x) が閉区間 [a,b] で連続、開区間 (a,b) で微分可能なら、ある c∈(a,b) が存在して

f′(c) = (f(b) − f(a)) / (b − a)

が成り立ちます。つまり、2点を結ぶ割線と平行な接線が、区間の内部に少なくとも1本存在するということです。

2. グラフを動かそう

青：曲線　橙：割線　緑：接線（平均値の定理を満たす位置）

※ a と b は a＜b になるよう自動調整します。三角関数の角度はラジアンです。複数の c がある場合はすべて表示します。

3. ロルの定理を確かめよう

もし f(a)=f(b) なら、割線の傾きは0。区間内に f′(c)=0 となる点があります。

この場合、f(−1)=f(1)=1 なので、c=0 で水平な接線が得られます。

4. 証明を読んでみよう

① ロルの定理の証明

f が [a,b] で連続だから最大値・最小値を取ります。f(a)=f(b) のとき、f が定数なら内部の任意の点で f′=0 です。定数でなければ、最大値または最小値の少なくとも一方が区間内部で達成されます。その点では微分可能性とフェルマーの定理により f′(c)=0 です。

② 平均値の定理の証明

割線の傾きを m=(f(b)−f(a))/(b−a) とし、g(x)=f(x)−m(x−a) とおきます。

g(b)−g(a)=f(b)−f(a)−m(b−a)=0 より g(a)=g(b)。g は連続かつ内部で微分可能なので、ロルの定理から g′(c)=0 となる c∈(a,b) が存在します。

したがって 0=g′(c)=f′(c)−m、すなわち f′(c)=(f(b)−f(a))/(b−a) です。

③ なぜ連続・微分可能が必要？

例：f(x)=|x|、区間 [−1,1]。両端の関数値は等しいのに、区間内部で f′(c)=0 となる点はありません。x=0 では微分不可能だからです。条件は省略できません。

5. 確認問題

問題：f(x)=x²、区間 [1,3] で平均値の定理を満たす c を求めましょう。

答えと解説を見る

割線の傾きは (9−1)/(3−1)=4。f′(x)=2x なので 2c=4。よって c=2 です。確かに 1＜2＜3。

発展：f(x)=x³−3x のとき、同じ傾きの接線が複数現れることがあります。上のグラフで確かめましょう。
