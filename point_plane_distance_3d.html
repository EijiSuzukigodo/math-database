④ 距離と垂線の足

点Pから平面への最短距離は、平面に垂直な線分PHの長さです。

例題を選ぶ

⑤ 公式の意味

平面 ax + by + cz + d = 0 の法線ベクトルは n = (a, b, c) です。

点 P(x₀,y₀,z₀) から平面までの距離は

距離 = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²)

垂線の足Hは、k = (ax₀ + by₀ + cz₀ + d)/(a²+b²+c²) とおくと、H = P − k(a,b,c) で求められます。

※ a、b、c がすべて0のときは平面を定められないため、計算を行いません。図は理解のための有限の平面片を表示しています。
