恒等式とは？

どんな x の値でも左右が等しくなる式を恒等式といいます。2つの多項式が恒等的に等しいためには、同じ次数の係数がそれぞれ等しくなる必要があります。

ax² + bx + c ≡ px² + qx + r ⇔ a=p, b=q, c=r

「≡」は、ここではすべての実数 x について等しいことを表します。

左辺：ax² + bx + c

右辺：px² + qx + r

③ x の値を変えて、左右の値を調べよう

ある1つの x で左右が等しくても、恒等式とは限りません。すべての x で等しいことが大切です。
