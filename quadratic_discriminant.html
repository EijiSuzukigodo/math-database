2次方程式と判別式を動かして理解する

みんなの数学データベース｜数学Ⅰ・2次関数

① グラフと解の関係

2次方程式 ax² + bx + c = 0 の実数解は、放物線 y = ax² + bx + c と x軸との交点のx座標 です。

スライダーを動かして、交点の数がどう変わるか観察しましょう。

y = x² − 4

※ 2次方程式なので a = 0 にはできません。スライダーが0に来た場合は自動で0.5に調整します。

② 判別式の意味

判別式 D = b² − 4ac によって、実数解の個数がわかります。

D > 0：異なる2つの実数解（x軸と2点で交わる）

D = 0：重解（x軸に接する）

D < 0：実数解なし（x軸と交わらない）

グラフの見える範囲を超える交点がある場合も、計算した解の個数は変わりません。

③ 練習問題

問題1：x² − 5x + 6 = 0 の判別式と実数解の個数は？
D = (−5)² − 4×1×6 = 1。異なる2つの実数解（x = 2, 3）。
問題2：x² − 4x + 4 = 0 はx軸と何点で交わる？
D = 16 − 16 = 0。1点で接する（x = 2）。
問題3：x² + 2x + 5 = 0 に実数解はある？
D = 4 − 20 = −16。実数解はありません。
