2次関数のグラフを動かして理解する

数学Ⅰ ／ 2次関数

1．放物線を動かしてみよう

2次関数は、頂点の位置がわかる形で次のように表せます。

y = a(x − p)² + q

下のスライダーを動かして、グラフの変化を観察しましょう。

※ a = 0 のときは2次関数ではなく、水平な直線になります。

式：y = x²
頂点：(0, 0)
対称軸：x = 0

2．3つの数値の意味

a：正なら上に開き、負なら下に開きます。絶対値が大きいほど細い放物線になります。

p：頂点のx座標です。pを増やすと右へ動きます。

q：頂点のy座標です。qを増やすと上へ動きます。

頂点は (p, q)、対称軸は x = p です（a ≠ 0）。

3．練習問題

問題1： y = 2(x − 3)² + 1 の頂点はどこでしょう？

問題2： y = −(x + 2)² + 3 のグラフはどちらに開くでしょう？

問題3： y = (x − 1)² − 2 の対称軸は？
