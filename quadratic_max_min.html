📈 2次関数の最大値・最小値

放物線を動かして、頂点と定義域の関係を理解しよう

① 基本の考え方

2次関数 y = a(x − p)² + q の頂点は (p, q) です。

a ＞ 0 のとき下に凸で、頂点が最も低い点です。a ＜ 0 のとき上に凸で、頂点が最も高い点です。

定義域がすべての実数なら、a ＞ 0 のとき最小値 q（最大値なし）、a ＜ 0 のとき最大値 q（最小値なし）です。

③ 定義域がある場合のポイント

定義域 L ≦ x ≦ R では、次の3か所を比較すると最大値・最小値が求められます。

  1. 左端 x = L の値
  2. 右端 x = R の値
  3. 頂点 x = p の値（ただし L ≦ p ≦ R の場合だけ）

頂点が定義域の外にあるときは、頂点の値を最大値・最小値として使えません。スライダーで確認してみましょう。

④ 理解度チェック

問題1

y = (x − 2)² + 1（定義域はすべての実数）の最小値は？

最小値は 1（x = 2 のとき）。最大値はありません。
問題2

y = −(x + 1)² + 4（定義域はすべての実数）の最大値は？

最大値は 4（x = −1 のとき）。最小値はありません。
問題3

y = (x − 2)² + 1、0 ≦ x ≦ 3 の最大値と最小値は？

x = 0 で y = 5、x = 3 で y = 2、頂点 x = 2 で y = 1。最大値は 5、最小値は 1 です。
