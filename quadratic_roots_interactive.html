2次方程式の解を動かして理解する

数学Ⅱ｜複素数と方程式（数学Ⅰの復習にも対応）

① 係数を変えてみよう

方程式 ax² + bx + c = 0 の係数を動かすと、放物線と解がどう変わるでしょうか。

※ a = 0 は2次方程式ではないため、選んだ場合は注意を表示します。

青：放物線　赤：実数解（x軸との交点）

② 判別式と解を確認

③ どうして解の個数が変わるの？

判別式 D = b² − 4ac の符号で実数解の個数が決まります。

  • D > 0：実数解が2つ。放物線はx軸と2点で交わります。
  • D = 0：重解。放物線はx軸に接します。
  • D < 0：実数解はありません。ただし複素数の範囲では2つの共役な解があります。
