2．数式で理解する

区間 [0, 2] を n 等分すると、1つの区間の幅は次のようになります。

Δx = (2 − 0) / n = 2 / n

各長方形の高さを f(xₖ) とすれば、面積の和は

Sₙ = Σₖ₌₁ⁿ f(xₖ) Δx

です。長方形の幅を小さくしていくと、面積の和は定積分の値に近づきます。

∫₀² f(x) dx = limₙ→∞ Sₙ

ここで、xₖ は各小区間で選んだ点です。左端・右端・中点のいずれを使うかで有限の n での近似値は異なりますが、今回の連続関数では、n を無限に大きくすると同じ積分値に収束します。

3．f(x) = x² を実際に計算する

右端を使う場合、k 番目の長方形の高さは f(2k/n) = 4k²/n² です。

Sₙ = Σₖ₌₁ⁿ (4k²/n²) × (2/n) = (8/n³) Σₖ₌₁ⁿ k²

平方和の公式 Σₖ₌₁ⁿ k² = n(n+1)(2n+1)/6 を使うと、

Sₙ = 4(n+1)(2n+1)/(3n²)

したがって、

limₙ→∞ Sₙ = 8/3 ≒ 2.666667

一方、積分の公式でも

∫₀² x² dx = [x³/3]₀² = 8/3

となり、同じ値が得られます。

4．考えてみよう

問題：f(x)=x² で n=4 のとき、左端と右端の近似値はそれぞれいくつでしょうか？ グラフで確かめてください。

答えと解説を見る

Δx = 1/2。左端は x=0, 0.5, 1, 1.5 なので、面積の和は (0+0.25+1+2.25)×0.5 = 1.75。右端は x=0.5, 1, 1.5, 2 なので (0.25+1+2.25+4)×0.5 = 3.75 です。正確な値は約 2.666667 です。
