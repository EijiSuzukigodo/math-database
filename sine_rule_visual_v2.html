正弦定理を動かして理解する

外接円と辺・角の関係を、図と計算で学ぶ

正弦定理 余弦定理 三角形の面積 定理の応用 高校数学の目次

① 図を動かして確かめる

頂点Aの位置と底辺BCの長さを変えられます。図の辺の値は描画上の縮尺による値です。

② 正弦定理

a / sin A = b / sin B = c / sin C = 2R

ここで a, b, c はそれぞれ角 A, B, C の向かい側の辺、R は外接円の半径です。

証明を開く

三角形の外接円を考え、辺 BC を弦とする円周角 A を用います。直径と弦からできる直角三角形では a = 2R sin A となります。A が鈍角の場合も sin(180°−A)=sin A を使えば同じ式です。他の辺についても同様に成り立ちます。

③ 例題

角 A=30°、辺 a=5 のとき外接円の半径 R を求めましょう。

解答と解説

2R=a/sin A=5/(1/2)=10。したがって R=5 です。

④ 練習問題

A=45°、B=60°、a=√2 のとき b を求めましょう。

答え

b=a sin60°/sin45°=√3。

学習のまとめ

図の値を変え、公式がいつでも成り立つことを確かめましょう。計算では、角度の単位が「度」であることに注意します。
