関数を多項式で近似してみよう

青い曲線は元の関数、赤い曲線はマクローリン多項式です。次数を増やすと、原点付近から近似が改善される様子がわかります。

マクローリン展開とは？

関数を x = 0 の近くで多項式によって表す方法です。一般に、n 次のマクローリン多項式は次の式で与えられます。

Pₙ(x) = f(0) + f′(0)x + f″(0)x²/2! + … + f⁽ⁿ⁾(0)xⁿ/n!

テイラー展開は、中心を x = a とする一般化です。マクローリン展開は a = 0 の場合に当たります。

次数を上げても、原点から遠い場所では近似が悪いことがあります。近似の良さは関数、次数、x の位置によって変わります。

確認問題

問題1： sin x のマクローリン多項式を3次まで求めてください。

解答を見る

sin x ≈ x − x³/6 です。

問題2： eˣ の2次近似を使って e⁰·¹ を近似してください。

解答を見る

1 + 0.1 + 0.1²/2 = 1.105 です（実際の値は約1.10517）。
